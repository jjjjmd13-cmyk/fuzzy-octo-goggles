# B 그림체 통일성 시험 · 2026-11-04

STYLE_B.md를 먼저 작성하고, 각 모델을 **별도 Blender 프로세스**에서 그 규칙표를 다시 읽어 제작했다. 다른 B 모델이나 기존 A 메시를 불러와 베끼지 않았다. 공통 코드는 도형·텍스처 생성·출력 도우미뿐이다. 색·재질 수치는 규칙표에서 읽으며 각 GLB에는 규칙표 SHA-256을 기록했다. 강아지는 마른 상태의 앉은 시바견이다.

| 파일 | 크기 | 삼각형 | PNG 최대 한 변 |
|---|---|---:|---:|
| test_b_shower.glb | 세로 0.25m | 2,556 | 256 |
| test_b_dryer.glb | 앞뒤 0.30m | 2,836 | 256 |
| test_b_brush.glb | 세로 0.20m | 2,236 | 512 |
| test_b_towel.glb | 가로 0.25 × 세로 약 0.15m | 2,272 | 512 |
| test_b_dog.glb | 앉은 높이 0.35m | 7,634 | 512 |

전부 glTF 2.0 바이너리, 미터, +Y 위, 앞 −Z. 도구 루트는 쥐는 곳이며 강아지 루트는 발 아래 바닥이다. 텍스처는 색/노멀/ORM PNG로 모두 GLB 안에 있다. 외부 이미지·헤어 파티클·털 카드·AO·발광·조명 굽기·리깅·키프레임 없음. 드라이기 `Fan`은 독립 메시이며 자기 피벗을 기준으로 로컬 Z 회전한다. 정확한 피벗·치수·해시는 `validation.json` 참조.

## 비교 그림

- `lineup_b.png`: **납품 GLB를 다시 불러와** 원래 크기로 같은 스튜디오에 한 줄 배치. 동일 조명/배경/카메라/노출, 개별 색 보정 없음.
- `compare_a_b.png`: 기존 `assets/models/tools/shower.glb`, `brush.glb`와 B 시험본을 같은 조건으로 배치. A 원본 기준 커밋 `1a895a3`. A 파일은 수정하지 않았다.
- 두 그림은 **실제 모델의 Blender 렌더**이며 게임 실행 화면이 아니다. 물·거품·젖은 털 효과가 들어간 콘셉트 그림을 대신하는 결과도 아니다.

## 검증과 제한

- Khronos glTF Validator 5개: 오류 0, 경고 0. 눈 재질의 불필요한 tangent 정보 메시지를 포함한 원문은 `gltf_validation.json`에 보존했다.
- 실제 GLB 바이트 검사: 삼각형·비퇴화 면·법선·tangent·크기·루트·PNG·색 허용범위·거칠기/금속성·노멀 강도·Fan 피벗 PASS (`validate_style_b.py`).
- Godot 4.4.1 **에디터 모드**에서 5종 직접 읽기, 색/거칠기/노멀 텍스처, 메시, 독립 Fan 회전 검사 PASS. 무압축 내장 이미지 모드를 사용했다. 게임 런타임 실행과는 별개다.
- 로컬 Godot 런타임은 빈 프로젝트조차 초기화 시 signal 11로 충돌한다. 전체 기존 테스트 29개는 성공을 확인하지 못했다(0 통과 / 29 실패). 호환 렌더러에서도 재현. 에디터 종료 시 자원 해제 진단도 관찰했다. 게임 내 외형·GPU 성능·장시간 조작·Windows/Steam Deck 실기는 미검증.
- 이 폴더는 원래 저장소의 `art/incoming/.gdignore` 아래 **검토용 시험 자산**이다. 현행 게임 도구/강아지를 교체하지 않았고 실행 코드는 수정하지 않았다.

**솔직한 평가:** 도구 30~50종은 이 색·재질 수치와 형태 규칙으로 통일을 유지할 수 있다. 다만 이번에 확인한 범위는 5종이며, 동물의 털 방향·젖은 상태·수건 접힘은 규칙표만으로 자동 보장되지 않아 외형 검수가 필요하다. 이번 시바는 절제한 PBR 스타일로, 고밀도 실사 털은 아니다.

## 재생성

Blender 4.5에서 `build_style_b.py -- shower` 형태로 shower / dryer / brush / towel / dog를 **각각 실행**한 뒤 `-- render`로 두 스튜디오를 렌더한다. 같은 저장소의 `tools/art/build_slots.py`에 있는 기본 도형 도우미를 사용한다. 납품 강아지는 `optimize_glb.py test_b_dog.glb`로 PNG 중복 제거·무손실 필터링을 적용했다(픽셀·형상 동일, 약 2.32MB → 0.80MB). PNG 라벨은 Pillow로 `compose_previews.py` 실행(기본 한국어 글꼴: Windows 맑은 고딕, 다른 OS는 `STYLE_B_FONT` 지정). 검증은 Python UTF-8 모드 + numpy/Pillow로 `validate_style_b.py`. Godot는 저장소 루트에서 `--headless --editor --script art/incoming/style_b_test/check_godot.gd`.

모델·표면 무늬는 이번 작업에서 수학적 도형/패턴으로 직접 생성했다. 외부 에셋·이미지·유료 리소스를 사용하지 않았다. 비교의 A 모델만 기존 저장소 자산을 사용했다.
