# 멍냥 목욕탕 실사풍 비교 시험

털·원목·천·벽돌의 표면 차이를 볼 수 있는 반사실 모형 3종입니다. 각 미리보기와 비교 이미지는 내보낸 GLB를 다시 불러와 렌더링했습니다.

| 모형 | 삼각형 | GLB 용량 | 내장 PNG 크기 | 이미지 |
| --- | ---: | ---: | --- | --- |
| [강아지](real_dog.glb) | 7,686 | 3.14 MB | 털 1024², 얼굴 128² | [미리보기](real_dog_preview.png) · [A/B 비교](real_dog_comparison.png) |
| [목욕통](real_tub.glb) | 3,340 | 2.82 MB | 256², 원목 512² | [미리보기](real_tub_preview.png) · [A/B 비교](real_tub_comparison.png) |
| [빵집](real_bakery.glb) | 4,116 | 6.03 MB | 256², 벽돌·원목·천 512² | [미리보기](real_bakery_preview.png) · [A/B 비교](real_bakery_comparison.png) |

- **강아지**는 기존 앉은 모형의 외곽·부위 계층·관절 위치를 기준으로 크림색 털과 한쪽 연갈색 귀를 만들었습니다. 털은 겹침을 검사한 UV 한 장과 `FurCleanAlbedo` 재질 하나를 사용합니다. 눈 반짝임은 조명으로 표현했습니다.
- **목욕통**은 욕조·고무 마개·도구걸이의 원본 형상과 위치를 유지하고, 같은 1.60 × 1.10 m 외곽과 0.90 m 상판 높이로 원목 받침을 만들었습니다. 법랑과 나뭇결은 별도 재질입니다.
- **빵집**은 줄눈이 있는 벽돌, 원목 문틀, 줄무늬 천 차양, 반투명 유리와 진열 빵을 모델링했습니다. 요청서 기준 중심은 방 좌표 (14.6, 0, −4.6)이고 외곽은 폭 3.0 × 높이 3.4 × 깊이 3.4 m입니다. 정면은 −X입니다. 현재 A 파일의 외곽 중심은 (14.25, 0, −6.75), 크기는 3.5 × 4.5 × 4.5 m라서 비교 렌더에서만 바닥 중심을 맞췄습니다. 배율은 같게 유지했습니다.

GLB는 1단위 = 1 m, +Y 위 기준입니다. 색·노멀·ORM은 PNG로 내장했고, ORM은 R=255(AO 없음), G=거칠기, B=금속성입니다. 비교는 각 쌍의 조명·배경·카메라 각도와 배율·노출을 일치시켰습니다.
