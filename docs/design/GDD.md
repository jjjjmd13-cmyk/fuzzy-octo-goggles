## 1. 한 줄 요약과 기둥

**빛이 꺼진 지하 도시로 내려가, 팀이 나눠 쓰는 등불 기름이 떨어지기 전에 유물을 들고 돌아오는 협동 탐사 게임.**

게임의 기둥 3개 (기능을 넣을지 말지 고민될 때 이 셋에 맞는지 본다):

1. **빛은 공용 자원이다** — 기름 한 통을 팀이 같이 쓴다. 누가 얼마나 쓰는지가 곧 대화거리.
2. **어둠은 위험하지만 꼭 들어가야 한다** — 유물과 길은 늘 빛 밖에 있다.
3. **싸우지 않고 버틴다** — 무기 없음. 빛을 키우고, 피하고, 같이 붙어 다니는 것이 유일한 방어.

기둥 3 덕분에 전투·타격감·무기 에셋이 필요 없다 → 범위와 위험이 크게 준다.

## 2. 시점 결정: **1인칭**

| 비교 | 1인칭 | 3인칭 |
|---|---|---|
| 어둠의 긴장감 | 좋음 — 뒤가 안 보임 | 약함 — 카메라가 주변을 다 보여 줌 |
| 에셋·애니메이션 | 내 화면엔 손·등불만. 동료 모형은 단순 동작(걷기·들기·쓰러짐)만 | 내 캐릭터가 늘 보임 → 애니메이션 품질 요구가 큼 |
| ChatGPT 그래픽 적합성 | 캐릭터 모형 품질이 덜 드러남 | 캐릭터가 화면 중심이라 약점이 잘 보임 |
| 협동 소통 | 정찰꾼이 "어디 있어?"를 말로 설명해야 함 → 기둥 2에 맞음 | 서로 잘 보여서 설명할 필요가 줄어듦 |
| 단점 | 멀미, 내 빛 범위를 알기 어려움 | — |

**결정: 1인칭.** 단점 대책:
- 시야각(FOV) 설정 60~100 (기본 80), 화면 흔들림 끄기 옵션.
- 빛 반경은 바닥에 비친 빛 원으로 바로 보이게 하고, 화면 아래 **기름 게이지** 옆에 현재 밝기 단계를 아이콘으로 표시.
- 동료 위치는 동료가 든 빛이 벽에 비치는 것 + 화면 가장자리 작은 표시(같은 층, 15m 안)로 알 수 있게.

## 3. 첫 데모 범위 (6개월 규모 기준)

### 데모에 넣는 것

| 항목 | 데모 범위 |
|---|---|
| 층 | **지하 1~2층** (층마다 절차 생성) + 지상 캠프 |
| 직업 | **4개** (등불지기·정찰꾼·짐꾼·기술자). 혼자일 때는 **만능 대원** 1개 |
| 괴물 | **2종**: 그림자 추적자, 기름 도둑 |
| 유물 | **6종** (가벼운 것 3, 무거운 것 2, 목표 유물 1) |
| 함정 | 2종: 곰덫, 무너지는 바닥 |
| 캠프 | 상점(기름·도구 3종), 캠프 강화 3개, 엘리베이터 |
| 목표 | 2층 끝 제단의 **빛의 파편**을 들고 귀환 = 데모 클리어 |
| 인원 | 1~4인, 스팀 친구 초대 (로비에서만 참가) |
| 입력 | 키보드·마우스 + 게임패드 (Steam Deck) |
| 언어 | 한국어 / 영어 |
| 저장 | 캠프 진행(돈, 강화)만 저장. 원정 도중 저장 없음 |

### 데모에서 빼는 것 (정식판 후보)

| 뺀 것 | 이유 |
|---|---|
| 3~5층, '빛의 심장' 엔딩 | 콘텐츠 분량. 데모는 2층으로 재미 검증만 |
| 괴물 3·4종째 | AI·애니메이션 비용 |
| 정찰꾼 **손으로 지도 그리기** | UI·동기화 비용 큼 → 데모는 발광 분필 표식으로 대체 |
| 직업 성장·해금, 장비 강화 트리 | 밸런스 작업량. 데모는 직업 고정 능력만 |
| 원정 도중 참가(난입)·재접속 | 네트워크 위험. 연결이 끊긴 플레이어는 '쓰러짐' 처리 |
| 근접 음성 채팅 | 스팀 음성/디스코드로 대체 |
| AI 짐꾼 당나귀 | 혼자 플레이는 만능 대원 + 수치 조절로 해결 |
| 층 테마 여러 개 | 데모는 1층 '돌 지하실', 2층 '무너진 거리' 2테마만 |
| 함정 3종째 이상, 퍼즐 방 | 데모 이후 |

## 4. 한 판의 흐름

```
[캠프] 직업 선택·기름/도구 구입 (2~3분)
   ↓ 엘리베이터
[1층] 탐사 8~12분 → 유물 수집 → 계단방 찾기
   ↓  (돌아갈지 더 내려갈지 결정 ①)
[2층] 탐사 10~15분 → 제단에서 빛의 파편
   ↓  (돌아갈지 결정 ②: 기름 남은 양 보고)
[귀환] 층마다 시작방 엘리베이터로 캠프 복귀
   ↓
[정산] 유물 판매 → 돈 → 캠프 강화
```

- 한 판 목표 25~35분.
- **귀환**: 각 층 시작방의 엘리베이터에 팀 전원(쓰러진 동료는 들쳐 업어서)이 타면 캠프로 올라감. 2층에서 1층을 다시 지날 필요 없음 (엘리베이터는 층마다 지상 직통).
- **실패**: 팀 전원이 쓰러짐 → 원정 실패. 들고 있던 유물을 모두 잃어 그 판 수입은 0. 이미 가진 돈·캠프 강화는 유지.
- **데모 클리어**: 빛의 파편을 들고 귀환 1회.

## 5. 빛과 기름

### 5.1 빛을 내는 것

| 빛 | 누가 | 반경 | 기름 소모 | 비고 |
|---|---|---|---|---|
| **큰 등불** — 낮춤 | 들고 있는 사람 (팀에 1개) | 5 m | 2 / 분 | |
| **큰 등불** — 보통 | | 8 m | 4 / 분 | 기본값 |
| **큰 등불** — 키움 | | 12 m | 8 / 분 | 기름 도둑이 타 죽고 도망 |
| 큰 등불 — **섬광** | 등불지기만 | 16 m, 2초 | 1회 10 | 재사용 20초. 모든 괴물 '후퇴' |
| **손등** (작은 램프) | 큰 등불 안 든 사람 각자 | 3 m | 0.5 / 분 (켰을 때만) | 정찰꾼은 없음 |
| **설치 램프** | 기술자 (혼자일 땐 만능 대원) | 5 m, 90초 | 설치 1회 15 | 층마다 2회 (만능 대원 1회) |
| 기름 샘 | 방 종류 (6.2) | 4 m | — | 늘 켜져 있는 안전지대 |

- 큰 등불은 **아이템**이다. 누구나 들 수 있고 바닥에 내려놓을 수도 있다(내려놓아도 켜져 있고 기름은 계속 줄어듦).
- 등불지기가 들면 소모 **0.75배** + 섬광 사용 가능.
- 기름은 **팀 공용 수치 하나**. 모든 빛이 같은 통에서 빠진다.

### 5.2 기름 수치

| 항목 | 값 |
|---|---|
| 기름 최대치 | 100 (캠프 강화 '큰 기름통'으로 130) |
| 출발 기름 | 인원별 표 (5.4) |
| 줍는 기름병 | +15 |
| 기름 샘 (방) | 한 번 퍼 오기 +25, 샘당 1회 |
| 상점 기름병 | 1병 +15, 원정당 최대 3병 |
| 부활 비용 | 5 |

**기준 계산** (2인, 큰 등불 보통 + 손등 1개 계속 켬): 4 + 0.5 = 4.5/분 → 출발 100으로 약 22분. 줍는 기름(층당 평균 2병 = 30)을 더하면 약 29분 → 한 판 목표 25~35분에 맞음. 아끼면 2층을 넉넉히 볼 수 있고, 낭비하면 1층에서 돌아와야 한다.

### 5.3 기름이 떨어지면

1. 기름 20 이하: 등불이 깜빡이고 경고음. 큰 등불 최대 단계가 '보통'으로 제한.
2. 기름 0: 큰 등불·손등·설치 램프 모두 꺼짐. **심지 시간 60초** 동안 반경 2m 희미한 빛만 남음.
3. 심지까지 꺼지면: 완전한 어둠. 괴물 2종 모두 이동 속도 1.5배, 어둠 게이지 쌓이는 속도 2배. 엘리베이터까지 뛰어야 함.

### 5.4 어둠 게이지와 괴물 접근 규칙

플레이어마다 **어둠 게이지 0~100** 이 있다 (화면 가장자리가 점점 어두워지는 것으로 표시, 숫자는 안 보임).

| 상태 | 게이지 변화 |
|---|---|
| 빛 밖 (어떤 빛 반경에도 없음) | +4 / 초 (정찰꾼 +2 / 초) |
| 손등만 켠 상태 | +1 / 초 |
| 큰 등불·설치 램프·기름 샘 반경 안 | −10 / 초 |

괴물 접근 규칙 (호스트가 판정):
- **게이지 30 이상**인 플레이어는 그림자 추적자의 '추적 후보'가 된다. 후보가 여럿이면 게이지가 가장 높은 사람.
- **게이지 100**: 추적자가 같은 층에 있으면 무조건 그 플레이어에게 감 (거리 무시).
- 그림자 추적자는 **큰 등불·설치 램프·기름 샘 반경 안으로 들어오지 않는다.** 손등(3m)은 무시하고 들어온다.
- 빛 반경 안에 0.5초 이상 걸치면(빛이 다가와서 덮치면) '후퇴'.

### 5.5 쓰러짐과 부활

- 추적자에게 잡히거나 함정·낙하로 쓰러지면 **30초** 동안 '쓰러짐'. 그동안 기어서 천천히(1 m/s) 움직이고 말할 수 있음.
- 동료가 **큰 등불 반경 안**에서 3초 상호작용 → 부활 (기름 5, 체력 절반).
- 30초 안에 부활하지 못하면 '기절' → 엘리베이터로 데려가면 캠프에서 깨어남 (그 판에선 다시 못 일어남, 업혀 다님).
- **혼자일 때**: 한 판에 한 번 **'마지막 불씨'** — 쓰러지면 5초 뒤 자동 부활 (기름 15). 두 번째 쓰러짐 = 원정 실패.

## 6. 직업

이동 속도 기준: 걷기 4.0 m/s, 달리기 6.0 m/s (스태미나 5초, 회복 3초 쉬고 시작).

| 직업 | 장점 | 약점 | 고유 능력 |
|---|---|---|---|
| **등불지기** | 큰 등불 소모 0.75배 | 달리기 4.8 m/s, 짐 슬롯 1 | **섬광** (5.1) |
| **정찰꾼** | 걷기 4.5 / 달리기 7.0, 어둠 게이지 절반, 어둠 속 윤곽 시야 6 m | 손등 없음, 짐 슬롯 1 | **발광 분필**: 바닥·벽 표식 (층마다 8개, 빛 아님 → 괴물에 영향 없음, 모두에게 보임) |
| **짐꾼** | 짐 슬롯 4, 무거운 유물 혼자 들기 (2.5 m/s) | 들고 있으면 달리기 불가 | **던지기**: 들고 있는 유물·기름병을 8 m 던져 동료에게 |
| **기술자** | 함정 해제 2초, 잠긴 문 열기 4초 | — | **설치 램프** (5.1) |
| **만능 대원** (혼자 전용) | 짐 슬롯 3, 무거운 유물 혼자 들기 (2.5 m/s), 함정 해제 4초, 잠긴 문 6초 | 섬광 없음 | **설치 램프** 층마다 1회 |

- 직업이 아닌 사람: 짐 슬롯 2, 함정 해제 8초, 잠긴 문 못 엶 (기술자가 없으면 잠긴 방 안 열쇠 상자에서 '녹슨 열쇠'를 찾아야 함 — 6.2).
- 같은 직업 중복 선택 가능 (단, 섬광 재사용 시간은 팀 공유).
- 무거운 유물: 짐꾼·만능 대원이 아니면 **2명이 같이** 들어야 함 (같이 들면 3.0 m/s, 둘 다 손등 못 씀).

## 7. 괴물 (호스트 권한, 단순 상태 기계)

공통 규칙:
- 괴물은 **호스트에서만** 생각하고 움직인다. 클라이언트는 위치·상태·애니메이션 이름만 받아서 보여 줌.
- 판단은 **10 Hz** (0.1초마다), 위치 동기화는 **20 Hz** + 보간.
- 길찾기는 Godot `NavigationAgent3D`. 빛 반경 안은 추적자에게 '못 가는 곳'으로 취급 (매 판단마다 다음 지점이 빛 안이면 멈춤).
- 등장: 층 생성 시 '괴물 예산'(8.1)만큼 배치. 플레이어로부터 **방 2개 이상 떨어진** 방에만 생김. 같은 층 안에서 쓰러진 괴물이 다시 생기지는 않음 (괴물은 죽지 않으니 숫자가 늘지 않음).

### 7.1 그림자 추적자 (Stalker)

어둠 속을 기어다니는 키 큰 그림자. 플레이어를 잡아 쓰러뜨린다. 빛을 싫어한다.

| 상태 | 하는 일 | 다음 상태로 |
|---|---|---|
| **잠복** IDLE | 제자리. 3~8초 무작위 | 시간 끝 → 배회 / 추적 후보 20 m 안 → 추적 |
| **배회** WANDER | 가까운 방 무작위 지점으로 2.5 m/s | 도착 → 잠복 / 추적 후보 20 m 안 → 추적 |
| **추적** STALK | 대상에게 3.5 m/s. 빛 경계에선 멈추고 기다림 | 거리 1.5 m & 대상이 빛 밖 → 공격 / 대상 게이지 < 30 이 5초 → 배회 / 빛 0.5초 → 후퇴 |
| **공격** ATTACK | 0.8초 준비 동작(소리+눈 빛남) 후 잡기 | 준비 중 대상이 빛 안으로 → 후퇴 / 성공 → 대상 쓰러짐, 후퇴 |
| **후퇴** FLEE | 빛 반대 방향으로 5.0 m/s, 4초 | 끝 → 잠복 |

- 섬광을 맞으면 어느 상태든 즉시 후퇴 (8초).
- 공격 준비 0.8초는 **반응할 틈** — 동료가 등불을 들고 달려오면 구할 수 있다 (협동 순간).

### 7.2 기름 도둑 (Oil Leech)

빛 가장자리에 달라붙어 기름을 빨아먹는 작은 벌레 떼 (한 무리 = 모형 3~5마리를 한 덩어리로 움직임).

| 상태 | 하는 일 | 다음 상태로 |
|---|---|---|
| **잠복** IDLE | 벽에 붙어 있음 | 큰 등불·설치 램프 15 m 안 → 접근 / 바닥의 기름병 10 m 안 → 훔치기 |
| **접근** SEEK | 가장 가까운 큰 빛의 **가장자리**(반경 +0.5 m)로 3.0 m/s | 도착 → 흡수 |
| **흡수** DRAIN | 가장자리에 붙어 공용 기름 **−1 / 초** (무리마다) | 빛이 커져서 무리가 반경 안에 들어옴 → 후퇴 / 빛이 멀어짐 → 접근 |
| **훔치기** STEAL | 바닥 기름병으로 가서 2초 뒤 없앰 | 끝 → 잠복 |
| **후퇴** FLEE | 6초 동안 빛 반대쪽으로, 그 뒤 잠복 | — |

- 플레이어를 쓰러뜨리지 않는다. 대신 **기름을 둘러싼 결정**을 만든다: "키움(8/분)으로 쫓을까, 무시하고 빨리 지나갈까?"
- 큰 등불을 '키움'으로 올리면 반경이 8 → 12 m 로 커지면서 가장자리에 붙은 무리가 빛 안에 들어와 후퇴한다.

## 9. 절차 생성 규칙

목표: **시드 숫자 하나 + 생성기 버전 + 인원 수**만 있으면 모든 클라이언트가 똑같은 층을 만든다.

### 9.1 격자 규격

| 단위 | 크기 | 쓰임 |
|---|---|---|
| **타일** | 2 m × 2 m | 바닥·벽 조각의 기본 크기. 모든 에셋이 이 격자에 맞음 ([CHATGPT_PROMPTS.md](../art/CHATGPT_PROMPTS.md)) |
| **방 칸(슬롯)** | 12 m × 12 m = 6 × 6 타일 | 층 배치도의 한 칸 |
| 층 배치도 | 7 × 7 슬롯 | 방은 이 안에 놓임 |
| 천장 높이 | 4 m (벽 조각 2단) | |
| 문 | 슬롯 경계 가운데 2 m 타일 1개 | 방과 방이 문으로만 이어짐 |

### 9.2 방 종류

| 종류 | 크기(슬롯) | 층당 수 | 내용 |
|---|---|---|---|
| 시작방 | 1×1 | 1 | 엘리베이터. 늘 밝음(반경 6 m). 괴물 없음 |
| 통로 | 1×1 | 나머지 채움 | 좁은 길, 기둥, 잔해 |
| 일반방 | 1×1 또는 1×2 | 3~4 | 상자, 유물 0~1, 기름병 0~1 |
| 보물방 | 1×1 | 1~2 | 유물 2. 막다른 곳(곁가지 끝)에만 |
| 기름 샘 | 1×1 | 1 | 4 m 빛, 퍼 오기 1회. 주 경로 중간쯤 |
| 함정방 | 1×1 | 1~2 | 함정 2~4개 |
| 잠긴 방 | 1×1 | 0~1 | 문이 잠김. 안에 무거운 유물. 열쇠는 다른 방 상자에 |
| 계단방 / 제단방 | 1×1 | 1 | 1층: 아래로 가는 계단 / 2층: 빛의 파편 제단 |

방마다 **손으로 만든 방 틀(템플릿) 씬** 을 종류별로 2~4개 만들고, 생성기가 그중 하나를 고른다. 데모 목표 틀 수: 약 20개.

### 9.3 생성 순서

1. **주 경로**: 시작방을 배치도 가장자리 무작위 칸에 둔다. 무작위 걷기(위·아래·왼·오른, 이미 쓴 칸 금지)로 길이 `주경로길이 = 층당 방 수 × 0.6` (반올림) 만큼 이어 붙이고, 마지막 칸을 계단방/제단방으로.
2. **곁가지**: 주 경로의 시작·끝을 뺀 칸에서 무작위로 골라, 길이 1~2 곁가지를 방 수가 채워질 때까지 붙인다. 곁가지 끝 = 보물방 후보.
3. **고리(선택)**: 서로 붙어 있지만 이어지지 않은 칸 쌍 중 하나를 확률 30%로 문으로 연결 (도망칠 길).
4. **종류 정하기**: 위 표 규칙대로. 기름 샘은 주 경로 40~60% 지점, 함정방은 주 경로 위, 잠긴 방 열쇠는 잠긴 방보다 시작방에 가까운 방에.
5. **틀 고르기**: 종류별 틀 목록에서 무작위 + 회전(0/90/180/270°, 문 위치가 맞는 것만).
6. **물건 배치**: 틀 안에 미리 찍어 둔 '배치 지점'(유물·기름병·함정·괴물) 중에서 무작위로 고름.
7. **검증**: 시작방에서 계단방까지 길이 있는지, 필요한 방 종류 수가 맞는지 확인. 실패하면 `시드 + 1` 로 다시 (최대 10번, 그래도 실패면 오류 기록 + 미리 만든 비상용 배치도 사용).

### 9.4 같은 결과를 보장하는 규칙 (개발팀 필독)

- 생성에는 **전용 `RandomNumberGenerator` 하나**만 쓰고 `seed` 를 직접 넣는다. 전역 `randi()`/`randf()`, 시간, 물리 결과, 프레임 수를 쓰지 않는다.
- 무작위를 뽑는 **순서를 고정**: 위 1~7 단계 순서대로, 각 단계 안에서도 배치도 칸을 (y, x) 순으로 훑는다. 딕셔너리는 넣은 순서를 쓰거나 키 정렬 후 순회.
- 층 시드 = `원정 시드 × 31 + 층 번호` (원정 시드는 호스트가 원정 시작 때 정해서 보냄).
- 생성기 코드를 바꾸면 **생성기 버전 숫자**를 올린다. 접속할 때 버전이 다르면 참가 거부.
- 생성 결과로 **배치도 해시**(방 종류·틀·회전·물건 배치를 문자열로 이어서 해시)를 만들어, 클라이언트가 호스트에 보내 비교. 다르면 오류 표시 후 로비로.
- QA 자동 테스트 후보: "같은 시드 → 같은 해시", "시드 1000개 생성해서 모두 검증 통과" (QA에 별도 요청 예정).

## 12. 네트워크 개요

- 방식: **호스트(방장) 권한**. 스팀 로비 + GodotSteam 피어(세부 방식은 개발팀 결정).
- 호스트만 정하는 것: 원정 시드, 공용 기름 수치, 괴물 AI, 함정 발동, 유물 줍기 판정(동시에 줍기 다툼 → 호스트 먼저 받은 사람), 부활·쓰러짐, 엘리베이터 출발.
- 각 클라이언트가 보내는 것: 내 위치·시선 (20 Hz), 손등 켬/끔, 상호작용 요청.
- 빛 반경 판정(어둠 게이지)은 **호스트가 계산** (빛 위치·반경을 다 알고 있으므로). 클라이언트는 화면 연출만.
- 층 자체는 시드로 각자 만들고, 이후 바뀌는 것(문 열림, 주운 물건, 해제한 함정)만 이벤트로 보냄.

## 13. 개발팀 첫 시제품 목표 (하나)

> **"어두운 방 3개에서, 2인이 큰 등불 하나와 공용 기름을 나눠 쓰고, 그림자 추적자 1마리가 빛 밖의 플레이어에게 다가와 잡는다."**

임시 모형(상자·캡슐)으로, 스팀 연결 대신 **로컬 ENet 접속(같은 PC 두 창)** 으로 먼저 해도 됨.

완료 조건 (QA·기획팀이 직접 해 보고 확인):
1. 손으로 배치한 방 3개(2 m 타일, 문으로 연결). 절차 생성은 아직 안 함.
2. 2인 접속. 둘 다 1인칭 이동·달리기.
3. 큰 등불 1개: 줍기·내려놓기·건네기, 밝기 3단계(5/8/12 m). 손등 켬/끔.
4. 공용 기름 수치가 두 화면에 똑같이 줄어듦 (5.1 수치), 0이 되면 꺼짐 + 심지 60초.
5. 어둠 게이지(호스트 계산)와 그림자 추적자 상태 기계(7.1) 전체: 빛 경계에서 멈춤, 빛 밖 플레이어에게 다가가 0.8초 준비 후 잡음, 빛을 비추면 후퇴.
6. 쓰러짐 → 동료가 등불 반경 안에서 3초 → 부활.
7. 수치는 리소스 파일 하나에서 읽음 (10장).

이 시제품으로 확인하려는 질문: **"등불 하나를 나눠 쓰는 것만으로 긴장되고 재밌는가?"** — 재미가 없으면 데모 범위를 늘리기 전에 기획팀이 빛·기름 규칙을 다시 짠다.

## 14. 개발 단계 (날짜 대신 완료 조건)

출시 시점은 정하지 않는다 (넥스트 페스트 등 외부 일정에 맞추지 않음). 각 단계는 **완료 조건을 모두 만족하고 사람 대표가 직접 플레이해 재미를 확인해야** 다음 단계로 넘어간다. "6개월"은 규모를 잡는 기준일 뿐 마감이 아니다.

### 단계 1. 시제품 — "등불 하나를 나눠 쓰는 게 재밌는가?"

| 부서 | 할 일 |
|---|---|
| 개발 | 13장 시제품 |
| 기획 | 플레이 테스트 → 빛·기름 수치 수정, 실패 패널티 결정(15장), 방 틀 설계 시작 |
| QA | 헤드리스 실행·CI, 시제품 완료 조건 7개 확인 |

**완료 조건**: 13장 완료 조건 7개 통과 + 2인 플레이 테스트 3판 이상 + 사람 대표가 "재밌다(계속 간다)" 판정. 아니면 빛·기름 규칙을 고쳐 단계 1 반복.

### 단계 2. 수직 단면 — "한 판이 처음부터 끝까지 돌아가는가?"

1층 하나로 한 판 전체(캠프 → 1층 → 귀환 → 정산)를 데모 품질에 가깝게 만든다.

| 부서 | 할 일 |
|---|---|
| 개발 | 절차 생성(9장), 스팀 로비·친구 초대, 직업 4개 + 만능 대원, 기름 도둑, 캠프·정산, 그래픽 교체 1차(P0 에셋) |
| 기획 | 1층 방 틀 약 10개, 유물·함정 규칙, 직업 밸런스, ChatGPT P0 에셋 받기·검수 |
| QA | 생성 결정성 테스트(9.4), 스팀 2~4인 접속 테스트 |

**완료 조건**:
- 1인·2인·4인 각각 한 판을 끝까지 플레이 가능 (원정 성공·실패 둘 다)
- 같은 시드 → 모든 클라이언트 같은 배치도 해시, 시드 1000개 검증 통과
- 스팀 친구 초대로 2인 이상 원정 완주
- 임시 모형이 아닌 P0 그래픽으로 1층 표시
- 사람 대표 플레이 테스트 통과

### 단계 3. 데모 — "남에게 보여 줄 수 있는가?"

3장 데모 범위 전체.

| 부서 | 할 일 |
|---|---|
| 개발 | 2층·제단·빛의 파편, 한/영, 게임패드·Steam Deck, 다듬기 |
| 기획 | 2층 방 틀, 튜토리얼, 문구(한/영), P1 에셋, 스토어 문구 |
| QA | 1~4인 전체 플레이 테스트, Windows/Linux/Steam Deck 확인, 출시 전 점검 |

**완료 조건**:
- 3장 '데모에 넣는 것' 전부 동작
- 1~4인 모두 데모 클리어(빛의 파편 귀환) 가능
- 치명 버그(진행 불가·접속 끊김 후 멈춤) 0건
- 사람 대표가 출시 시점 결정
