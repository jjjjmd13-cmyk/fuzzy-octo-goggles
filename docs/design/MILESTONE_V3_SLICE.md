# 멍냥 목욕탕 V3 — 수직 단면 (하루 영업 한 판 + 3일)

작성: 기획팀 · 2026-10-26 · 근거: [GDD_V3.md](GDD_V3.md) 0.3, [TUNING_V3.md](TUNING_V3.md)
사람 대표 결정: 작은 시제품마다 테스트하지 않고, **"하루 영업 한 판"이 완성된 상태**까지 만든 뒤 플레이한다.

> 개발팀은 아래 체크리스트를 그대로 PR 설명에 복사해서 채워 주세요. **모든 칸 ✅ + QA 첫 플레이 통과**가 되면 사람 대표에게 넘깁니다.

## 0. 한 줄

**메인 메뉴 → 1일차 영업(약 8분, 주인 손님 4~6명) → 정산 → 컴퓨터 쇼핑 → 2일차 → 3일차 → 저장하고 끄고 다시 켜서 이어하기**가 막힘 없이 된다.

## 1. 하루 영업

- [ ] 하루 = 영업 약 8분 (`day_open_minutes_real` 8). 화면 위에 **벽시계**(9시 → 6시, 숫자 없이 바늘)
- [ ] 주인 손님이 **차례로** 들어옴: 1일차 4명 · 2일차 5명 · 3일차 6명 (한 명 약 1분 반 = 목욕 65초 + 맞이·돌려주기)
- [ ] **대기열**: 대기 의자 3개. 꽉 차면 문밖에 줄. 기다림은 **주인 몸짓**으로 보임 (시계 보기 → 발 구르기 → 시무룩). 너무 오래면 떠남 (그날 그 손님 0원)
- [ ] **접수**: 주인 말풍선 그림(요청) → 요청 카드로 바뀌어 목욕대 옆 집게에 걸림 (GDD_V3 3.3·3.5)
- [ ] 6시가 되면 새 손님은 안 옴. 목욕 중인 손님은 끝까지 할 수 있음
- [ ] 끝나면 주인 반응 3종 + 동전 건넴 + 강아지가 주인에게 달려감 (GDD_V3 3.5)

## 2. 손동작 6단계 + 한 손 조작 (GDD_V3 3.1·2장)

- [ ] 적시기: 누르고 조준, 물줄기 보임, 휠 = 온도
- [ ] 샴푸 짜기: 누르는 시간 = 양, 너무 많으면 넘침
- [ ] 문지르기: 원 그리기 (왕복은 거의 안 큼)
- [ ] 헹구기: 바가지 위→아래 쓸어내리기
- [ ] 수건: 꾹꾹 연타, 물방울이 줄어듦
- [ ] 드라이어: 휠로 거리, 털 날림
- [ ] 같은 손동작이 두 단계에 쓰이지 않음. 각 단계 10~20초 (TUNING_V3 8장 `stage_target_seconds`)
- [ ] 도구 자동, 강아지 자동 회전, **마우스 하나로 하루 끝까지** (오른쪽 버튼·키보드 없이). 패드도 됨

## 3. 손님 2종 · 성격 2개

| | 무엇이 다른가 | 열리는 날 |
|---|---|---|
| **강아지** | 기본 | 1일차 |
| **고양이** | 물을 싫어함: 온도 '좋음' 범위가 좁음(`[0.45, 0.6]`), 젖어 있는 시간이 길면 기분 −, 바가지를 머리에 쏟으면 크게 싫어함. 대신 요금 높음 | **2일차** |
| **간지럼쟁이** 🪶 | 배·발을 문지르면 금방 다리 찰랑 → 등부터 해야 함 | **2일차** |
| **겁쟁이** 💧 | 온도 '좋음' 범위가 더 좁음, 얼굴에 물이 닿으면 크게 싫어함 | **3일차** |

- [ ] 고양이 모형 (임시 장난감 모형, 강아지와 같은 부품 방식: 귀·꼬리 따로 움직임)
- [ ] 성격은 요청 카드 구석의 작은 그림으로 보임
- [ ] 1일차 = 강아지만, 성격 없음 (배우는 날)

## 4. 정산 → 쇼핑 → 다음 날

- [ ] **정산 화면**: 받은 손님 수 · 떠난 손님 수 · 번 돈 (요금 + 팁) · 오늘 가장 기뻐한 손님 얼굴 하나
- [ ] **컴퓨터 쇼핑** (화면 하나, 탭 없이 4칸):

| 물건 | 값 | 효과 |
|---|---|---|
| 기본 샴푸 | 20 | 8마리분. 다 쓰면 거품이 안 남 |
| 복숭아 샴푸 | 60 | 8마리분, 분홍 거품, 복숭아 요청 손님 팁 + |
| **넓은 샤워기** (도구 업그레이드 1) | 150 | 적시기·헹구기 붓 반경 1.5배 → 한 마리가 빨라짐 |
| **창가 화분** (꾸미기 1) | 80 | 가게에 화분이 생김 + 주인 기다림이 조금 길어짐 (떠나기 전 시간 +20%) |

- [ ] 1일차 수입 약 150~200 → 2일차 아침에 **업그레이드냐 꾸미기냐 샴푸냐** 고민이 생기는 값 (TUNING_V3 에 `slice_*` 로 확정)
- [ ] 산 업그레이드·꾸미기가 다음 날 **눈에 보임** (샤워기 머리 모양이 바뀜, 화분이 놓임)
- [ ] "다음 날" 버튼 → 아침 화면 (오늘 새로 열린 것 알림: "고양이 손님이 오기 시작했어요!") → 영업 시작

## 5. 3일 진행 · 저장

- [ ] 1→2→3일차 진행, 날마다 새 것 하나 (2일차: 고양이 + 간지럼쟁이, 3일차: 겁쟁이)
- [ ] 3일차 정산 뒤: "수직 단면은 여기까지! 고마워요" 화면 → 메뉴로 (그 뒤 날은 없음)
- [ ] **자동 저장**: 정산이 끝날 때마다 (돈 · 날짜 · 산 물건 · 남은 샴푸). 영업 도중에는 저장 안 함
- [ ] 메인 메뉴에 **이어하기 / 새로 하기**. 끄고 다시 켜서 이어하기가 됨
- [ ] 협동: 이번 단면은 **혼자 하기만 검사**. 2인 접속이 깨지지 않을 정도만 유지 (자리마다 한 사람 구조, GDD_V3 7장)

## 6. 기본 연출

- [ ] 효과음: 단계마다 (쏴아·뿌직·뽀글·촤아악·꾹·위잉), 완료 "딩", 동전 "짤랑", 주인 반응, 손님 들어올 때 문 종 "딸랑"
- [ ] 파티클: 물줄기·튀는 물, 거품 공, 바가지 물 쏟기, 물방울, 드라이어 털 날림
- [ ] 반응 애니메이션: 펄쩍, 다리 찰랑, 몸 털기, 볼 펄럭, 주인 쪽 보기, 주인에게 달려가기, 주인 반응 3종
- [ ] 배경음악 1곡 (영업 중) + 짧은 곡 1개 (정산). **CC0 무료 곡 또는 코드로 합성** — 쓴 곡의 출처·라이선스 파일을 같이 넣음. 돈 드는 것 금지
- [ ] 음량 설정 (효과음 / 음악) 메뉴에

## 7. 처음 하는 사람용 안내

- [ ] 1일차 첫 손님에서만, 단계가 바뀔 때 **손동작 그림 힌트** 1장씩 (예: 원 그리는 손 그림). 글자는 한 줄 이하
- [ ] 첫 정산 뒤 컴퓨터 자리로 가라는 화살표 한 번
- [ ] 메뉴 → 1일차까지 클릭 2번 이내, 설명 화면 없이 시작
- [ ] 막히면 쓰는 F1 도움말 (조작 그림 한 장)

## 8. 그림 넣을 자리 (사람 대표 ChatGPT 그림)

- [ ] 교체 지점이 한 곳씩 정해져 있고 `docs/dev/` 에 표로 정리: 도구 아이콘 4 · 요청 카드 · 말풍선 아이콘 · 기분 얼굴 3 · 동전 · **가게 간판**(메뉴 + 가게 벽) · **목욕대 뒤 배경 그림** · 주인 6명(판자 그림) · 꾸미기 화분
- [ ] 그림이 아직 없으면 지금 임시 그림으로 그대로 동작
- [ ] 그래픽 주문서는 대표 세션 문서(`docs/art/ORDER_V3.md`)를 따름

## 9. 넘기기 전 조건 (QA)

- [ ] **QA 가 '처음 하는 사람' 시점으로 한 번 전체를 돌려 봄**: 깨끗한 설치(저장 파일 없음)에서 메뉴 → 1~3일차 → 끄고 이어하기 → 끝 화면. Windows 빌드로.
- [ ] QA 기록 (`docs/qa/` 에): 걸린 시간 (하루 몇 분), **막힌 곳·헷갈린 곳**, 버그
- [ ] **막힘(진행 불가) 0건, 튕김 0건**. 헷갈린 곳은 고치거나 대표에게 알림
- [ ] 자동 테스트 전부 통과 (기존 + 하루 흐름·저장/불러오기·쇼핑)

## 10. 이번 단면에 넣지 않는 것

가게 확장(목욕대 2대째·2층), 빗질·다듬기·리본, 동물 3종째 이상, 성격 3개째 이상, 사건(탈출·정전 등), 단골 주인, 가게 레벨, 엔딩, 협동 검사, 영어 문구(한국어만, 단 문구는 번역 키로).
