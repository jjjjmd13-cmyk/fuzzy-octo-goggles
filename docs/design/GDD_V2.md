# 멍냥 목욕탕 (가제: *Paws & Bubbles*) — 상세 기획서

작성: 기획팀 · 2026-10-26 · 판: 0.1 · 근거: [CONCEPTS_V2.md](CONCEPTS_V2.md) A안 (대표 선택 2026-10-26)
수치: [TUNING_V2.md](TUNING_V2.md) · 그래픽 요청문: [CHATGPT_PROMPTS_V2.md](../art/CHATGPT_PROMPTS_V2.md)

> 등불 원정대에서 배운 것: **목표는 1분 안에 보이게, 상태는 숫자 대신 모양·색·소리로, 위험은 눈에 보이는 것만.** 이 문서의 모든 규칙이 이 세 가지를 지킨다.

---

## 1. 한 줄과 기둥

**진흙투성이 동물 손님을 씻기고, 말리고, 빗겨서 주인에게 돌려보내는 협동 목욕탕. 젖은 손님은 내려놓으면 도망간다.**

1. **보면 안다** — 손님 머리 위 그림 = 할 일. 동물 모양 = 지금 상태. 설명 문구 없이 시작 가능.
2. **손님은 살아 있다** — 재료가 아니라 동물. 도망가고, 몸을 털고, 화를 낸다 → 웃긴 장면이 저절로.
3. **바쁜 손, 짧은 판** — 한 판 4~6분, 실패해도 바로 다시.

## 2. 카메라: **위에서 비스듬히 보는 고정 카메라** (스테이지마다 한 화면)

- 가게 전체가 한 화면에 보여서 **모두가 같은 상황을 본다** (등불 원정대의 "안 보여서 모르겠다" 반대).
- 내 캐릭터·동물 상태·기계가 다 보이니 말로 "저기 고양이 도망간다!" 가 바로 됨.
- 캐릭터 애니메이션이 작게 보여서 ChatGPT 그래픽 품질 부담이 적음.
- 지금 기반의 3인칭 따라가는 카메라는 쓰지 않음 (개발팀: 카메라만 교체).

## 3. 기본 규칙 (모든 스테이지 공통)

### 3.1 손님 한 마리의 흐름

```
입구 등장 → (대기석에서 기다림) → [욕조] 진흙 → 거품 → 젖음
         → [드라이어] 젖음 → 뽀송 → (스테이지에 따라 [빗질대] → [리본대])
         → 출구 문의 주인에게 → 완료 (동전 + 하트)
```

| 상태 | 모양 (보면 아는 것) | 소리 |
|---|---|---|
| 진흙 | 갈색 얼룩, 파리 한두 마리 | 철퍽 |
| 거품 (욕조 안) | 거품에 덮여 머리만 보임, 비눗방울 | 뽀글뽀글 → "펑" (끝) |
| 젖음 | 털이 납작, 색이 진함, 물방울 뚝뚝 | 뚝뚝 |
| 뽀송 | 털이 동그랗게 **두 배로 부풀어 오름** | "뽀옹!" |
| 빗질 끝 | 반짝이 효과 | 샤랑 |
| 리본 | 머리에 리본 | 딸랑 |

- 손님 머리 위 **말풍선**에 남은 단계가 그림으로 줄 서 있음 (🛁 💨 🪮 🎀). 하나 끝나면 그림이 '톡' 하고 빠짐.
- **기다림 = 하트 3개.** 시간이 지나면 하트가 하나씩 비고, 마지막 하트는 깜빡임. 다 비면 손님이 "흥!" 하고 나감 (그 손님 실패). 숫자는 안 보임.

### 3.2 젖은 손님은 도망간다 (이 게임의 웃음)

- 젖은 동물을 바닥에 내려놓으면 **몸을 한 번 털고(주변에 물 튀김) 뛰어다닌다.**
- 지나간 자리에 **물웅덩이**가 생김 → 밟으면 미끄러져 주욱 밀려남 (잠깐 조작 불가).
- 잡으면(다가가서 들기) 다시 얌전해짐. 드라이어까지 들고 가면 됨.
- 진흙 상태·뽀송 상태는 내려놓아도 그 자리에 앉아 있음. **"젖었을 때만 도망"** — 규칙이 하나라 바로 배움.

### 3.3 플레이어가 하는 것

| 동작 | 키보드 | 게임패드 |
|---|---|---|
| 이동 | WASD | 왼쪽 스틱 |
| 들기 / 내려놓기 / 기계에 넣기 / 꺼내기 | Space | A |
| 대시 (짧게 빨리) | Shift | X |
| 감정 표현 (손 흔들기, 놀리기 — 웃음용) | E | Y |

- 손에는 **한 번에 하나** (동물 한 마리 또는 물건 하나).
- 기계: 넣으면 저절로 돌아감, 다 되면 "띵!" + 기계 위 말풍선에 체크. 다 된 동물은 기계 안에서 기다림 (오래 두면 하트가 줄어듦).
- 플레이어끼리 부딪힘 (살짝 밀림). 같은 동물은 한 사람만 들 수 있음.

## 4. 첫 시제품 (1~2주)

> **"방 하나에서, 강아지가 30초마다 들어오고, 욕조·드라이어로 씻기고 말려서 출구로 보낸다. 젖은 강아지를 내려놓으면 도망가서 잡으러 뛰어다닌다."**

확인하려는 질문 하나: **"도망가는 젖은 강아지를 잡으러 뛰어다니는 게 웃긴가? 둘이 하면 자연히 역할이 나뉘는가?"**

### 4.1 범위

| 넣는 것 | 빼는 것 (다음 반복) |
|---|---|
| 방 하나 (가로 8 × 세로 6 타일 = 16 × 12 m), 고정 카메라 | 여러 스테이지, 지역 지도 |
| 강아지 1종 (상태 4: 진흙·거품·젖음·뽀송) | 다른 동물, 대형견 |
| 욕조 1, 드라이어 1, 입구, 대기석 3자리, 출구 문 | 빗질대, 리본대, 가게 꾸미기 |
| 하트 3개 기다림, 화나서 나감 | 동전·팁·상점 |
| 도망 + 물웅덩이 + 미끄러짐 | 던지기 |
| 영업 3분 → 결과 화면 (보낸 수, 별 1~3) → 다시 | 저장 |
| 1인 (오프라인 호스트) / 2인 (ENet), 인원별 손님 간격 | 3·4인 (기반은 되지만 시제품 테스트는 1·2인) |
| 효과음 7개 (3.1 표) — **무료(CC0) 임시 소리** 또는 직접 만든 삑삑 소리 | 배경 음악 |
| 시작 안내 한 줄 + 결과 화면 | 튜토리얼 |

### 4.2 완료 조건 (QA·기획팀이 직접 해 보고 확인)

1. 방 하나, 위에서 보는 고정 카메라. 1인·2인 모두 캐릭터가 화면 안에서 움직임.
2. 강아지가 정해진 간격(인원별)으로 입구에 들어와 빈 대기석에 앉음. 대기석이 꽉 차면 입구 밖에서 줄 섬(보이게).
3. 들기·내려놓기·기계에 넣기·꺼내기. 욕조 4초 → 젖음, 드라이어 3초 → 뽀송. 모양이 상태마다 확실히 다름 (임시 모형이면 **색 + 크기**: 갈색 → 흰 거품 구 → 진한 파랑 → 흰색 1.6배).
4. 머리 위 말풍선(🛁 💨)과 하트 3개. 하트가 다 비면 화내고 나감.
5. 젖은 강아지를 내려놓으면: 몸 털기(0.5초) → 뛰어다님 (방향 무작위, 벽에 닿거나 2초마다 방향 바꿈) → 물웅덩이 남김 → 밟으면 미끄러짐. 잡으면 멈춤.
6. 뽀송 강아지를 출구 문에 데려가면 완료 + 카운트 + "띵" 소리.
7. 영업 3분 뒤 결과 화면: 보낸 수 / 화나서 나간 수 / 별 1~3 → 아무 키로 다시 시작.
8. 동물·기계·웅덩이·영업 시간은 **호스트 권한**, 2인 화면이 같음.
9. 모든 수치는 리소스 한 곳 (TUNING_V2.md 키 이름 그대로).
10. 효과음 7개가 상태 변화마다 남 (임시 소리라도 꼭 있어야 함 — "효과가 안 보인다" 재발 방지).

### 4.3 시작 안내 (판 시작 3초, 화면 위쪽)

- 한국어: **"더러운 손님을 씻기고(🛁) 말려서(💨) 출구로! 젖은 손님은 도망가요."**
- English: **"Wash (🛁) and dry (💨) the muddy guests, then take them to the exit! Wet guests run away."**

### 4.4 시제품 다음

PLAYTEST 질문지는 시제품이 나오면 V2 용으로 새로 씀 (질문 수는 등불 원정대처럼 8~10개, 5분 안에 답).

## 5. 플레이 타임 설계 (스팀 환불 기준)

**스팀 환불**: 구매 후 14일 이내 + 플레이 2시간 미만이면 조건 없이 환불.
그래서 두 가지를 동시에 맞춘다.

- **A. 처음 2시간 안에 "계속하고 싶다"가 확실히** — 해금이 5~10분마다 하나씩, 2시간 전에 큰 변화 하나.
- **B. 2시간에 "다 봤다"가 아니도록** — 첫 클리어(모든 스테이지 별 1개 이상) **4~6시간**, 별 전부 **10시간 이상**.
- **같은 판 반복으로 늘리지 않는다.** 시간은 ① 새 스테이지 ② 새 규칙·동물·기계 ③ 별 3개·도전 과제로만 늘린다.

### 5.1 전체 구조

| 지역 | 스테이지 | 새로 나오는 것 | 지역 해금 조건 |
|---|---|---|---|
| 1. 동네 목욕탕 | 6 + 대목날 1 | 강아지 · 고양이 · 오리 / 욕조 · 드라이어 · 빗질대 · 리본대 / 가게 꾸미기 | 처음부터 |
| 2. 바닷가 지점 | 6 + 1 | 모래투성이(털기 기계) · 꽃게(집게로 꼬집음) · **대형견(2인 들기, 혼자는 느림)** | 별 7개 |
| 3. **목욕 버스** | 6 + 1 | **가게가 달리는 버스 안**: 커브마다 바닥이 기울어 동물·물건·사람이 미끄러짐 · 정류장마다 손님이 우르르 | 별 14개 |
| 4. 눈 마을 온천 | 6 + 1 | 얼음 바닥 · 떨고 있는 손님은 **먼저 데우기** (순서가 바뀌는 규칙) · 펭귄 (스스로 물에 들어감) | 별 21개 |
| 5. 반짝 펫 쇼 | 6 + 1 | 쇼 무대: 손님마다 원하는 꾸미기 조합 (리본 색·모자) · 마지막 대회 = 엔딩 | 별 28개 |
| **합계** | **35** | 동물 9종, 기계 8종 | |

- **대목날** (지역마다 마지막 1개): 손님 두 배 + 특별 손님 1마리 (아주 큰 개, 고양이 왕 등). 깨면 다음 지역 + 꾸미기 세트.
- 해금 조건 = 그 전 지역 스테이지 수만큼 별 → **별 1개씩만 따도 다음 지역이 열림** (막혀서 그만두는 일 없음).
- 별 기준: ★1 목표 손님 수, ★2 더 많이, ★3 더 많이 + 화나서 나간 손님 0. 인원별로 목표가 다름 (TUNING_V2.md).

### 5.2 해금 곡선 — 처음 2시간 (혼자 하기 기준, 분은 누적 플레이 시간)

| 분 | 무엇 | 왜 계속하고 싶은가 |
|---|---|---|
| 0 | 1-1: 강아지 · 욕조 · 드라이어 | 30초 안에 첫 손님을 보냄 |
| ~8 | 1-2: **빗질대** | 새 기계, 단계 하나 더 |
| ~15 | 1-3: **고양이** (물을 싫어해서 욕조에서 한 번 뛰쳐나옴) | 새 동물, 새 소동 |
| ~22 | **가게 꾸미기 해금** (첫 동전으로 간판·바닥 색·직원 모자) | 내 가게가 생김 |
| ~29 | 1-4: **리본대** (리본을 달면 팁 두 배, 선택) | 욕심낼 것이 생김 |
| ~37 | 1-5: **오리** (물을 좋아해서 욕조에서 안 나오려 함) | 고양이와 반대 — 웃음 |
| ~45 | 1-6: 비 오는 날 (입구에서 손님이 다시 더러워짐) | 첫 '규칙 변주' |
| ~55 | **1-대목날**: 손님 두 배 + 커다란 털뭉치 개 | 첫 큰 판, 지역 1 끝 |
| ~62 | **지역 2 바닷가 지점** — 새 배경·음악 | 새 장소 |
| ~70 | 2-1: 모래투성이 손님 → **털기 기계** | |
| ~80 | 2-2: **대형견** (2인 들기, 혼자는 느리게 끌기) | 협동의 맛이 커짐 |
| ~90 | 2-3: 꽃게 (가만두면 다른 손님을 꼬집어 화나게 함) | |
| ~100 | 2-4 ~ 2-6, 꾸미기 세트 2 | |
| **~112** | **2-대목날 → 지역 3 '목욕 버스' 공개** (예고 영상처럼 버스가 출발) | **2시간 전에 가장 큰 변화**: 가게가 움직이고 기운다 |
| ~120 | 3-1: 첫 커브에서 모두 미끄러짐 | "이건 해 봐야 한다" 지점 |

- 4인은 같은 해금이 조금 빨리 옴 (약 0.85배 시간). 4인 기준으로도 '목욕 버스'가 **2시간 안**에 나오게 지역 1·2 스테이지 길이를 정함.
- 2시간 안에 새 동물 6종(강아지·고양이·오리·털뭉치·대형견·꽃게) 중 5~6종, 새 기계 5종, 새 지역 2개, 꾸미기 해금을 보게 됨 — **하지만 전체 35 스테이지 중 14개(40%)** 만 본 상태.

### 5.3 플레이 타임 표

한 번 도전 = 영업 4~5분 + 준비·결과 1분 ≈ **6분**. '도전 횟수'는 평균 몇 번 해야 그 목표를 이루는지(추정, 시제품·플레이 테스트로 고침).

| 목표 | 계산 | **혼자 하기** | **4인** |
|---|---|---|---|
| 첫 2시간 지점 | — | 지역 2 끝 · 목욕 버스 공개 (14/35 스테이지) | 지역 3 초반 (16/35) |
| **첫 클리어** (35개 모두 별 1개 이상, 엔딩) | 35 × 6분 × 도전 1.4회(혼자) / 1.25회(4인) + 지도·꾸미기 10% | **약 5.4시간** | **약 4.8시간** |
| 별 2개 전부 | + 남은 도전 | 약 8시간 | 약 7시간 |
| **별 3개 전부** (105개) | 35 × 6분 × 도전 3.0회 / 2.6회 + 10% | **약 11.5시간** | **약 10시간** |
| 도전 과제 전부 (아래 5.4) | + 약 2~3시간 | 약 14시간 | 약 12.5시간 |

- 4인이 빠른 이유: 손이 많아 첫 시도에 별을 따기 쉬움. 대신 소동이 커서 별 3개는 혼자보다 조금만 빠름.
- 혼자 하기가 너무 오래 걸리지 않게: 손님 수·간격·기계 자동화로 인원별 조절 (TUNING_V2.md 4장).

### 5.4 반복이 아닌 '변주'로 늘리기

- **스테이지 변주** (같은 가게 구조 반복 금지): 지역마다 가게 구조 6개가 모두 다름 (회전문, 2층 계단, 컨베이어, 좁은 복도, 미끄러운 타일, 움직이는 버스 등).
- **도전 과제 30개** (스팀 업적과 같음): "한 판에 웅덩이에 10번 미끄러지기", "화난 손님 0으로 대목날 깨기", "대형견을 혼자 끌어서 보내기" 등. 다른 방식으로 플레이하게 만드는 것만.
- **손님 도감**: 동물 9종 × 꾸미기 변형. 처음 씻긴 손님이 도감에 사진으로 남음 (모으는 재미).
- **하지 않는 것**: 같은 스테이지 반복 보상(파밍), 긴 대기 시간, 에너지 제한, 무작위 뽑기.

## 6. 인원별 조절 (원칙, 숫자는 TUNING_V2.md)

## 7. 네트워크 (지금 기반 재사용)

- 호스트 권한, 최대 4인, 혼자 하기 = 오프라인 호스트 (기반 그대로).
- 호스트가 정하는 것: 손님 등장·상태·도망 경로, 기계 타이머, 웅덩이 생성·사라짐, 하트, 영업 시간, 별 계산.
- 클라이언트가 보내는 것: 이동 입력, "들기/넣기" 요청 (등불 시제품의 줍기·건네기 구조를 그대로 다시 씀).
- 동시에 움직이는 동물 최대 8마리 → 위치 20 Hz + 보간이면 충분.
- 목욕 버스(지역 3)의 기울기: 실제 물리 회전이 아니라 **바닥 기울기 값 하나를 호스트가 정하고, 그 방향으로 미는 힘**만 모두에게 적용 (동기화가 쉬움).

## 8. 데모 범위 (나중 단계, 참고)

지역 1 전체 (7 스테이지) + 지역 2 맛보기 2 스테이지 → 약 60~80분. 데모 끝 화면에 "목욕 버스" 예고.
(데모는 무료라 환불과 상관없지만, 정식판 첫 2시간 구성과 같은 흐름을 보여 줌)

## 9. 열린 질문 (대표 결정 필요)

1. 던지기 (동물을 던져 건네기 — 오버쿡드식): 웃기지만 '동물을 던진다'는 느낌이 귀여운 분위기와 맞는지. 기획팀 의견: **넣지 않음** (대신 '미끄럼 보내기': 바닥에 내려놓고 밀면 비누 거품 위로 주욱 미끄러져 감). 시제품 다음에 결정.
2. 게임 이름: 가제 '멍냥 목욕탕 / Paws & Bubbles' 로 계속 갈지 (스팀 페이지 전까지 결정).
