# 멍냥 목욕탕 — 첫 시제품 플레이 테스트지

작성: 기획팀 · 2026-10-26 · 대상: GDD_V2 4장 첫 시제품 (PR #24) · 답하는 사람: 사람 대표

**알고 싶은 것 세 가지**
1. 젖은 강아지가 도망가는 게 **웃긴가?**
2. 처음 1분에 **할 일을 알았나?**
3. 2인일 때 **역할이 자연스럽게 나뉘었나?**

---

## 진행 방법 (10~15분)

1. **혼자 1판** (설명 없이 바로 시작 — 시작 안내만 보고) → **2인 2판** (친구, 또는 같은 PC 창 두 개).
2. 한 판 = 영업 3분. 판 사이에 메모 한 줄씩.
3. 끝나고 **5분 안에** 아래 6개에 답. 숫자 칸은 1~5 (1 = 전혀 아니다, 3 = 보통, 5 = 아주 그렇다).
4. 답은 이 파일을 복사해 `docs/design/playtest/YYYY-MM-DD.md` 로 두거나 대표 세션에 붙여 주세요.

## 질문

| # | 질문 | 답 |
|---|---|---|
| Q1 | 젖은 강아지가 도망가서 잡으러 뛰어다닐 때 **웃기거나 즐거웠나요?** (1~5, 기억나는 장면 한 줄) | |
| Q2 | 처음 판에서 **무엇을 해야 하는지 언제 알았나요?** (① 1분 안에 바로 ② 1판이 끝날 즈음 ③ 끝까지 잘 모르겠음 — 헷갈린 것 한 줄) | |
| Q3 | (2인) **역할이 나뉘었나요?** (① 말 안 해도 자연히 ② 말로 정해서 ③ 안 나뉨, 각자 다 함) | |
| Q4 | 강아지 상태(진흙 → 거품 → 젖음 → 뽀송)와 기계가 끝난 걸 **보고·듣고 바로 알았나요?** (1~5) | |
| Q5 | 3분이 끝났을 때 **바로 한 판 더** 하고 싶었나요? (1~5) | |
| Q6 | 가장 **답답했던 순간** 하나 (한 줄) | |

## 답에 따라 기획팀이 바꿀 것

### 판정

| 조건 | 판정 | 다음 |
|---|---|---|
| Q1 ≥ 4 **그리고** Q5 ≥ 4 **그리고** Q2 = ① | **통과** | 다음 반복: 빗질대 + 고양이 + 미끄럼 보내기 + 말풍선 그림 아이콘 (GDD_V2 5.2 의 1-2·1-3 맛보기) |
| Q1·Q5 중 하나가 3 이하, 또는 Q2 = ② | **고쳐서 다시** | 아래 처방대로 수치·연출만 고쳐 같은 시제품으로 한 번 더 |
| Q1 ≤ 2 **그리고** Q5 ≤ 2 | **핵심 재검토** | "도망가는 손님"이 안 웃기면 이 게임의 차별점이 없음 → 기획팀이 핵심 소동 대안 2개(예: 기계가 고장 나서 거품이 넘침 / 동물끼리 장난)를 제안. CONCEPTS_V2 B안(눈사람)도 다시 비교 |

### 질문별 처방 (키는 TUNING_V2.md)

| 답 | 문제 | 바꿀 것 |
|---|---|---|
| **Q1 ≤ 2** (안 웃김) | 도망이 너무 짧거나 시시함 | `escape_speed` 3.5 → 4.0, `escape_turn_interval` 2.0 → 1.2 (더 갈팡질팡), `puddle_slide_distance` 2.5 → 3.5. 도망칠 때 짖는 소리·발자국 효과 추가 요청 |
| **Q1 ≥ 4 인데 Q5 ≤ 2** (웃기지만 지침) | 잡기가 너무 힘듦 | `escape_speed` 3.5 → 3.0, `escape_avoid_player_range` 2.0 → 1.2 (덜 피함) |
| **Q2 = ② 또는 ③** | 할 일이 안 보임 | 말풍선을 글자 → 그림으로 (1순위), 동물을 들면 **넣을 기계 위에 화살표**가 뜸, 시작 안내 표시 3초 → 5초 |
| **Q3 = ③** (각자 다 함) | 같이 할 이유가 약함 | `party_guest_interval` 2인 20 → 15초 (혼자선 못 따라가게), 욕조·드라이어를 방 양 끝으로 떨어뜨림 |
| **Q3 = ①** | 좋음 | 그대로 |
| **Q4 ≤ 2** | 상태 변화가 약함 | 뽀송 크기 1.6 → 2.0배, 상태 바뀔 때 0.3초 '뿅' 커졌다 돌아오는 연출, 효과음 크게 |
| **Q5 ≤ 2** (한 판이 김) | 3분이 지루함 | `shop_duration` 180 → 150, 마지막 30초에 손님 간격 절반 ("마감 러시") |
| **Q6** | — | 다음 반복 1순위 수정 항목 |

혼자 1판만 했으면 Q3 은 빈칸으로 두고, 역할 판정은 2인 테스트 뒤로 미룹니다.
