- 저장소에 넣지 않은 임시 씬으로 `scenes/v4/fp_shop.tscn` 을 띄우고 18일 점검 도구 (`scripts/dev/fp_day_tools.gd`) 를 붙임. 날마다 `simulate_served()` (= F6: 그날 올 손님 480초 ÷ 간격을 모두 😊 로 받음, 요금 + 기분 팁 15 + 빠른 팁 5) → `end_day()` → 사기 → 다음 날. F8 기록 (`user://v4_day_log.csv`) 켬.
- 사는 사람 두 가지 (남길 돈 100, 샴푸가 10마리분 아래면 1병, 빗이 거의 닳으면 새 빗살):
  - **A 도구만**: 가장 싼 다음 도구 단계부터.
  - **B 섞어서**: 도구 ↔ 가장 싼 꾸미기를 번갈아, 4일차부터 가위 먼저.
- 사는 것은 시뮬 편의상 `buy()` (바로 적용). 그래서 CSV 의 `upkeep`·`bought` 열은 비어 있음 (택배 `order()` 로 산 것만 셈 — 도구 문제 아님).
- 한계: **모든 손님을 😊 로 받은 '최대' 곡선**. 실제는 의자가 차거나 떠나고 😐·🤩 가 섞임 → 점검표 3장의 '기대 (약 85%)' 와 비교. 금색 사진·신뢰는 이 시뮬로 못 봄 (`gold_photos` 0, `trust_levels` '-').
