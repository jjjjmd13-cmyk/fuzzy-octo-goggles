# 조사: 손으로 하는 가게 운영 시뮬레이터 2종

작성: 기획팀 · 2026-10-26 · 요청: 사람 대표 ("오니기리 샵 시뮬레이터, Dooms Hair Salon 같은 게임처럼")

> **조사 한계**: 이 세션에서는 스팀 상점·커뮤니티 페이지를 직접 열 수 없었음 (접속 막힘). 웹 검색 결과(상점 요약, 리뷰 발췌, 공략·위키 요약)만 보고 정리했다.
> 영상으로 손맛을 직접 확인하지 못했으므로 **"확인됨"과 "기획팀 추정"을 나눠 적는다.** 사람 대표가 직접 해 본 게임이라면 아래 추정이 틀린 부분을 알려 주면 바로 고친다.

## 2. 둠스 헤어 살롱 (*Dooms Hair Salon*)

- 스팀 앱 3398870 (원제 *Salon Krasi Dum*), Slimebox, 2025-03-24 출시, 약 $9.99, 리뷰 대체로 긍정적 (79~91%, 집계마다 다름). **온라인 협동 최대 4인.**

| 항목 | 내용 | |
|---|---|---|
| 손님 | 매일 "말도 안 되는 머리 모양"의 손님이 옴 → 시원하게 잘라 주고 돈을 받음 | 확인됨 (상점 설명) |
| 도구 | 처음엔 기본 가위, 가게 확장 단계에 따라 더 좋은 가위·바리캉이 해금 (업적 "드디어 바리캉 샀다") | 확인됨 (위키·업적) |
| 가게 | 확장 1~7단계, 가구 설치, 귀찮은 일 자동화 | 확인됨 |
| 웃긴 소동 | 마피아·악당이 영업을 방해, 손님이 졸다가 잠듦, 차가 사람을 치고 감 | 확인됨 (리뷰) |
| 곁가지 | 미용실 외에 채굴·코인 같은 부업으로 넓어짐 | 확인됨 (리뷰) |
| 협동 | "혼자도 좋지만 협동은 한 단계 위" (리뷰) | 확인됨 |
| 불만 | 버그 (가게 밖으로 못 나감, 확장 구역이 안 보임, 튕김) | 확인됨 |
| 시점·자르는 손맛 | 검색으로는 자세히 확인 못함 — 같은 계열 게임처럼 1인칭에서 도구를 들고 머리카락을 직접 깎는 방식으로 **추정** | 추정 |

**배울 점**: **결과가 눈에 크게 보이는 손작업**(덥수룩한 머리 → 깔끔) + 가게가 커지면서 도구가 좋아지는 성장 + 영업 중에 끼어드는 **웃긴 사건**. 협동은 '같은 가게에서 일을 나누는' 방식.

## 3. 두 게임의 공통 재미 (기획팀 정리)

1. **1인칭으로 손님 한 명을 내 손으로 처리** — 단계가 3~6개, 단계마다 다른 도구·다른 마우스 동작.
2. **결과가 그 자리에서 보임** — 밥이 모양이 잡힘, 머리가 잘림. 숨은 수치가 아님.
3. **하루 영업 → 정산 → 구매·확장 → 다음 날** 순환. 새 레시피·도구·손님이 조금씩 열림.
4. **반복은 짧게** — 같은 동작을 오래 시키면 불만 (오니기리 김 붙이기). 업그레이드로 점점 빨라지게.
5. **웃긴 순간은 작업 중에** — 손님이 잠듦, 방해꾼 (둠스).
6. **혼자가 기본**, 협동은 같은 가게에서 일을 나눠 맡는 덤 (둠스).
