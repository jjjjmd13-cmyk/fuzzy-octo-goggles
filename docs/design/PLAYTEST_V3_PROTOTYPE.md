# 멍냥 목욕탕 V3 — 시제품 1 (손맛) 플레이 테스트지

작성: 기획팀 · 2026-10-26 · 대상: GDD_V3 8.1 시제품 1 (PR #29) · 답하는 사람: 사람 대표

**알고 싶은 것**: 기둥 1 **"직접 손으로 하는 느낌"** — 강아지 한 마리 씻기는 과정 자체가 재밌나?

## 진행 방법 (10~15분)

1. 설명 없이 시작해서 **강아지 5마리 이상** 씻겨 보기 (한 마리 약 2분 목표).
2. 2~3마리째쯤 돈이 모이면 컴퓨터 자리에서 **복숭아 샴푸**를 사서 써 보기.
3. 끝나고 **5분 안에** 아래 6개에 답. 숫자 칸은 1~5 (1 = 전혀 아니다, 3 = 보통, 5 = 아주 그렇다).
4. 답은 이 파일을 복사해 `docs/design/playtest/YYYY-MM-DD.md` 로 두거나 대표 세션에 붙여 주세요.

## 질문

| # | 질문 | 답 |
|---|---|---|
| Q1 | **강아지 한 마리를 씻기는 과정 자체가 재밌었나요?** (1~5) | |
| Q2 | **손으로 직접 하는 느낌**이 났나요? (1~5) — 가장 손맛이 좋았던 단계 / 가장 지루했던 단계 (적시기·거품·헹구기·수건·드라이어 중) | |
| Q3 | 몇 마리째에 **"또 같은 거네"** 싶었나요? (마리 수, 안 들었으면 "없음") | |
| Q4 | 강아지 반응(차가운 물에 펄쩍, 간지럼·몸 털기, 드라이어에 볼 펄럭)이 **양념으로 좋았나요, 방해였나요?** (좋음 / 보통 / 방해) | |
| Q5 | 샴푸를 사고 나서 **돈을 모아 다른 걸 사고 싶어졌나요?** (1~5) | |
| Q6 | 설명 없이 **무엇을 해야 하는지** 바로 알았나요? (바로 / 조금 헤맴 / 모르겠음 — 헤맨 곳 한 줄) | |

## 답에 따라 기획팀이 바꿀 것

| 답 | 다음 (키는 TUNING_V3.md) |
|---|---|
| Q1 ≥ 4, Q2 ≥ 4, Q3 ≥ 5마리 (또는 없음) | **통과** → 시제품 2 (가게 키우기 순환, GDD_V3 8.2) |
| Q2 에 지루한 단계가 있음 | 그 단계 시간을 반으로 (`tool_*_rate` 2배), 그래도 지루하면 동작을 바꿈 (예: 문지르기 → 누르고 있기) |
| Q3 ≤ 3마리 | 더러움 무늬를 3 → 8종으로 앞당기고 성격(GDD_V3 3.4) 하나를 시제품 2 전에 넣음, `stage_complete_ratio` 0.9 → 0.85 |
| Q4 = 방해 | 반응 쿨타임 2배 (`proto_cold_cooldown`·`proto_eye_cooldown`), `shake_time` 6 → 9초, 반응 중에도 칠하기는 계속되게 |
| Q4 = 좋음 | 시제품 2 에서 반응 종류를 하나 더 (졸보 성격: 따뜻한 물에 잠듦) |
| Q5 ≤ 2 | 살 것이 매력 없음 → 시제품 2 에서 도구 업그레이드·꾸미기를 첫날부터 상점에 보이게 |
| Q6 = 조금 헤맴 / 모르겠음 | 헤맨 곳에 처음 한 번만 그림 힌트 (예: 샴푸 병 위에 '클릭' 손 모양) |
| Q1 ≤ 2 | **핵심 재검토** — 손작업 자체가 재미없으면 다른 손작업(미용·빗질 중심 등)으로 바꿔 제안 |
