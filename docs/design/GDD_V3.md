## 0. 사람 대표 질문에 대한 답: "이건 혼자 하는 게임이지?"

> **네. 혼자서 처음부터 끝까지 재밌는 가게 운영 게임이 기본이고, 친구가 들어오면 같은 가게에서 일을 나눠(한 명은 접수·계산, 한 명은 목욕) 더 많은 손님을 받는 협동이 덤으로 붙습니다.**

## 1. 한 줄과 기둥

**1인칭으로 동물 손님을 내 손으로 직접 씻기고 말리고 꾸며 주는 작은 목욕탕을 운영하고, 번 돈으로 도구를 사고 가게를 키운다.**

1. **내 손으로 한다** — 단계마다 다른 도구, 다른 마우스 동작. 자동으로 돌아가는 기계 없음.
2. **결과가 동물 몸에 그대로 보인다** — 진흙이 씻겨 나가고, 거품이 덮이고, 털이 부풀어 오른다. 진행 막대·숫자 게이지 없음.
3. **웃긴 순간은 작업 중에** — 차가운 물에 펄쩍, 얼굴에 드라이어를 대면 볼이 펄럭, 거품을 털어서 화면에 튐.
4. **하루 → 정산 → 쇼핑 → 다음 날** — 매일 새것이 하나씩.

## 2. 시점과 조작

- **1인칭.** 목욕대 앞에 서면 카메라가 목욕대 쪽으로 살짝 붙음 (작업 모드). 걸어서 계산대·선반·컴퓨터로 이동.
- **마우스가 손.** 왼쪽 버튼 = 도구 쓰기 (누르고 있으면 계속), 마우스 움직임 = 도구가 동물 몸 위를 따라감.
- **도구 바꾸기**: 숫자 1~5 또는 휠 / 목욕대 옆 도구걸이에서 클릭. 손에 든 도구가 화면 오른쪽 아래에 크게 보임.
- **동물 돌리기**: 오른쪽 버튼 끌기 = 목욕대 회전판이 돌아감 (반대편 털도 씻기 위해).
- 게임패드: 오른쪽 스틱 = 도구 이동, RT = 쓰기, LB/RB = 도구 바꾸기 (Steam Deck 대응).

## 3. 손님 한 마리 (핵심 루프)

```
① 접수   손님이 계산대에 '요청 카드'를 내밂 (그림: 🛁 / 🛁+🪮 / 🛁+🪮+🎀 빨강, 향 🍑)
② 안내   목욕대로 손님을 데려감 (클릭하면 따라옴)
③ 적시기 샤워기
④ 거품   샴푸 짜기 → 문지르기
⑤ 헹구기 샤워기
⑥ 말리기 수건 → 드라이어
(⑦ 빗질 · ⑧ 다듬기 · ⑨ 리본 — 해금되면)
⑩ 계산   카드와 비교 → 요금 + 팁, 손님 표정
```

### 3.1 단계별 손맛 (각 단계가 따로 재밌어야 함)

| 단계 | 도구 | 마우스 동작 | 눈에 보이는 결과 | 소리 | 웃긴 순간 |
|---|---|---|---|---|---|
| ③ 적시기 | 샤워기 | 누르고 몸 위를 훑기 | 맞은 부위 털이 **진해지고 납작**해짐, 진흙이 갈색 물로 흘러내림 | 쏴아 | **물 온도 다이얼**: 너무 차가우면 펄쩍 뛰어 물이 튐, 너무 뜨거우면 혀를 내밀고 헥헥 |
| ④ 거품 | 샴푸 병 → 손 | 병 클릭 = 등에 한 덩이 짜기. 손으로 **빙글빙글 문지르기** — 빨리 문지를수록 거품이 커짐 | 거품이 몸을 덮어 감, 거품 밑 진흙 얼룩이 사라짐. 다 덮으면 강아지가 **거품 구름**처럼 됨 | 뽀글뽀글, 다 되면 "뽀옹" | 한 곳만 오래 문지르면 **간지러워서 다리를 찰랑**, 더 하면 **몸을 털어 거품이 화면에 튐** (잠깐 앞이 하얗게) |
| ⑤ 헹구기 | 샤워기 | 다시 훑기 | 거품이 녹아 흘러내림. **남은 거품은 반짝이는 점**으로 표시 | 쏴아 → 뽀득 | 눈 쪽에 물을 대면 눈을 꼭 감고 고개를 돌림 |
| ⑥-1 말리기 | 수건 | 문지르기 | 물방울이 줄어듦 | 북북 | — |
| ⑥-2 말리기 | 드라이어 | 바람을 쐬기 (거리가 가까울수록 빠름, 너무 가까우면 "앗 뜨거") | 털이 **부풀어 올라 두 배 크기 솜뭉치**가 됨 | 위잉 → "뽀옹!" | **얼굴에 대면 볼·귀가 펄럭**, 입이 벌어짐 |
| ⑦ 빗질 (해금) | 빗 | 털 방향으로 쓸기 | 엉킨 털 뭉치가 풀려 매끈 | 샤샥 | 엉킨 곳을 세게 당기면 "깨갱" (기분 −) |
| ⑧ 다듬기 (해금) | 가위 | 튀어나온 털 끝을 클릭해 자르기 | 털이 깔끔한 모양으로 | 싹둑 | 너무 많이 자르면 **우스꽝스러운 모양** (손님이 거울 보고 놀람) |
| ⑨ 리본 (해금) | 리본 상자 | 색 고르고 머리에 클릭 | 리본 | 딸랑 | — |

**진행은 동물 몸으로 보인다**: 몸을 **부위 12개**(머리·귀2·등·배·다리4·꼬리·엉덩이·목)로 나누고, 부위마다 상태(진흙 / 젖음 / 거품 / 헹굼 / 뽀송)를 따로 가짐. 모든 부위가 다음 상태가 되면 그 단계 끝 → 요청 카드의 그림에 체크 ✓ + "딩".

### 3.2 손님 기분 (얼굴로 보임, 숫자 없음)

- 얼굴 표정 3단계: 😊 (좋음) → 😐 → 😣 (싫음). 귀 모양·꼬리도 같이 바뀜.
- 기분이 내려가는 것: 차갑거나 뜨거운 물, 눈에 물·거품, 한 곳 너무 오래, 드라이어 너무 가까이, 엉킨 털 세게 당기기.
- 기분이 올라가는 것: 적당한 물 온도, 등 긁어 주기(손 도구로 등을 살살), 간식(해금).
- 😣 에서 더 나빠지면 **목욕대에서 뛰어내리려 함** → 화면에 손이 뻗는 연출과 함께 **클릭 연타로 붙잡기** (웃긴 순간, 놓치면 젖은 채 가게를 뛰어다님 → 잡으러 가기).
- 계산 때 기분 + 요청과 맞음 → **팁**.

### 3.3 요청 카드 (할 일이 처음부터 보임)

- 그림으로만: 서비스 아이콘(🛁 🪮 ✂️ 🎀) + 원하는 향(🍑 🌸 🍋) + 리본 색.
- 카드는 목욕대 옆 집게에 걸려 늘 보임. 끝난 단계는 ✓.
- 맞는 향 샴푸를 쓰면 팁 +, 리본 색이 맞으면 팁 +.

## 4. 하루와 가게 운영

| 시간 | 하는 일 |
|---|---|
| 아침 (준비, 시간 안 감) | 선반 채우기, 도구 정리, 오늘의 특별 손님 확인 |
| **영업 (9시~6시, 실제 약 8분)** | 손님이 대기석에 하나둘 옴 (기다리면 기분이 조금씩 내려감). 내가 처리할 수 있는 만큼 받음 |
| 정산 | 번 돈, 팁, 손님 평점 (별), 가게 경험치 |
| 쇼핑 (컴퓨터 화면) | **소모품** 샴푸·린스(병마다 사용 횟수), **도구** 업그레이드, **서비스** 해금, **꾸미기**, **확장** |

- **소모품**: 샴푸 한 병 = 손님 8마리. 떨어지면 거품이 안 남 → 사 둬야 함 (오니기리의 '재료 관리' 맛). 향 샴푸는 비싸지만 팁 +.
- **도구 업그레이드**: 샤워기 수압(넓게 적심), 드라이어 바람(빨리 부풂), 큰 손(거품 빨리) → **같은 동작이 점점 빨라짐** (반복 지루함 방지, 오니기리 불만 반영).
- **가게 레벨** (손님 만족 경험치): 레벨마다 새 동물·새 서비스·확장이 열림.
- **확장**: 목욕대 2대째, 대기실 소파, 2층 미용실(빗질·다듬기), 마당(큰 개).
- **꾸미기**: 벽지·바닥·타일·화분·간판 — 손님 기분이 조금 오름 (보너스는 작게, 꾸미는 재미 위주).

### 4.1 영업 중 사건 (웃긴 순간, 하루 0~2개)

| 사건 | 무엇 |
|---|---|
| 탈출 손님 | 목욕 중 뛰어내린 손님이 젖은 채 가게를 뛰어다님 (V2 의 '도망'을 사건으로 살림) |
| 오리 떼 | 오리 손님이 친구들을 데려와 욕조에서 안 나옴 |
| 정전 | 드라이어가 안 됨 → 수건만으로 말리기 |
| 털갈이 철 | 털이 엄청 날림 → 빗질 손님이 몰림 |
| VIP 손님 | 까다로운 요청 (향+리본+모양), 팁이 큼 |

## 5. 동물과 해금 (정식판 목표)

| 동물 | 특징 (손맛이 달라지는 점) | 해금 |
|---|---|---|
| 강아지 | 기본 | 1일차 |
| 고양이 | 물을 싫어함 — 온도 범위가 좁고, 적시기를 빨리 끝내야 함 | 가게 Lv2 |
| 오리 | 물을 좋아함 — 헹구기가 끝나도 안 나가려 함, 깃털은 문지르기 대신 쓸기 | Lv3 |
| 털뭉치 개 (푸들) | 털이 많아 거품·말리기가 오래, 다듬기 필수 | Lv4 (2층 미용실과 함께) |
| 대형견 | 목욕대 대신 마당 큰 욕조, 회전판 없음 → 직접 돌아가며 씻기 | Lv6 |
| 토끼 | 아주 예민 — 드라이어 대신 수건만 | Lv7 |
| 고슴도치 | 가시 사이를 칫솔로 살살 (새 도구) | Lv8 |

서비스: 목욕(1일차) → 빗질(Lv2) → 리본(Lv3) → 다듬기(Lv4) → 향 샴푸 고르기(Lv5) → 발톱 다듬기(Lv7).

## 6. 플레이 타임 (스팀 환불 기준, 목표 유지)

목표: 첫 클리어 **2.5~3시간** (혼자), 전부 **5~6시간**, **2시간 지점에 남은 것이 보이게**.

- 하루 = 준비 1분 + 영업 약 8분 + 정산·쇼핑 1~2분 ≈ **10분**.
- **첫 클리어 = '반짝 펫 쇼 대회'** (가게 Lv8 에 열리는 특별한 하루, 엔딩): 약 **18일**.

| 시점 (혼자) | 날 | 무엇이 새로 나오나 |
|---|---|---|
| 0~10분 | 1일 | 강아지, 목욕 4단계 (적시기·거품·헹구기·말리기) |
| ~20분 | 2일 | 첫 쇼핑: 향 샴푸 하나, 꾸미기 상점 열림 |
| ~30분 | 3일 | **Lv2**: 고양이 + 빗질 |
| ~45분 | 4~5일 | **Lv3**: 오리 + 리본, 첫 사건(오리 떼) |
| ~60분 | 6일 | 목욕대 2대째 확장 (두 마리 동시에 — 바빠짐) |
| **~80~90분** | **8~9일** | **Lv4: 2층 미용실 확장** + 털뭉치 개 + 다듬기(가위) — **가장 큰 변화** (새 층, 새 손맛) |
| ~105분 | 10~11일 | Lv5: 향 고르기, VIP 손님 |
| **120분 (2시간)** | **12일** | Lv6 직전. **남은 것이 화면에 보임**: 상점의 잠긴 칸(마당 확장·대형견·토끼·고슴도치), 펫 쇼 대회 포스터(벽), 손님 도감 빈칸 |
| ~140분 | 14일 | Lv6: **마당 확장 + 대형견** |
| ~160분 | 16일 | Lv7: 토끼, 발톱 |
| **~180분** | **18일** | Lv8: 고슴도치 → **펫 쇼 대회 (엔딩)** |
| 엔딩 뒤 | 자유 영업 | VIP 의뢰 12개(각자 다른 까다로운 요청), 꾸미기 전부, 손님 도감 전부, 업적 15개 |

| 목표 | **혼자** | **4인** |
|---|---|---|
| 가장 큰 변화 (2층 미용실) | 약 1.5시간 | 약 1.2시간 |
| 2시간 지점 | 12일차, 동물 4/7, 확장 2/4 | 15일차, 동물 5/7 |
| **첫 클리어** (펫 쇼 대회) | **약 3시간** | **약 2.5시간** |
| **전부** (VIP 의뢰·도감·꾸미기·업적) | **약 5.5시간** | **약 5시간** |

- 4인이 빠른 이유: 같은 하루에 더 많은 손님 → 돈·경험치가 빨리 참 (날 수는 줄어듦). 4인은 하루 손님 수를 늘려서 한가하지 않게 함.
- **같은 하루 반복으로 늘리지 않음**: 날마다 손님 구성·요청·사건이 다르고, 레벨마다 새 동물·서비스가 열림. 엔딩 뒤 콘텐츠도 '새 요청'(VIP 의뢰)으로.
- 숫자는 추정. 시제품·플레이 테스트로 고침.

## 7. 협동 (고정 조건 유지, 혼자가 기본)

| 인원 | 어떻게 나누나 |
|---|---|
| 1인 | 모든 일을 혼자. 손님 수는 혼자 손에 맞춤 |
| 2인 | **목욕대를 하나씩** 맡거나, **한 명은 접수·계산·선반 채우기 + 한 명은 목욕** |
| 3~4인 | 접수·계산 / 목욕 / 2층 미용 처럼 층·자리를 나눔. 한 손님을 여럿이 동시에 만질 수도 있음 (한 명 헹구고 한 명 드라이어) |

- 돈·레벨·꾸미기는 **가게 하나를 같이** 씀 (호스트 저장).
- 하루 손님 수 = 인원에 맞게 늘어남 (TUNING_V3).
- 원정 도중 참가 없음 → **하루 영업 도중 참가 없음**, 아침(준비 시간)에만 참가.

## 8. 첫 시제품 (1~2주)

> **"1인칭으로 목욕대 하나에서 강아지 한 마리를 적시고, 거품 내고, 헹구고, 말려서 돈을 받고, 그 돈으로 샴푸 하나를 산다."**

확인하려는 질문 하나: **"손님 한 마리 씻기는 과정 자체가 재밌나?"** (가게 운영은 아직 확인 안 함)

### 8.1 범위

| 넣는 것 | 빼는 것 (다음 반복) |
|---|---|
| 1인칭 이동 + 작업 모드(목욕대 앞) | 계산대 걷기·대기석 (손님은 목욕대에 바로 나타남) |
| 강아지 1종, 부위 12개 상태 | 다른 동물 |
| 도구 4개: 샤워기(온도 다이얼), 샴푸+손, 수건, 드라이어 | 빗·가위·리본 |
| 단계 4개: 적시기 → 거품 → 헹구기 → 말리기, 단계마다 3.1 표의 결과·소리·웃긴 순간 1개씩 | 탈출 붙잡기 (다음 반복 1순위) |
| 얼굴 표정 3단계 기분 | 사건 |
| 끝나면 손님이 동전을 떨어뜨림 → 클릭해서 줍기 (요금 + 기분 팁) | 계산대 |
| 벽의 컴퓨터(단순 화면)에서 **복숭아 샴푸 하나 사기** → 쓰면 거품이 분홍색 + 팁 +. 기본 샴푸는 병마다 손님 8마리 | 가게 확장·꾸미기 |
| 강아지를 다 씻기면 다음 강아지가 나옴 (끝없이, 몇 마리 씻겼는지 표시) | 하루·영업 시간 |
| 1인 (오프라인 호스트). 2인 접속은 기반만 유지 | 협동 플레이 테스트 |
| 효과음 (3.1 표의 소리) — 직접 만든 임시 소리 (`tools/make_sfx.py`) | 배경 음악 |

### 8.2 완료 조건

1. 1인칭으로 걸어서 목욕대 앞에 서면 작업 모드 (마우스가 도구가 됨), 물러나면 다시 걷기.
2. 도구 4개를 1~4 키/휠로 바꿈, 손에 든 도구가 화면에 보임.
3. 오른쪽 끌기로 강아지가 회전판째 돎 (반대쪽 털을 씻을 수 있음).
4. **적시기**: 샤워기 물줄기가 닿은 부위만 진해지고 납작해짐, 진흙 물이 흘러내림. 온도 다이얼(차갑다·좋다·뜨겁다) — 차가우면 펄쩍 + 물 튐.
5. **거품**: 병 클릭 = 거품 덩이, 손으로 문지르면 부위가 거품으로 덮임. 빨리 문지르면 더 빨리. 한 곳 3초 넘게 → 다리 찰랑, 6초 넘게 → 몸 털기 (화면에 거품).
6. **헹구기**: 거품 부위가 헹굼으로 바뀜, 남은 거품은 반짝이는 점으로 보임.
7. **말리기**: 수건으로 물방울 줄이기 → 드라이어로 털 부풀리기 (1.0 → 2.0배). 얼굴에 대면 볼 펄럭.
8. 단계가 끝날 때마다 요청 카드 그림에 ✓ + "딩". 숫자·막대 없음.
9. 기분 얼굴 3단계가 행동에 따라 바뀜, 끝날 때 기분에 따라 팁.
10. 동전을 주워 돈이 오름 → 컴퓨터에서 복숭아 샴푸 구매 → 거품 색·팁이 바뀜. 샴푸가 떨어지면 거품이 안 남 (다시 사야 함).
11. 부위 상태·기분·돈은 **호스트 권한** (혼자 = 오프라인 호스트). 나중에 2인이 같은 강아지를 같이 씻을 수 있는 구조.
12. 수치는 `TUNING_V3.md` 키 이름으로 리소스 한 곳 (`res://data/balance/sim_balance.tres`).

## 9. 개발팀: 다시 쓸 것 / 버릴 것

**다시 쓸 것**: 네트워크 계층(`Net`, 오프라인 호스트·ENet·Steam 전송), 메인 메뉴·일시 메뉴, 테마·글꼴(Pretendard), 수치 리소스 방식(`tuning.gd`), 테스트 실행기·CI, 그래픽 교체 지점 방식, 강아지 모형의 상태별 색 바꾸기(`dog_model.gd` → 부위별로 확장), 효과음 만드는 도구(`tools/make_sfx.py`), 방 짓기(`room_builder.gd`). 1인칭 이동은 등불 원정대 시제품(PR #12)의 플레이어 코드를 git 기록에서 되살리면 빠름.
**버릴 것 (또는 보관)**: 쿼터뷰 고정 카메라·쿼터뷰 이동, 대시, Space 하나로 다 하는 `use_action`, 자동으로 도는 욕조·드라이어 기계(`machine.gd`), 도망·웅덩이·미끄러짐(사건 '탈출 손님'으로 나중에 일부만 다시), 대기석 줄 로직(다음 반복에 계산대와 함께 다시 볼 수 있음).
**새로 필요한 기술 (가장 큰 위험)**: 마우스로 동물 몸 **부위를 맞히고 상태를 칠하는 것**. 권장: 텍스처에 직접 그리기 대신 **부위 12개(콜라이더) × 상태 값** 으로 단순화 → 판정·동기화·그래픽 교체가 모두 쉬움. 첫 주에 이것부터 확인.
