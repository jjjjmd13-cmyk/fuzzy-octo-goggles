## 0. 사람 대표 질문에 대한 답: "이건 혼자 하는 게임이지?"

> **네. 혼자서 처음부터 끝까지 재밌는 가게 운영 게임이 기본이고, 친구가 들어오면 같은 가게에서 일을 나눠(한 명은 접수·계산, 한 명은 목욕) 더 많은 손님을 받는 협동이 덤으로 붙습니다.**

## 1. 한 줄과 기둥

**동물 손님을 내 손으로 직접 씻기고 말리고 꾸며 주는 작은 목욕탕을 운영하고, 번 돈으로 도구를 사고 가게를 키운다.**

사람 대표가 두 참고 게임에서 좋았다고 한 두 가지가 기둥이다. 기능을 넣을지 고민될 때 이 둘에 도움이 되는지 본다.

1. **직접 손으로 하는 느낌** — 단계마다 다른 도구, 다른 마우스 동작. 결과가 동물 몸에 그 자리에서 보임 (진흙이 지워지고, 거품이 덮이고, 털이 부풂). 자동으로 도는 기계·진행 막대 없음.
2. **가게 키우는 재미** — 하루 영업 → 돈 → 샴푸·도구 구매, 확장, 꾸미기 → 새 손님·새 서비스. 매일 무언가 하나가 늘어남.

**양념 (기둥 아님)**: 손님 반응·작은 소동 — 차가운 물에 펄쩍, 간지러워 몸 털기, 드라이어에 볼 펄럭. 손작업을 더 재밌게 하는 정도로만 쓰고, 이것 때문에 작업이 방해받아 답답하지 않게.

## 2. 시점과 조작: **작업대 시점** (자리마다 고정 카메라 + 마우스 커서)

개발팀 제안과 기획팀 1차안(자유 1인칭)을 비교해 **작업대 시점**으로 정함 (대표 의견과 같음).

| | 작업대 시점 (채택) | 자유 1인칭 (1차안) |
|---|---|---|
| 손맛 | 커서 = 손. 동물이 화면 가운데 크게 → 문지르는 곳이 정확히 보임 | 카메라와 도구가 같이 움직여 조준이 어려움 |
| 멀미·Steam Deck | 멀미 없음, 패드 스틱으로 커서만 움직이면 됨 | 멀미 가능, 패드 조준 어려움 |
| 만들기 | 자리마다 카메라 하나 | 1인칭 이동 + 작업 모드 전환 |
| 가게 느낌 | 자리 사이 이동이 짧은 카메라 이동으로 대신함 | 걸어 다니는 '내 가게' 느낌이 더 강함 |

- **자리(작업대)**: 접수대 · 목욕대 · (해금) 미용대 · 진열대(샴푸 선반) · 컴퓨터(쇼핑).
- **자리 옮기기**: 화면 아래 자리 아이콘 클릭 또는 숫자 키 / 패드 LB·RB → 카메라가 0.4초에 걸쳐 그 자리로 미끄러지듯 이동 (가게 안이 이어져 보이게).
- **한 손(마우스)으로 다 된다** (0.3, 플레이 테스트 3 "조작이 불편함" 반영):
  - **도구는 자동으로 손에 들림** — 요청 카드의 다음 단계 도구가 저절로 쥐어짐. 숫자 키로 바꾸지 않음 (도구걸이를 클릭하면 직접 바꿀 수도 있음).
  - **강아지는 알아서 돈다** — 보이는 쪽이 다 되면 회전판이 반대쪽으로 천천히 돎. 일찍 돌리고 싶으면 회전판 가장자리의 화살표를 클릭.
  - 왼쪽 버튼 = 도구 쓰기 (단계마다 동작이 다름, 3.1), 휠 = 그 단계의 '양' 조절 (드라이어 거리 등). 오른쪽 버튼·키보드는 쓰지 않아도 됨.
- **패드**: 왼쪽 스틱 = 커서, RT = 쓰기, 오른쪽 스틱 위아래 = 휠 대신, LB·RB = 자리.
- 가게 전체를 둘러보는 자유 시점은 나중에 꾸미기 모드(손님 없을 때)에서만 검토.

## 3. 손님 한 마리 (핵심 루프)

```
① 접수   (접수대 자리) 손님이 '요청 카드'를 내밂 (그림: 🛁 / 🛁+🪮 / 🛁+🪮+🎀 빨강, 향 🍑)
② 안내   "목욕대로" 버튼 → 손님이 목욕대로 가고 카메라도 목욕대 자리로
③ 적시기 샤워기
④ 거품   샴푸 짜기 → 문지르기
⑤ 헹구기 샤워기
⑥ 말리기 수건 → 드라이어 (요청 카드에서는 두 줄: 수건 ✓, 드라이어 ✓)
(⑦ 빗질 · ⑧ 다듬기 · ⑨ 리본 — 해금되면)
⑩ 계산   카드와 비교 → 요금 + 팁, 손님 표정
```

### 3.1 단계별 손맛 — **단계마다 다른 손동작** (기둥 1)

0.3 에서 바꿈: 플레이 테스트 3 에서 "문지르기만 다섯 번"이 지루했음 → **같은 '왼쪽 끌기로 칠하기'를 두 번 이상 쓰지 않는다.** 각 단계 10~20초.

| 단계 | 도구 (자동으로 손에) | **손동작** | 눈에 보이는 결과 | 소리 | 양념 반응 | 목표 |
|---|---|---|---|---|---|---|
| ③ 적시기 | 샤워기 | **누르고 있는 동안 물이 나옴 + 조준.** 물줄기가 화면에 보이고 커서가 맞는 곳. 휠 = 물 온도 (수도꼭지 색: 파랑·초록·빨강) | 맞은 곳이 진해지고 납작, 진흙물이 흘러내림 | 쏴아 (누르는 동안) | 차가우면 펄쩍 + 물 튐, 뜨거우면 헥헥 | 12초 |
| ④-1 샴푸 짜기 | 샴푸 병 | **누르고 있는 시간 = 짜는 양.** 병이 찌그러지고 거품 덩이가 커짐. 떼면 등에 떨어짐 | 덩이 크기 = 문지를 수 있는 넓이. 너무 많으면 거품이 넘쳐 흘러내림 (샴푸 낭비) | 뿌직~ | — | 3초 |
| ④-2 문지르기 | 손 | **동그랗게 원 그리기.** 원을 그릴수록 거품이 부풀고, 빠를수록 크게 (원 그리기 인식 — 단순 왕복은 거품이 안 큼) | 원 그린 자리부터 거품 공이 불어나 몸을 덮음 | 뽀글뽀글, 빠를수록 크게 | 같은 곳 오래 → 다리 찰랑 → 몸 털기 (화면에 거품) | 15초 |
| ⑤ 헹구기 | 바가지 | **위에서 아래로 쓸어내리기.** 커서를 올렸다가 아래로 끌면 바가지가 기울어 물이 쏟아짐 → 그 띠의 거품이 한 번에 씻겨 내려감 | 거품이 폭포처럼 흘러내림. 3~4번 쏟으면 끝 | 촤아악 | 머리 위로 쏟으면 눈을 꼭 감고 부르르 | 10초 |
| ⑥-1 수건 | 수건 | **꾹꾹 누르기 (클릭 연타).** 누를 때마다 수건이 꾹 눌리고 물이 짜여 뚝뚝 | 누른 자리 물방울이 사라짐 (몸에 맺힌 물방울 수 = 남은 젖음) | 꾹, 꾹 | 배를 꾹 누르면 "킁" | 10초 |
| ⑥-2 드라이어 | 드라이어 | **커서로 방향 + 휠로 거리.** 가까우면 빠르고 털이 세게 날림 | 털이 바람 방향으로 날리며 점점 부풀어 솜뭉치 | 위잉 (가까울수록 높게) | 얼굴에 대면 볼·귀 펄럭, 너무 가까우면 찡그림 (기분 −) | 15초 |
| ⑦ 빗질 (해금) | 빗 | 털 방향으로 **길게 쓸기** (한 번에 한 줄) | 엉킨 털 뭉치가 풀려 매끈 | 샤샥 | 엉킨 곳 세게 → "깨갱" | — |
| ⑧ 다듬기 (해금) | 가위 | 튀어나온 털 끝을 **클릭해 자르기** | 깔끔한 모양 | 싹둑 | 너무 많이 → 우스꽝스러운 모양 | — |
| ⑨ 리본 (해금) | 리본 | 색 고르고 **머리에 끌어다 놓기** | 리본 | 딸랑 | — | — |

한 마리 목욕 ≈ **65초** + 주인 맞이·돌려주기 ≈ **1분 반**.

**진행은 동물 몸으로 보인다 (개발팀 제안 채택)**
- **더러움 마스크**: 동물마다 '더러움 마스크'(텍스처)가 있고, 단계마다 다른 손동작이 마스크를 다른 모양으로 칠함 (물줄기 = 둥근 점, 문지르기 = 원, 바가지 = 세로 띠, 수건 = 꾹 누른 도장, 드라이어 = 바람 부채꼴).
- **단계 완료 = 칠해진 비율** `stage_complete_ratio` (TUNING_V3). 나머지는 일부러 봐주는 몫 — 구석 털 한 올 때문에 헤매지 않게. 남은 구역은 반짝여서 보임.
- **거품** = 작은 거품 공 여러 개가 몸에 붙음. 문지를수록 늘고 커짐, 샤워기를 대면 줄어들며 사라짐 (헹구기).
- **젖음 / 뽀송** = 털 셰이더 값 2개: 젖음(진하고 반짝, 납작) → 말리면 뽀송(부풀기, 밝아짐).
- **마우스를 빨리 움직일수록** 거품이 빨리 늘고 문지르는 소리가 커짐 → 손에 힘을 주는 느낌.
- 단계가 끝나면 요청 카드의 그림에 ✓ + "딩". 숫자·진행 막대는 없음 (비율은 내부 판정만).

### 3.2 손님 기분 (얼굴로 보임, 숫자 없음)

- 얼굴 표정 3단계: 😊 (좋음) → 😐 → 😣 (싫음). 귀 모양·꼬리도 같이 바뀜.
- 기분이 내려가는 것: 차갑거나 뜨거운 물, 눈에 물·거품, 한 곳 너무 오래, 드라이어 너무 가까이, 엉킨 털 세게 당기기.
- 기분이 올라가는 것: 적당한 물 온도, 등 긁어 주기(손 도구로 등을 살살), 간식(해금).
- 😣 에서 더 나빠지면 **목욕대에서 뛰어내리려 함** → 화면에 손이 뻗는 연출과 함께 **클릭 연타로 붙잡기** (웃긴 순간, 놓치면 젖은 채 가게를 뛰어다님 → 잡으러 가기).
- 계산 때 기분 + 요청과 맞음 → **팁**.

### 3.3 요청 카드 (할 일이 처음부터 보임)

- 그림으로만: 서비스 아이콘(🛁 🪮 ✂️ 🎀) + 원하는 향(🍑 🌸 🍋) + 리본 색.
- 카드는 목욕대 옆 집게에 걸려 늘 보임. 끝난 단계는 ✓.
- 맞는 향 샴푸를 쓰면 팁 +, 리본 색이 맞으면 팁 +.

### 3.4 같은 단계라도 손님마다 다르게 (반복 지루함 막기)

조사에서 나온 불만 "같은 동작 반복이 지루하다"(오니기리 김 붙이기) 대책. 단계 순서는 같아도 **손님마다 손이 하는 일이 달라지게** 한다.

1. **더러움 무늬가 손님마다 다름** — 진흙이 발에만 / 등에 큰 얼룩 / 온몸 점박이 / 꼬리 끝만 / 페인트가 묻어 옴(문질러야 지워짐) 등. 마스크 시작 모양을 손님마다 무작위(패턴 8종 + 회전·크기)로 → 어디부터 칠할지가 매번 다름.
2. **성격 하나** (요청 카드에 작은 그림으로 보임) — 손님마다 1개씩, 같은 단계의 '좋은 방법'을 바꿈:

| 성격 | 그림 | 이렇게 하면 좋아함 / 싫어함 |
|---|---|---|
| 간지럼쟁이 | 🪶 | 배·발을 문지르면 금방 다리 찰랑 → 등부터 |
| 겁쟁이 | 💧 | 물 온도 '좋음' 범위가 좁음, 얼굴에 물 닿으면 크게 싫어함 |
| 멋쟁이 | ✨ | 마무리(빗질·리본)를 꼼꼼히 하면 팁 두 배, 90% 대신 98% 를 원함 |
| 졸보 | 💤 | 따뜻한 물이면 목욕대에서 잠듦 — 잠든 동안은 얌전, 드라이어 소리에 깸 |
| 급한 손님 | ⏱ | 빨리 끝내면 팁, 대신 기다림에 약함 |

- 성격은 가게 레벨에 따라 하나씩 열림 (처음엔 성격 없음 → 1일차에 간지럼쟁이 → ...). 새 성격 = 같은 동물도 새로 느껴지게.

### 3.5 주인 손님 (0.3 새로)

사람 대표 질문 "나중엔 사람(주인)이 강아지를 데리고 들어오나?" → **네.** 손님은 **주인 + 동물** 한 쌍.

| 때 | 주인 | 강아지 |
|---|---|---|
| 들어올 때 | 강아지를 안고(또는 줄을 잡고) 접수대로. 머리 위 **말풍선 그림**으로 요청 (🛁 🍑 🎀 등) → 그게 요청 카드가 됨 | 주인 품에서 두리번, 진흙이 뚝뚝 |
| 목욕하는 동안 | 대기 의자에 앉아 기다림 — **목욕대 화면 뒤쪽에 보임** | **주인 쪽을 자주 봄**: 기분 좋으면 꼬리를 흔들고, 싫으면 주인을 보며 낑낑 (기분이 얼굴 말고 몸짓으로도 보임) |
| 끝날 때 | 강아지를 받아 들고 반응: 😊 하트·박수 / 😐 끄덕 / 😣 한숨. **동전을 직접 건넴** (팁 = 반응에 따라) | 주인에게 달려가 **꼬리 빙빙 + 점프** (뽀송한 털이 출렁) |

- 주인은 모양이 단순한 사람 (2등신 장난감, 모자·옷 색만 다르게 6종). 말은 하지 않고 그림·몸짓만 (한/영 번역 필요 없음).
- 단골 주인: 같은 주인이 다른 날 다시 오면 인사 + 지난번 요청을 기억 (가게 키우기와 연결 — 시제품 2 이후).
- **이번 반복(시제품 1-2)에 넣음** — 판단 이유: "몰입이 안 된다"는 불만에 그래픽 다음으로 가장 크게 듣고, 돈 받는 순간을 '화면 위 숫자'가 아니라 **사람에게 고맙다는 말을 듣는 순간**으로 바꿈. 비용은 단순 모형 1개 + 반응 애니메이션 3개라 작음. 접수대·대기 줄·하루 영업은 여전히 시제품 2.

## 4. 하루와 가게 운영

| 시간 | 하는 일 |
|---|---|
| 아침 (준비, 시간 안 감) | 선반 채우기, 도구 정리, 오늘의 특별 손님 확인 |
| **영업 (9시~6시, 실제 약 8분)** | 손님이 대기석에 하나둘 옴 (기다리면 기분이 조금씩 내려감). 내가 처리할 수 있는 만큼 받음 |
| 정산 | 번 돈, 팁, 손님 평점 (별), 가게 경험치 |
| 쇼핑 (컴퓨터 화면) | **소모품** 샴푸·린스(병마다 사용 횟수), **도구** 업그레이드, **서비스** 해금, **꾸미기**, **확장** |

- **소모품**: 샴푸 한 병 = 손님 8마리. 떨어지면 거품이 안 남 → 사 둬야 함 (오니기리의 '재료 관리' 맛). 향 샴푸는 비싸지만 팁 +.
- **도구 업그레이드**: 샤워기 수압(넓게 적심), 드라이어 바람(빨리 부풂), 큰 손(거품 빨리) → **같은 동작이 점점 빨라짐** (반복 지루함 방지, 오니기리 불만 반영).
- **가게 레벨** (손님 만족 경험치): 레벨마다 새 동물·새 서비스·확장이 열림.
- **확장**: 목욕대 2대째, 대기실 소파, 2층 미용실(빗질·다듬기), 마당(큰 개).
- **꾸미기**: 벽지·바닥·타일·화분·간판 — 손님 기분이 조금 오름 (보너스는 작게, 꾸미는 재미 위주).

## 5. 동물과 해금 (정식판 목표)

| 동물 | 특징 (손맛이 달라지는 점) | 해금 |
|---|---|---|
| 강아지 | 기본 | 1일차 |
| 고양이 | 물을 싫어함 — 온도 범위가 좁고, 적시기를 빨리 끝내야 함 | 가게 Lv2 |
| 오리 | 물을 좋아함 — 헹구기가 끝나도 안 나가려 함, 깃털은 문지르기 대신 쓸기 | Lv3 |
| 털뭉치 개 (푸들) | 털이 많아 거품·말리기가 오래, 다듬기 필수 | Lv4 (2층 미용실과 함께) |

## 6. 플레이 타임 (스팀 환불 기준, 목표 유지)

목표: 첫 클리어 **2.5~3시간** (혼자), 전부 **5~6시간**, **2시간 지점에 남은 것이 보이게**.

- 하루 = 준비 1분 + 영업 약 8분 + 정산·쇼핑 1~2분 ≈ **10분**.
- **첫 클리어 = '반짝 펫 쇼 대회'** (가게 Lv8 에 열리는 특별한 하루, 엔딩): 약 **18일**.

| 시점 (혼자) | 날 | 무엇이 새로 나오나 |
|---|---|---|
| 0~10분 | 1일 | 강아지, 목욕 4단계 (적시기·거품·헹구기·말리기) |
| ~20분 | 2일 | 첫 쇼핑: 향 샴푸 하나, 꾸미기 상점 열림 |
| ~30분 | 3일 | **Lv2**: 고양이 + 빗질 |
| ~45분 | 4~5일 | **Lv3**: 오리 + 리본, 첫 사건(오리 떼) |
| ~60분 | 6일 | 목욕대 2대째 확장 (두 마리 동시에 — 바빠짐) |
| **~80~90분** | **8~9일** | **Lv4: 2층 미용실 확장** + 털뭉치 개 + 다듬기(가위) — **가장 큰 변화** (새 층, 새 손맛) |
| ~105분 | 10~11일 | Lv5: 향 고르기, VIP 손님 |
| **120분 (2시간)** | **12일** | Lv6 직전. **남은 것이 화면에 보임**: 상점의 잠긴 칸(마당 확장·대형견·토끼·고슴도치), 펫 쇼 대회 포스터(벽), 손님 도감 빈칸 |
| ~140분 | 14일 | Lv6: **마당 확장 + 대형견** |
| ~160분 | 16일 | Lv7: 토끼, 발톱 |
| **~180분** | **18일** | Lv8: 고슴도치 → **펫 쇼 대회 (엔딩)** |
| 엔딩 뒤 | 자유 영업 | VIP 의뢰 12개(각자 다른 까다로운 요청), 꾸미기 전부, 손님 도감 전부, 업적 15개 |

| 목표 | **혼자** | **4인** |
|---|---|---|
| 가장 큰 변화 (2층 미용실) | 약 1.5시간 | 약 1.2시간 |
| 2시간 지점 | 12일차, 동물 4/7, 확장 2/4 | 15일차, 동물 5/7 |
| **첫 클리어** (펫 쇼 대회) | **약 3시간** | **약 2.5시간** |
| **전부** (VIP 의뢰·도감·꾸미기·업적) | **약 5.5시간** | **약 5시간** |

- 4인이 빠른 이유: 같은 하루에 더 많은 손님 → 돈·경험치가 빨리 참 (날 수는 줄어듦). 4인은 하루 손님 수를 늘려서 한가하지 않게 함.
- **같은 하루 반복으로 늘리지 않음**: 날마다 손님 구성·요청·사건이 다르고, 레벨마다 새 동물·서비스가 열림. 엔딩 뒤 콘텐츠도 '새 요청'(VIP 의뢰)으로.
- 숫자는 추정. 시제품·플레이 테스트로 고침.

## 7. 협동 (고정 조건 유지, 혼자가 기본)

| 인원 | 어떻게 나누나 |
|---|---|
| 1인 | 모든 일을 혼자. 손님 수는 혼자 손에 맞춤 |
| 2인 | **자리마다 한 사람**: 목욕대를 하나씩 맡거나, 한 명은 접수·계산·선반 + 한 명은 목욕 |
| 3~4인 | 접수·계산 / 목욕 / 2층 미용 처럼 자리를 나눔. 한 손님은 한 자리에서 한 사람이 맡음 (단계가 끝나면 다음 자리로 손님을 넘김) |

- 돈·레벨·꾸미기는 **가게 하나를 같이** 씀 (호스트 저장). 동기화는 **결과만**(단계 완료·기분·돈·손님 넘기기) — 붓질 자체는 맡은 사람 화면에서.
- 하루 손님 수 = 인원에 맞게 늘어남 (TUNING_V3).
- 원정 도중 참가 없음 → **하루 영업 도중 참가 없음**, 아침(준비 시간)에만 참가.

| 단계 | 확인할 기둥 | 질문 |
|---|---|---|
| **시제품 1 (1~2주)** | 1. 직접 손으로 하는 느낌 | "손님 한 마리 씻기는 과정 자체가 재밌나?" |

### 8.1 시제품 1 — 손맛

> **"목욕대 작업대 시점에서 강아지 한 마리를 적시고, 거품 내고, 헹구고, 말려서 돈을 받고, 그 돈으로 샴푸 하나를 산다."**

| 넣는 것 | 빼는 것 (시제품 2 이후) |
|---|---|
| 작업대 2개: 목욕대, 컴퓨터(쇼핑). 자리 아이콘 클릭으로 옮기기 | 접수대·대기석·하루 영업 |
| 강아지 1종, 더러움 마스크 (무늬 3종 무작위) | 다른 동물, 성격 |
| 도구 4개: 샤워기(온도 다이얼), 샴푸 병 + 손, 수건, 드라이어 | 빗·가위·리본 |
| 단계 4개: 적시기 → 거품 → 헹구기 → 말리기 (90% 판정), 단계마다 3.1 표의 결과·소리·양념 반응 1개씩 | 탈출 붙잡기 |
| 얼굴 표정 3단계 기분 | 사건 |
| 끝나면 손님이 동전을 떨어뜨림 → 클릭해서 줍기 (요금 + 기분 팁) | 계산대 |
| 컴퓨터(단순 화면)에서 **복숭아 샴푸 사기** → 쓰면 분홍 거품 + 팁 +. 기본 샴푸는 병마다 8마리 | 확장·꾸미기 |
| 다 씻기면 다음 강아지 (끝없이, 몇 마리째인지 표시) | |
| 1인 (오프라인 호스트). 2인 접속 기반은 유지 | 협동 테스트 |
| 효과음 — 직접 만든 임시 소리 (`tools/make_sfx.py`). 문지르는 소리는 마우스 속도에 따라 커짐 | 배경 음악 |

**완료 조건**
1. 목욕대 작업대 시점: 강아지가 화면 가운데 크게, 커서 = 도구. 자리 아이콘(또는 키)으로 컴퓨터 자리로 갔다 올 수 있음.
2. 도구 4개를 휠/1~4/도구걸이로 바꿈, 커서 모양이 도구로 바뀜.
3. 오른쪽 끌기(패드: 오른쪽 스틱)로 회전판이 돌아 반대쪽을 칠할 수 있음.
4. **적시기**: 물줄기가 닿은 곳 마스크가 칠해지며 털이 진해지고(셰이더 '젖음') 진흙 물이 흘러내림. 온도 다이얼 — 차가우면 펄쩍 + 물 튐.
5. **거품**: 병 클릭 = 거품 덩이, 손으로 문지르면 거품 공이 늘며 진흙 마스크가 지워짐. 마우스가 빠를수록 빨리·소리 크게. 한 곳을 오래 문지르면 다리 찰랑, 더 오래면 몸 털기.
6. **헹구기**: 샤워기를 대면 거품 공이 줄어들며 사라짐. 남은 거품이 보임.
7. **말리기**: 수건 → 드라이어, 셰이더 '젖음' → '뽀송'(부풀기 1.0 → 2.0배). 얼굴에 대면 볼 펄럭.
8. 단계 완료 = 칠한 비율 90%, 마지막 10% 구역이 반짝여 보임. 끝나면 카드에 ✓ + "딩". 숫자·막대 없음.
9. 기분 얼굴 3단계가 행동에 따라 바뀜, 끝날 때 기분에 따라 팁.
10. 동전 줍기 → 컴퓨터에서 복숭아 샴푸 구매 → 거품 색·팁 변화. 샴푸가 떨어지면 거품이 안 남.
11. 마스크·기분·돈은 호스트 권한 (혼자 = 오프라인 호스트). 협동 때는 **자리마다 한 사람**이 맡고 **결과(단계 완료·기분·돈)만 동기화** (마스크 자체는 맡은 사람 화면에서만 칠하고, 다른 사람에게는 진행 비율만 보내 대충 보이게).
12. 수치는 `TUNING_V3.md` 키로 `res://data/balance/sim_balance.tres` 한 곳.

| ② 단순 반복 | 3.1 표대로 **단계마다 다른 손동작 6개** (누르고 조준 / 누르는 시간 / 원 그리기 / 쓸어내리기 / 연타 / 휠 거리). 각 10~20초 |
| ③ 조작 불편 | 도구 자동으로 손에, 강아지 자동 회전, **마우스 하나로 끝** (2장) |
| ① 몰입 | **주인 손님** 추가 (3.5). 그래픽은 ChatGPT 2D 먼저 받아 붙일 수 있는 것부터 (CHATGPT_PROMPTS_V3 순서 바꿈): 요청 말풍선·카드·도구 아이콘·간판·배경 그림 |

**완료 조건 (1차 12개에 더하거나 바꾸는 것)**
1. 단계마다 3.1 표의 손동작이 따로 있음. 같은 동작이 두 단계에 쓰이지 않음.
2. 적시기: 누르는 동안 물줄기가 보이고, 휠로 온도. 샴푸: 누르는 시간만큼 덩이가 커짐. 문지르기: 원을 그려야 거품이 큼 (왕복은 거의 안 큼). 헹구기: 위→아래로 쓸면 띠 모양으로 씻김. 수건: 클릭 연타. 드라이어: 휠로 거리, 털이 날림.
3. 각 단계 10~20초, 한 마리 목욕 약 65초 (TUNING_V3 `stage_target_seconds`).
4. 다음 단계 도구가 자동으로 손에 들림. 강아지가 보이는 쪽이 다 되면 저절로 돎. 오른쪽 버튼·숫자 키 없이 끝까지 됨.
5. 주인이 강아지를 데리고 들어와 말풍선 그림으로 요청 → 대기 의자에 앉아 보임 → 강아지가 주인 쪽을 보며 기분을 몸짓으로 → 끝나면 주인 반응 3종 + 동전을 건넴 + 강아지가 주인에게 달려감.
6. 받은 2D 그림(아이콘·카드·말풍선·간판·배경)이 오면 바로 붙일 수 있는 교체 지점.

플레이 테스트지는 [PLAYTEST_V3_PROTOTYPE.md](PLAYTEST_V3_PROTOTYPE.md) 그대로 쓰고, Q2 에 "가장 손맛이 좋은 손동작"을 같이 물음.

### 8.2 시제품 2 — 가게 키우기 순환 (시제품 1 통과 뒤)

> **"하루 영업(8분) → 정산 → 쇼핑(샴푸·도구 업그레이드 1개·꾸미기 3개·목욕대 2대째) → 다음 날 새 손님(고양이)과 성격 1개가 열림. 5일을 해 본다."**

- 넣는 것: 접수대(요청 카드 받기)·대기석, 하루 시간, 정산 화면, 상점 탭 4개(소모품·도구·꾸미기·확장), 가게 레벨 1~3, 고양이, 성격 2개(간지럼쟁이·겁쟁이), 빗질.
- 확인 질문: "5일째 끝에 **하루만 더** 하고 싶었나?", "번 돈으로 **무엇을 살지 고민**했나?", "가게가 **커지는 게 보였나**?"
- 완료 조건과 질문지는 시제품 1 결과를 보고 따로 씀.

## 9. 개발팀: 다시 쓸 것 / 버릴 것

**다시 쓸 것**: 네트워크 계층(`Net`, 오프라인 호스트·ENet·Steam 전송), 메인 메뉴·일시 메뉴, 테마·글꼴(Pretendard), 수치 리소스 방식(`tuning.gd`), 테스트 실행기·CI, 그래픽 교체 지점 방식, 강아지 모형의 상태별 색 바꾸기(`dog_model.gd` → 부위별로 확장), 효과음 만드는 도구(`tools/make_sfx.py`), 방 짓기(`room_builder.gd`).
**버릴 것 (또는 보관)**: 쿼터뷰 고정 카메라·쿼터뷰 이동·플레이어 걷기(작업대 시점이라 캐릭터 이동 없음), 대시, Space 하나로 다 하는 `use_action`, 자동으로 도는 욕조·드라이어 기계(`machine.gd`), 도망·웅덩이·미끄러짐(사건 '탈출 손님'으로 나중에 일부만 다시), 대기석 줄 로직(다음 반복에 계산대와 함께 다시 볼 수 있음).
**새로 필요한 기술 (가장 큰 위험)**: 커서 아래 동물 몸에 **더러움 마스크를 붓질**하는 것 (개발팀 제안: 화면 커서 → 레이캐스트 → 마스크 좌표에 칠하기, 칠한 비율 계산). 첫 주에 이것부터 확인. 1인칭 이동은 쓰지 않으므로 등불 원정대 플레이어 코드는 필요 없음.

## 10. V2(오버쿡드식)를 접은 이유 (2026-10-26)

기록: [playtest/2026-10-26-v2.md](playtest/2026-10-26-v2.md)

- 혼자 했더니 **도망이 한 번도 안 일어남** — 욕조에서 드라이어로 바로 옮기면 내려놓을 일이 없음. 핵심 웃음이 혼자선 안 생기는 구조였음.
- "들어서 옮기기만 하고 재미가 없다" — 기계가 자동이라 **손으로 하는 일이 없었음**.
- 잘 된 것 (V3 에 가져감): 할 일을 바로 알았음, 상태가 색으로 잘 보였음 → **"보면 안다"는 유지**.
