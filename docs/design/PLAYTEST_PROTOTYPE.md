# 시제품 플레이 테스트지

작성: 기획팀 · 2026-10-25 · 대상: GDD 13장 시제품 · 답하는 사람: 사람 대표

**알고 싶은 것 하나: "등불 하나를 나눠 쓰는 것만으로 긴장되고 재밌는가?"**
그리고 실패 패널티(GDD 15장 보류 항목)를 정할 근거.

---

## 진행 방법 (10~20분)

1. **친구와 2인**으로 하는 것이 가장 좋습니다. 친구가 없으면 같은 PC에서 창 두 개(한 창은 가만히 세워 둠)로 혼자 해도 됩니다 — 그 경우 Q1~Q5 는 "혼자" 칸에 답해 주세요.
2. 최소 **3판**: 
   - 1판: 그냥 자유롭게 (규칙 익히기)
   - 2판: 기름을 30으로 줄여서 시작 (개발팀 디버그 키) — 기름 압박 확인
   - 3판: 일부러 한 명이 어둠 속으로 멀리 가 보기 — 추적자·구출 확인
3. 끝나고 **5분 안에** 아래 질문에 답합니다. 생각나는 대로 짧게, 숫자 칸은 1~5 중 하나.
4. 답은 이 파일을 복사해 `docs/design/playtest/YYYY-MM-DD.md` 로 저장하거나, 대표 세션에 그대로 붙여 주세요. 기획팀이 정리합니다.

점수: **1 = 전혀 아니다 · 3 = 보통 · 5 = 아주 그렇다**

## 질문

| # | 질문 | 답 |
|---|---|---|
| Q1 | 등불(큰 빛) 밖으로 나갈 때 **긴장됐나요?** (1~5) | |
| Q2 | **기름이 줄어드는 게 신경 쓰였나요?** 밝기를 낮추거나 손등을 끄는 등 아끼려고 한 적이 있나요? (1~5, 있었다면 언제) | |
| Q3 | 등불을 **누가 들지, 어디로 갈지** 친구와 말로 정한 순간이 있었나요? 몇 번쯤? (없음 / 1~2번 / 자주) | |
| Q4 | 추적자가 다가올 때 **0.8초 준비 동작을 보고 피하거나, 등불로 동료를 구한** 적이 있나요? (예/아니오, 그때 기분 한 줄) | |
| Q5 | 쓰러진 동료를 **구하러 갈지 말지 고민**했나요? 아니면 고민할 것 없이 당연히 갔나요? (고민함 / 당연히 감 / 그냥 둠) | |
| Q6 | 추적자가 **불공평하게** 느껴진 적이 있나요? (어디서 왔는지 모르게 잡힘, 빛 안인데 잡힘 등) (예/아니오, 상황) | |
| Q7 | 한 판이 끝났을 때 **바로 한 판 더** 하고 싶었나요? (1~5) | |
| Q8 | 가장 재밌었던 순간 하나, 가장 지루했던 순간 하나 (각 한 줄) | |
| Q9 | 전원이 쓰러졌을 때, **그동안 모은 걸 전부 잃는다면** 어떤 기분일 것 같나요? (다시 도전하고 싶다 / 짜증 나서 그만둘 것 같다 / 상관없다) | |
| Q10 | 이 방향으로 **계속 만들까요?** (계속 / 고쳐서 다시 시제품 / 다른 방향 검토) | |

## 답에 따라 기획팀이 바꿀 것 (분기)

### 핵심 판정

| 조건 | 판정 | 다음 |
|---|---|---|
| Q1 ≥ 4 **그리고** Q7 ≥ 4 **그리고** Q10 = 계속 | **통과** | 단계 2 (수직 단면) 시작 |
| Q1·Q7 중 하나가 3 이하, Q10 = 계속 또는 고쳐서 | **고쳐서 다시** | 아래 표대로 수치·규칙을 고쳐 시제품 2차 (개발 작업은 수치 리소스 위주) |
| Q1 ≤ 2 **그리고** Q7 ≤ 2, 또는 Q10 = 다른 방향 | **방향 재검토** | 기획팀이 빛·기름 핵심 규칙 대안 2개를 써서 대표에게 제안. 단계 2 시작 안 함 |

### 질문별 처방

| 답 | 무엇이 문제인가 | 기획팀이 바꿀 것 |
|---|---|---|
| **Q1 ≤ 2** (빛 밖이 안 무서움) | 어둠의 대가가 약함 | `dark_gain_unlit` 4 → 6, 추적자 `stalker_detect_range` 20 → 25. 추적자 접근 소리·눈빛 연출 요청 |
| **Q1 = 5 인데 Q7 ≤ 2** (무섭기만 함) | 압박이 너무 셈 | `dark_gain_unlit` 4 → 3, `stalker_attack_windup` 0.8 → 1.0 |
| **Q2 ≤ 2** (기름이 신경 안 쓰임) | 기름이 넉넉함 | `party_oil_start` −20, 또는 `light_lantern_drain_normal` 4 → 5. 기름 게이지를 더 눈에 띄게 |
| **Q2 = 5 + "계속 낮춤으로만 다님"** | 아끼는 게 정답이라 선택이 없음 | 낮춤 반경 5 → 4 (낮춤을 더 위험하게), 키움 소모 8 → 6 |
| **Q3 = 없음** (말할 일이 없음) | 등불이 협동 도구가 아님 | 손등 반경 3 → 2 / 소모 0.5 → 1.0 (각자 다니기 어렵게). 시제품 2차에 '무거운 유물 2인 운반' 1개 추가 검토 |
| **Q4 = 아니오** | 구출 순간이 안 생김 | `stalker_attack_windup` 0.8 → 1.2, 공격 준비 소리 크게 |
| **Q5 = 그냥 둠** | 부활 가치가 낮거나 비용이 큼 | `down_duration` 30 → 45, `oil_revive_cost` 5 → 0 |
| **Q5 = 당연히 감** | 결정이 아님 (나쁘지 않음) | 그대로. 단계 2에서 부활 비용 10 실험 |
| **Q6 = 예** | 정보 부족 | 상황에 따라: 접근 소리·방향 표시 추가, 빛 판정 경계 시각화(바닥 원)를 더 뚜렷하게. 수치보다 연출 문제로 개발팀에 이슈 |
| **Q8** | — | 지루한 순간을 다음 시제품의 1순위 수정 항목으로 |

### 실패 패널티 결정 (GDD 15장 보류 항목)

Q9 와 Q7 을 같이 봅니다.

| Q9 답 | Q7 | 결정 (`penalty_run_income_keep_ratio`) |
|---|---|---|
| 다시 도전하고 싶다 | 아무 값 | **전부 잃음 유지** (0.0) |
| 상관없다 | ≥ 4 | 전부 잃음 유지 (0.0) |
| 상관없다 | ≤ 3 | 실패해도 **25% 남김** (0.25) — 판의 의미를 조금 줌 |
| 짜증 나서 그만둘 것 같다 | 아무 값 | **50% 남김** (0.5) + 빛의 파편 등 목표 유물만 잃음 |

결정한 값은 [TUNING.md](TUNING.md) 8장과 GDD 15장에 적고 "바꾼 기록"에 남깁니다.
혼자 플레이(1인)로만 테스트했다면 패널티는 결정하지 않고 2인 테스트 뒤로 미룹니다 (혼자일 때 체감이 다름).
