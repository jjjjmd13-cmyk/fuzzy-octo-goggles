# 멍냥 목욕탕 V4 — 1인칭 가게 (짧은 기획서)

작성: 기획팀 · 2026-10-30 · 판 0.2 (시간 제한 빼고 대기 참을성으로 압박) · **1인용** (사람 대표 결정, PR #58)
이전 판: [GDD_V3.md](GDD_V3.md) (작업대 시점) — 아래 '바꾼 이유'만 남기고 V4 가 대신함.

## 바꾼 이유 (사람 대표 플레이, 2026-10-30)

1일차도 다 못 함: "원 그리기가 너무 답답", "샤워기·샴푸·손이 2D 커서라 별로", "내가 생각한 느낌이 아님".
→ **내 눈으로 가게를 걷고, 3D 도구를 손에 들고, 짧고 시원하게 씻긴다.**

## 재미 4가지

1. **가게 키우기** — 번 돈으로 확장·새 도구·새 손님
2. **귀여운 동물 반응** — 씻길 때마다 바로 보이는 반응
3. **바쁜 가게 돌리기** — 손님이 몰리면 걷고, 집고, 씻고, 계산하느라 바쁨
4. **꾸미기·결과물** — 리본 달아 보낸 강아지, 내가 꾸민 가게

## 조작 (Dooms Hair Salon·오니기리 샵 시뮬처럼)

| 입력 | 하는 일 |
|---|---|
| WASD + 마우스 | 1인칭으로 걷고 둘러보기 |
| 왼쪽 클릭 (대상 보고) | 집기 / 내려놓기 / 손님 데려가기 / 버튼 |
| 왼쪽 누르고 있기 (도구 든 채) | 도구 쓰기 — 화면 가운데 조준점이 닿는 곳에 |
| 마우스 움직이기 (누른 채) | 쓸기 — **움직인 만큼 바로 칠해짐** (원 그리기 없음) |
| Q | 든 도구 내려놓기 (선반 쪽이면 제자리로) |

- 도구는 **3D 모형을 손에 든 채로** 화면 오른쪽 아래에 보임 (떠 있는 2D 커서 없음).
- 패드: 왼쪽 스틱 걷기, 오른쪽 스틱 시선, RT 쓰기, A 집기.

## 하루 흐름

```
문 열기(현관 팻말 클릭) → 손님(주인+강아지) 들어옴 → 접수대에서 요청 말풍선 보기
→ 강아지 클릭 = 따라옴 → 목욕통에 넣기 → 선반에서 도구 집어 씻기(아래 표)
→ 드라이 → (요청이면) 리본 → 강아지 클릭 = 주인에게 데려가기 → 계산대 동전
→ 영업 끝 → 정산 → 가게 컴퓨터에서 구매·확장 → 다음 날
```

## 씻기 — 시간 제한 없음 (빨리 할수록 좋을 뿐)

| 단계 | 도구 | 하는 것 | "시원한" 손맛 |
|---|---|---|---|
| 적시기 | 샤워기 | 누르고 쓸기 | 물줄기 + **물 튀김**, 진흙물이 주르륵, 털이 납작·진해짐 |
| 거품 | 샴푸 | 누르고 쓸기 | 쓰는 곳마다 **거품이 '팍' 부풀어 붙음**, 뽀글 소리 |
| 헹구기 | 샤워기 | 누르고 쓸기 | 거품이 **한 덩이씩 미끄러져 떨어짐**, 뽀득 소리 |
| 말리기 | 드라이어 | 누르고 쓸기 | 털이 **뽕 하고 부풀어** 솜뭉치, 귀가 펄럭 |
| (꾸미기) | 리본 | 머리에 클릭 | 딸랑 + 강아지가 거울 보듯 고개 갸웃 |

- 붓은 **크게** (몸의 1/5 쯤을 한 번에). 다 칠하지 않아도 **80%** 면 다음 단계 — 남은 곳은 반짝.
- 단계별 시간 목표·시간 제한은 **없음** (사람 대표 결정). 붓이 커서 익숙하면 자연히 빨라짐 — 압박은 아래 '대기 손님 참을성'에서만 옴.
- 샤워기 하나로 적시기·헹구기를 같이 쓰므로 도구는 **3개**(샤워기·샴푸·드라이어) + 리본.

## 압박 = 대기 손님 참을성 (손님마다 다름)

- 목욕 중인 손님은 기다려 줌. **대기 의자의 손님**만 시간이 지나면 떠남 → 빨리 씻어야 다음 손님을 받음.
- 손님(주인)마다 성격이 하나, **머리 위 표시**로 처음부터 보임. 시간이 줄면 표시가 깜빡이고 주인 몸짓이 바뀜 (시계 보기 → 발 구르기 → 일어섬).
- 메모: 성격별로 다른 표시로 시작하고, **플레이 뒤 모두 같은 게이지로 통일할지 결정** (사람 대표).

| 성격 | 머리 위 표시 | 참을성 (대기) | 나올 비율 | 팁 |
|---|---|---|---|---|
| **급함** | 🔴 빨간 시계 | **30초** | 20% | 제때 받으면 팁 + |
| **보통** | 🟡 노란 시계 | 90초 | 45% | 보통 |
| **느긋** | 🟢 초록 잎 | 180초 | 25% | 보통 |
| **끝까지** | 표시 없음 (☕ 컵) | 안 떠남 | 10% | 적음 — 대신 마음 편한 손님 |

- 숫자(초)는 첫 값이고 플레이로 고침. 첫날은 보통·느긋만, 2일차부터 급함이 섞임 (처음부터 놓치지 않게).
- 떠난 손님은 그날 수입 0. 화내지 않고 "다음에 올게요" 손 흔들기 (귀여운 분위기 유지).

## 동물 반응 (짧게, 자주, 방해 안 하게)

- 단계 시작마다 하나: 물 → 깜짝 놀라 귀 쫑긋 / 거품 → 꼬리 살랑 / 헹굼 끝 → **몸 털기(물이 화면에 튐)** / 말림 → 뽕 부풀고 행복한 얼굴
- 반응은 0.5~1초, 그동안에도 계속 씻을 수 있음.
- 기분은 얼굴로만 (V3 와 같음): 대충 하면 😐, 잘하면 😊 → 팁. → 자세한 규칙은 아래 '기분·반응' 절.

## 가게 키우기 (시제품 뒤, 방향만)

목욕통 2대째 → 대기 소파 → 미용실(가위·빗) → 고양이·다른 동물, 꾸미기(벽지·바닥·화분). 하루 손님 수가 늘어 **바빠짐**. V3 의 정산·쇼핑·하루 흐름·저장 코드는 그대로 다시 씀.

- 빼는 것: 손님 주인·대기 참을성·접수·계산·하루·쇼핑·리본 — 대표가 "이 느낌 맞다"고 한 뒤에.

## 시제품 2 — 손님 한 바퀴와 하루 (2026-11-02, 사람 대표가 첫 시제품 승인)

> **"손님에게 가서 클릭해 강아지를 받고 → 목욕 → 주인에게 클릭해 돌려주면 돈과 팁을 받는다. 하루 8분 영업이 끝나면 간단 정산."**

- 손님(주인+강아지)이 들어와 대기 의자에 앉음 → 주인을 클릭하면 강아지가 내 손(또는 뒤를 따라옴)으로 → 목욕통에 넣고 씻김 → 강아지를 클릭해 들고 주인에게 가서 클릭 = 돌려주기.
- 돌려줄 때 주인 반응 + 동전: **요금 + 기분 팁 + 빠른 팁** (빨리 돌려줄수록 큼, 급한 손님은 2배). 수치는 TUNING_V4 3장.
- 하루 8분. 끝나면 새 손님이 안 오고, 남은 손님은 끝까지 받을 수 있음 → 정산 화면 (받은·떠난 손님, 요금, 팁, 합계).
- 빼는 것 (그다음): 리본·꾸미기·확장·쇼핑·저장.
- 사람 대표가 볼 것: "손님을 받고 돌려주는 한 바퀴가 바쁘고 재밌나? 돈이 모이는 게 기분 좋나?"


## 기본 순서와 도구 키우기 (2026-11-02, 사람 대표 결정)

**목욕·드라이·빗질은 1일차부터 매번 하는 기본 순서.** 미용(털 자르기)만 손님 요청.
진행은 **더 좋은 도구를 사서 더 빨리·더 시원하게.** 매번 다른 것은 **손님 쪽**(크기·털 길이·고양이·성격·미용 요청).

```
적시기 → 거품 → 헹구기 → 드라이 → 빗질 → (요청이면) 미용 → 돌려주기
```

- 기본 도구로도 **단계 하나 5~8초** (느려서 답답하면 안 됨). 한 마리 약 35초.
- 수건은 뺌 (드라이기가 처음부터 있음).

| 단계 | 기본 (1일차) | 2단계 | 3단계 | 업그레이드하면 |
|---|---|---|---|---|
| 적시기·헹구기 | 작은 샤워기 | 넓은 샤워기 | 레인 샤워기 | 물줄기가 넓어지고 굵어짐, 물 튀김이 커짐 |
| 거품 | 샴푸병 | 거품 펌프 | 거품 대포 | 거품이 덩어리 → 뭉게구름 → **펑 터지며 한 번에 덮음** |
| 드라이 | 작은 드라이기 | 큰 송풍 드라이기 | (없음) | 바람이 넓어지고 털이 더 크게 **뽕** |
| 빗질 | 일반 빗 | 슬리커 브러시 | 전동 브러시 | 엉킨 뭉치가 더 크게 쓱 풀리고 반짝임이 커짐 |
| 미용 | (없음) | 가위 | — | 가위를 사면 미용 요청 손님이 가끔 옴 |

### 미용 (요청 손님만) — 실제로 자르기 (2026-11-11 사람 대표 플레이 의견으로 고침)

- 가위를 산 다음 날부터, 손님 약 1/4 이 요청 카드에 **모양 실루엣**을 들고 옴 (곰돌이컷·사자컷·여름컷).
- **바뀐 점**: 정해진 털 다발을 '클릭해서 없애기' 가 아니라, **가위로 털을 직접 잘라 모양을 만든다**. 빗질이 끝나면 털이 길게 자란 상태 (털 길이 1.0), 목표 모양까지 잘라 냄. 개발팀이 조작 시제품을 먼저 만들고 플레이로 값을 고침.

**조작 (마우스 하나)**
- **누른 채 지나가기** = 사각사각 연속으로 자름 (빗질·거품처럼 붓으로 칠하듯). **클릭 한 번** = 사각 한 번 (조금만 다듬기).
- 한 번 지나가면 그 자리 털이 **안내선까지 쓱** 잘림 (한 번에 최대 0.25 만큼). 안내선에 닿은 뒤에도 같은 곳을 계속 누르고 있으면 조금씩 더 짧아짐 (= 지나치게 자르기, 아래).
- **잘린 털이 떨어짐**: 털 색 조각이 팔랑 떨어져 목욕통 바닥에 쌓임 → 돌려줄 때 '쓱' 사라짐. 소리 사각사각 (자르는 양만큼 빠르게).

**목표 모양 안내선**
- 미용 단계에 들어가면 털 위에 **목표 모양이 반투명 하늘색 껍질**로 겹쳐 보임 (요청 카드 실루엣과 같은 모양). 자를 곳 둘레에는 점선.
- 안내선에 딱 맞은 곳은 털이 살짝 반짝 (맞았다는 표시). 다 맞으면 "다 됐어요!" 반짝 + 손님이 뽐냄. 그 전에도 언제든 돌려줄 수 있음.

**목표 털 길이 (1.0 = 미용 전, 0.3 = 가장 짧게)**

| 모양 | 머리 | 몸 | 다리 | 꼬리 | 한 줄 |
|---|---|---|---|---|---|
| 곰돌이컷 | **0.55** (얼굴 둥글게) | 0.8 | 0.8 | 1.0 | 얼굴 둘레를 동그랗게 |
| 사자컷 | 1.0 (갈기) | **0.35** | **0.35** | 1.0 (끝 방울) | 몸만 짧게, 머리·꼬리는 남김 |
| 여름컷 | 0.45 | **0.35** | 1.0 (보송) | 0.45 | 다 짧게, 다리만 보송 |

**실패 없음 — 결과는 팁과 기분만 조금**
- 맞은 정도 = **안내선 ±0.08 안에 든 털 면적 비율**. 0.7 이상 '비슷함', 0.95 이상 '똑같음' (기존 `v4_trim_match_at` 그대로, 뜻만 면적 비율로) → 팁 0 / 10 / 25 (`v4_trim_match_tip` 그대로).
- **지나치게 자르기**: 안내선보다 0.15 넘게 짧은 면적이 20% 넘으면 손님이 살짝 시무룩 → 기분 −1 (한 번만). 그 밖의 벌은 없음. 털은 다음 방문엔 다시 자라 있음.
- 미용 요금 40 (`v4_price_trim`) 은 결과와 상관없이 받음.
- 목표 시간: 기본 가위로 **15~25초**. 멋쟁이 성격은 요청이 1.5배 잦음 (`v4_dandy_trim_mult` 그대로).
- 수치: TUNING_V4 3-1 아래 '미용 — 실제로 자르기' (제안).

## 손동작 다시 정리 — 단계마다 다르게, 힘들지 않게 (2026-11-04, 사람 대표 플레이 피드백)

피드백: "수건을 다시 넣자, 그런데 그냥 누르고 있는 건 재미없다" / "빗질은 위아래로, 너무 힘들지 않게" / "업그레이드가 2번 사면 끝나는 느낌".
점검: 지금은 적시기·거품·헹굼·드라이가 모두 **"누른 채 쓸기"** 하나라 V3 처럼 같은 동작이 반복됨. → 아래처럼 **단계마다 동작 하나씩** (원 그리기 같은 정밀 동작은 없음).

| 순서 | 단계 | 손동작 | 보이는 변화 | 시간 |
|---|---|---|---|---|
| 1 | 적시기 | **누른 채 쓸기** (물줄기 조준) | 털이 진해지고 납작, 흙탕물 | 4~6초 |
| 2 | 거품 | **한 곳에서 짧게 좌우로 비비기** (마우스를 작게 흔들기) | 비빈 자리에서 거품이 몽글몽글 커져 옆으로 번짐 | 4~6초 |
| 3 | 헹굼 | **위 → 아래로 쓸어내리기** (물로 거품을 아래로 밀기) | 거품이 덩어리째 주르륵 미끄러져 떨어짐 | 3~5초 |
| 4 | **수건** (다시 넣음) | **톡톡 두드리기** (클릭 연타, 누를 때마다 꾹) | 두드린 자리 물방울이 뚝뚝 떨어지고 털이 덜 젖어 보임 | **2~4초** |
| 5 | 드라이 | 누른 채 대고 **다가가기·물러서기** (가까울수록 빠르고 털이 크게 날림, 너무 붙으면 찡그림) | 털이 바람 방향으로 날리며 뽕 | 4~6초 |
| 6 | 빗질 | 엉킨 뭉치에 대고 **위 → 아래로 2~3번 쓸기** (털 방향이면 1번 덜) | 뭉치가 쓱 풀리며 반짝 | 뭉치당 1초, 3~5초 |
| 7 | 미용 (요청만) | 모양 선을 따라 **클릭** (싹둑) | 털 다발이 떨어지고 모양이 남음 | 지금 그대로 |

- 같은 손동작이 두 단계에 겹치지 않게 함 (헹굼과 빗질은 둘 다 '위→아래'지만 헹굼은 넓게 한 번에, 빗질은 뭉치 하나씩 짧게).
- 동작이 서툴러도 진행은 됨 (방향·속도가 맞으면 **더 빨리** 될 뿐). 정밀도로 막지 않음.
- 한 마리 기본 도구 약 30~40초.

## 가게 밖·택배 (2026-11-04, 사람 대표 요청 — 꾸미기와 같이 들어감)

"가게 안에서 밖으로도 나갈 수 있게. 돈 주고 물건을 사면 택배로 와서, 밖에서 가지고 들어오게." **산 물건을 내 손으로 들고 들어와 여는 맛.**

### 가게 밖 — 작게: 가게 앞 마당

- **문**: 지금 손님이 들어오는 **오른쪽 벽 문 = 가게 정문**. 플레이어도 이 문으로 나감 (가까이 가면 자동으로 열림, 문 종 "딸랑"). 새 문은 만들지 않음.
- **마당**: 정문 밖 약 5 m × 7 m (방 좌표 x = 4 ~ 9, z = −3.5 ~ 3.5). 보도블록 바닥, 가게 바깥 벽(창문 2개·차양·바깥 간판), **택배 매트**(문 왼쪽, 손님 길에서 떨어진 곳), 우편함, 가로등 1개, 마당 끝 낮은 울타리 + 화단. 울타리 너머는 찻길 (못 나감, 트럭만 지나감). 찻길 건너편에는 **들어갈 수 없는 이웃 건물** (빵집·꽃집·카페·집 2채·인도 소품, 보기만 하는 배경 — 2026-11-06 사람 대표 요청, `ART_SLOTS.md` 4-7).
- **손님과 안 부딪히게**: 손님은 찻길 → 마당 → 정문으로 **정해진 한 줄 길**만 걸음 (문 바로 앞 z ≈ 2.6 줄). 택배 매트는 그 길 반대쪽. 손님과 플레이어는 서로 통과 (막히지 않음).
- **영업 중에도 나갈 수 있음.** 단, 시간은 계속 흐르고 대기 손님 참을성도 줄어듦 (밖에 오래 있으면 손해일 뿐, 막지는 않음).

### 아침 준비 시간 (새로)

- 다음 날이 되면 **아침**: 시계가 멈춰 있고 손님이 오지 않음. 이때 택배를 들이고 꾸밈.
- 정문 안쪽에 걸린 **영업 팻말**(해 / 달 그림)을 클릭해서 뒤집으면 영업 시작 → 8분 시계가 감.
- 팻말을 뒤집을 때 밖에 상자가 남아 있으면 한 줄 알림: "택배 상자 2개가 아직 밖에 있어요" + [그래도 열기] [가지러 가기]. **벌칙 없음** — 상자는 매트 위에 쌓여 있기만 하고, 영업 중·영업 뒤 언제든 가져와도 됨.

### 택배 흐름

1. 하루 끝 가게(도구·꾸미기 탭)에서 삼 → 정산 화면에 "내일 아침 도착 📦 3개".
2. 다음 날 아침 시작하자마자 작은 배달 트럭이 찻길에 서서 상자를 매트에 내려놓고 "빵빵" 하고 떠남 (약 4초, 기다릴 필요 없음). 우편함 깃발이 올라감.
3. 상자를 클릭해서 **들기 (한 번에 하나, 두 손)**. 들고 있으면 도구를 못 쓰고, 큰 상자는 조금 느리게 걸음.
4. 가게 안(문턱 안쪽)에서 클릭하면 **상자 열기** (밖에서는 "안에서 열어요" 안내).
5. 열면:
   - **도구** → 상자에서 튀어나와 선반의 제자리로 날아가 놓임 (이전 단계 도구와 바로 바뀜).
   - **꾸미기** → 그 범주의 정해진 자리로 날아가 놓임 (#91: 범주마다 자리 하나). 벽지·바닥은 방 끝에서 끝까지 '쓱' 바뀜.
   - 빈 상자는 납작하게 접혀 사라짐.
- **상자 크기 3종**: 작은 상자 = 도구·벽 장식, 중간 = 화분·조명·간판·러그, 큰 상자 = 목욕통·선반·카운터·벽지·바닥.
- 같은 날 산 것은 **한 상자에 묶지 않음** (하나씩 여는 재미). 대신 너무 많으면 귀찮으니 아래 수레.

### 귀찮지 않게 — 수레 (**시험용, 플레이 뒤 결정**)

- 사람 대표 의견: "하루 끝에 바로 들고 들어가니 필요 없을 수도." → 일단 넣어 보고, 플레이 뒤 쓸모 있으면 남기고 아니면 뺌.
- **택배 수레** (도구 가게에서 150): 상자 3칸 (큰 상자 = 2칸). 수레 손잡이를 잡고 밀고 다니며, 매트 앞에서 클릭하면 상자가 수레에 척척 실림. 가게 안에서 클릭 한 번 = 맨 위 상자 열기.
- 수레 자신이 **첫 택배로 옴** (큰 상자) → 열면 수레가 나옴.
- 수레가 없어도 상자는 보통 하루 1~3개라 2~3번 오가면 끝 (마당이 작아서 왕복 약 10초).

### 재미 포인트 (짧게)

- 상자 열기: 뚜껑이 퐁 열리고 종이 꽃가루 + 물건이 위로 튀어 한 바퀴 돎 + "짜잔" 소리. ★3 꾸미기·5단계 도구는 꽃가루가 무지개색.
- 상자를 흔들면 (들고 마우스를 좌우로) 달그락 소리 — 무엇이 들었는지 미리 알 수 있음.
- 대기 중인 강아지 손님이 **안 연 상자**가 가게 안에 있으면 가끔 다가가 킁킁 냄새 맡고 꼬리 흔듦 (참을성에는 영향 없음).
- 우편함 깃발, 트럭 "빵빵", 문 종 "딸랑" — 아침 시작이 바로 알 수 있게.

### 이번에 안 하는 것

배송 날짜 고르기·빠른 배송, 밖에서 하는 일(산책·손님 마중), 동네 다른 가게, 상자 쌓아 두기 꾸미기, 날씨.

- 수치: TUNING_V4 3-4. 그래픽: `docs/art/ART_SLOTS.md` 4-3, 요청문 `docs/art/ORDER_V4_OUTSIDE.md`.

## 샴푸·빗 닳음 — 작은 관리 (2026-11-04, 사람 대표 요청, 제안)

**목표**: 가게를 '돌보는' 느낌을 조금만. 막히는 일은 없고, 관리 행동은 **하루 1번 이하** (보통 이틀에 한 번).

### 샴푸 = 소모품

- 한 병 = **20마리분** (80). 큰 통 = **50마리분** (180, 마리당 조금 쌈). 처음엔 1병이 있음.
- 거품 단계 한 번에 1마리분 씀. 거품 도구 단계가 높으면 덜 씀: 3·4단계 ×0.75, 5단계 ×0.5 (비싼 도구가 샴푸도 아껴 줌).
- **사람 대표 결정: 샴푸 없음 = 요금 거의 없음 (막지는 않음).** 샴푸가 없으면 거품 단계를 건너뛰고 씻김. 요금 40 → **10**, 팁 0, 주인이 시무룩 + "샴푸 냄새가 안 나요…".
  - 막지 않는 이유: 샴푸가 하루 중간에 떨어지면 택배가 다음 날 아침에야 옴 → 완전히 막으면 그날 남은 시간이 통째로 버려짐.
- 사기: 하루 끝 가게 → 다음 날 아침 택배 (작은 상자). 상자를 열면 선반의 샴푸가 가득 참.
- **떨어지기 전 알림 (강하게)**:
  - 정산 화면: "남은 샴푸 **N마리분**". **5마리분 이하**면 노란 글씨 + [샴푸 1병 사기] 버튼 하나 (가게 탭에 안 들어가도 됨). 0 이면 빨간 글씨.
  - 영업 중: 남은 **3마리분**이 되는 순간 한 번 알림 "샴푸가 3마리분 남았어요" (화면 위 말풍선 + 병 눈금 깜빡).

### 빗 = 닳음

- 빗질할 때마다 빗살이 조금 닳음 (한 마리 = 1). **부러지지 않음.**
- 수명의 절반까지는 그대로, 그 뒤로 0 이 될 때까지 빗질 속도가 천천히 ×0.7 까지 느려짐.
- 바꾸기: 가게에서 **새 빗살** (싸게) → 택배 → 열면 빗이 새것.
- 단계별 수명 — **비싼 도구는 오래 가거나 안 닳음**:

| 빗 단계 | 1 일반 빗 | 2 슬리커 | 3 쌍빗 | 4 전동 | 5 반짝 전동 |
|---|---|---|---|---|---|
| 수명 (마리) | 30 (약 3~4일) | 60 (약 7일) | 120 (약 2주) | 안 닳음 | 안 닳음 |
| 새 빗살 값 | 20 | 30 | 50 | — | — |

### 표시

- **샴푸병**: 손에 들면 병 옆에 작은 눈금 5칸 (게임이 그림, 그래픽 따로 없음). 선반 위 샴푸병도 같은 눈금.
- **빗**: 손잡이 끝 작은 점 색 초록 → 노랑 (절반) → 주황 (거의 닳음). 안 닳는 빗은 점 없음.

### 귀찮음·경제 확인

- 관리 행동: 샴푸 1병 = 하루 약 9마리 → **2일에 1번**. 일반 빗 3~4일에 1번, 슬리커 1주에 1번 → 둘이 겹쳐도 하루 1번 이하 (정산 버튼 하나로 끝). 4단계 빗부터 빗 관리 없음.
- 비용: 샴푸 마리당 4 × 하루 9마리 ≈ **36 (수입의 약 8~9%)** + 빗 하루 약 3~6 → **하루 약 40 (수입 400~450 의 약 10%)**. 샴푸를 안 사면 한 마리 40 → 10 이라 하루 손해 약 300 → 사는 게 훨씬 이득. 거품 3단계부터 약 27, 5단계 약 18 → 업그레이드할수록 관리비도 줄어 "좋은 도구를 산 보람".
- 도구 5단계 8,100 은 관리비 10% 를 빼면 약 21일 → 하지만 도구가 좋아질수록 하루 손님이 늘어 (한 마리 35초 → 14초) 수입도 오름. 18일에 도구 전부 + 꾸미기 일부가 맞는 그림. 플레이 뒤 다시 봄.
- 수치: TUNING_V4 3-5.

## 고양이·동물 성격 (2026-11-04, 사람 대표 순서 4 — 개발팀 질문에 답)

### 싫어함 → 얼굴 (이 절의 기분 규칙, 간단하게)

- 고양이·성격의 규칙을 어기면 **싫어함 1** (짧은 반응 + 머리 위 작은 💢). 씻기는 멈추지 않음.

- 성격이 없는 강아지는 지금처럼 싫어함이 생기지 않음 → 늘 😊.
- **'기분·반응' (다음 순서) 과 나눌 선**: 여기서는 "무엇을 싫어하나 + 싫어함 수 → 얼굴 3단계" 만. 반응 애니메이션 늘리기, 성격 없는 손님의 일반 기분(대충 씻기·오래 걸림 등), 기분 표시 연출은 '기분·반응' 에서 정함 (그때 이 셈법을 대신할 수 있음).

| 🚿 **샤워 무서움** | 머리·등부터 적시면 싫어함 → **발부터** 적셔야 함 (발 → 몸 순서면 괜찮음) | 발이 아니어도 처음 2초만 조심 | 물줄기를 앞발로 톡톡 치며 놂 |

| 🧺 **수건 무는 손님** | 수건 톡톡 중 가끔 수건을 물고 당김 → 마우스를 살살 좌우로 흔들면 놓음 (벌점 없음, 조금 느려질 뿐) | 덜 자주 묾 | 줄다리기 놀이 (흔들면 꼬리 붕붕, 좋아함 +1, 한 번) |

- 성격의 '한 단계 쉬워짐' (신뢰 친함부터): 간지럼 0.6 → 0.9초 · 겁쟁이 얼굴 반경 0.12 → 0.08 m · 고양이 젖은 시간 40 → 55초, 머리에 물은 싫어함 아님 (반응만).
- 버릇이 있는 단골: 24마리 중 9마리 (버릇마다 3마리). 버릇은 단골 카드에 처음 겪은 뒤 표시.

### 대표 단골 3마리 (특히 개성 있게)

| 단골 | 처음 오는 날 | 성격·버릇 | 처음 (낯가림) | 단짝이 되면 | 주인 |
|---|---|---|---|---|---|
| **몽실** (회색 강아지) | 5일차 (겁쟁이가 열리는 날의 2번째 손님) | 💧 겁쟁이 + 🚿 샤워 무서움 | 주인 다리 뒤에서 덜덜, 목욕대에서 눈 꼭 감음 | 먼저 목욕대로 뛰어올라 앉아 기다림 | 할머니 — "우리 몽실이가 여기만 오면 씩씩해져요" |
| **나비** (회색 고양이) | 3일차 (고양이가 열리는 날의 2번째 손님) | 🐱 고양이 + 💨 드라이 소리 예민 | 도도하게 고개 돌림, 드라이를 켜면 귀가 납작 | 드라이 바람에 눈 감고 골골, 끝나면 내 손에 머리 비빔 | 바쁜 회사원 — "나비가 집에서도 이 가게 얘기를 해요 (?)" |

- 세 마리는 다른 단골보다 2배 자주 옴 (18일에 약 10번) → 18일 안에 단짝까지 가는 이야기가 확실히 보임.
- 대사는 주인이 짧게 (한 줄, 번역 키). 단계마다 1~2줄.

### 사진첩에 '관계' 기록

- 단골 카드에 사진 두 장을 나란히: **첫 방문** 사진 ↔ **최근** 사진 (가장 좋은 사진은 그대로 쪽 칸에).
- **'처음 ~한 날'** 기록 (작은 스티커 + 일차):
  - 처음 온 날 · 처음 🤩 · 처음 좋아하는 곳을 찾은 날 · 익숙함·친함·단짝이 된 날
  - 버릇 넘은 날: 샤워 무서움 → "처음으로 무서워하지 않고 적신 날", 드라이 예민 → "처음으로 드라이를 끝까지 편하게 한 날", 수건 → "처음으로 수건 놀이를 한 날"
  - 처음 미용 · 처음 액세서리를 좋아한 날
- 저장 (`album` 단골 칸에 더함): `"trust": 0~3`, `"trust_pts"`, `"first": {사진 정보}`, `"recent": {사진 정보}`, `"moments": [{"id": "trust_2", "day": 9}, …]`.
