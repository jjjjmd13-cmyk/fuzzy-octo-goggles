# 멍냥 목욕탕 V4 — 1인칭 가게 (짧은 기획서)

작성: 기획팀 · 2026-10-30 · 판 0.2 (시간 제한 빼고 대기 참을성으로 압박) · **1인용** (사람 대표 결정, PR #58)
이전 판: [GDD_V3.md](GDD_V3.md) (작업대 시점) — 아래 '바꾼 이유'만 남기고 V4 가 대신함.

## 바꾼 이유 (사람 대표 플레이, 2026-10-30)

1일차도 다 못 함: "원 그리기가 너무 답답", "샤워기·샴푸·손이 2D 커서라 별로", "내가 생각한 느낌이 아님".
→ **내 눈으로 가게를 걷고, 3D 도구를 손에 들고, 짧고 시원하게 씻긴다.**

## 재미 4가지

1. **가게 키우기** — 번 돈으로 확장·새 도구·새 손님
2. **귀여운 동물 반응** — 씻길 때마다 바로 보이는 반응
3. **바쁜 가게 돌리기** — 손님이 몰리면 걷고, 집고, 씻고, 계산하느라 바쁨
4. **꾸미기·결과물** — 리본 달아 보낸 강아지, 내가 꾸민 가게

## 조작 (Dooms Hair Salon·오니기리 샵 시뮬처럼)

| 입력 | 하는 일 |
|---|---|
| WASD + 마우스 | 1인칭으로 걷고 둘러보기 |
| 왼쪽 클릭 (대상 보고) | 집기 / 내려놓기 / 손님 데려가기 / 버튼 |
| 왼쪽 누르고 있기 (도구 든 채) | 도구 쓰기 — 화면 가운데 조준점이 닿는 곳에 |
| 마우스 움직이기 (누른 채) | 쓸기 — **움직인 만큼 바로 칠해짐** (원 그리기 없음) |
| Q | 든 도구 내려놓기 (선반 쪽이면 제자리로) |

- 도구는 **3D 모형을 손에 든 채로** 화면 오른쪽 아래에 보임 (떠 있는 2D 커서 없음).
- 패드: 왼쪽 스틱 걷기, 오른쪽 스틱 시선, RT 쓰기, A 집기.

## 하루 흐름

```
문 열기(현관 팻말 클릭) → 손님(주인+강아지) 들어옴 → 접수대에서 요청 말풍선 보기
→ 강아지 클릭 = 따라옴 → 목욕통에 넣기 → 선반에서 도구 집어 씻기(아래 표)
→ 드라이 → (요청이면) 리본 → 강아지 클릭 = 주인에게 데려가기 → 계산대 동전
→ 영업 끝 → 정산 → 가게 컴퓨터에서 구매·확장 → 다음 날
```

## 씻기 — 시간 제한 없음 (빨리 할수록 좋을 뿐)

| 단계 | 도구 | 하는 것 | "시원한" 손맛 |
|---|---|---|---|
| 적시기 | 샤워기 | 누르고 쓸기 | 물줄기 + **물 튀김**, 진흙물이 주르륵, 털이 납작·진해짐 |
| 거품 | 샴푸 | 누르고 쓸기 | 쓰는 곳마다 **거품이 '팍' 부풀어 붙음**, 뽀글 소리 |
| 헹구기 | 샤워기 | 누르고 쓸기 | 거품이 **한 덩이씩 미끄러져 떨어짐**, 뽀득 소리 |
| 말리기 | 드라이어 | 누르고 쓸기 | 털이 **뽕 하고 부풀어** 솜뭉치, 귀가 펄럭 |
| (꾸미기) | 리본 | 머리에 클릭 | 딸랑 + 강아지가 거울 보듯 고개 갸웃 |

- 붓은 **크게** (몸의 1/5 쯤을 한 번에). 다 칠하지 않아도 **80%** 면 다음 단계 — 남은 곳은 반짝.
- 단계별 시간 목표·시간 제한은 **없음** (사람 대표 결정). 붓이 커서 익숙하면 자연히 빨라짐 — 압박은 아래 '대기 손님 참을성'에서만 옴.
- 샤워기 하나로 적시기·헹구기를 같이 쓰므로 도구는 **3개**(샤워기·샴푸·드라이어) + 리본.

## 압박 = 대기 손님 참을성 (손님마다 다름)

- 목욕 중인 손님은 기다려 줌. **대기 의자의 손님**만 시간이 지나면 떠남 → 빨리 씻어야 다음 손님을 받음.
- 손님(주인)마다 성격이 하나, **머리 위 표시**로 처음부터 보임. 시간이 줄면 표시가 깜빡이고 주인 몸짓이 바뀜 (시계 보기 → 발 구르기 → 일어섬).

| 성격 | 머리 위 표시 | 참을성 (대기) | 나올 비율 | 팁 |
|---|---|---|---|---|
| **급함** | 🔴 빨간 시계 | **30초** | 20% | 제때 받으면 팁 + |
| **보통** | 🟡 노란 시계 | 90초 | 45% | 보통 |
| **느긋** | 🟢 초록 잎 | 180초 | 25% | 보통 |
| **끝까지** | 표시 없음 (☕ 컵) | 안 떠남 | 10% | 적음 — 대신 마음 편한 손님 |

- 숫자(초)는 첫 값이고 플레이로 고침. 첫날은 보통·느긋만, 2일차부터 급함이 섞임 (처음부터 놓치지 않게).
- 떠난 손님은 그날 수입 0. 화내지 않고 "다음에 올게요" 손 흔들기 (귀여운 분위기 유지).

## 동물 반응 (짧게, 자주, 방해 안 하게)

- 단계 시작마다 하나: 물 → 깜짝 놀라 귀 쫑긋 / 거품 → 꼬리 살랑 / 헹굼 끝 → **몸 털기(물이 화면에 튐)** / 말림 → 뽕 부풀고 행복한 얼굴
- 반응은 0.5~1초, 그동안에도 계속 씻을 수 있음.
- 기분은 얼굴로만 (V3 와 같음): 대충 하면 😐, 잘하면 😊 → 팁.

## 가게 키우기 (시제품 뒤, 방향만)

목욕통 2대째 → 대기 소파 → 미용실(가위·빗) → 고양이·다른 동물, 꾸미기(벽지·바닥·화분). 하루 손님 수가 늘어 **바빠짐**. V3 의 정산·쇼핑·하루 흐름·저장 코드는 그대로 다시 씀.

## 첫 시제품 — 아주 작게

> **"1인칭으로 걸어서, 선반의 도구 3개(샤워기·샴푸·드라이어)를 집어, 목욕통의 강아지 한 마리를 30초 안에 씻기고, 강아지가 반응한다."**

- 넣는 것: 1인칭 걷기, 방 하나(목욕통 + 도구 선반), 도구 3개 집기·내려놓기·쓰기, 강아지 1마리 4단계, 반응 4개, 효과음. (시간 제한 없음)
- 빼는 것: 손님 주인·대기 참을성·접수·계산·하루·쇼핑·리본 — 대표가 "이 느낌 맞다"고 한 뒤에.
- **재사용**: 강아지·목욕통·타일 GLB, 털 셰이더(`sim_fur.gdshader`)와 더러움 마스크 칠하기, 효과음 도구, 수치 리소스, 메뉴. 걷기는 등불 원정대 시제품(PR #12)의 1인칭 플레이어 코드를 git 기록에서 되살리면 빠름.
- 대표가 볼 것 **딱 하나**: "도구를 들고 쓱쓱 씻기는 게 시원하고 재밌나?"
