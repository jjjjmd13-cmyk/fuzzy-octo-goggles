## A. 폭풍 우편선 (가제: *Storm Post*)

**한 줄 소개**: 폭풍 치는 하늘 바다를 가로지르는 낡은 우편 비행선. 엔진은 꺼지고, 돛은 찢어지고, 소포는 굴러다닌다 — 그래도 배달은 제시간에.

**장르**: 3인칭 협동 작업 분담 액션 (오버쿡드식 카오스를 '움직이는 배' 위에서)

### 핵심 재미 (협동)
- 배 위에 **기능 장소(스테이션)** 가 있음: 조타륜, 석탄 화로(엔진), 돛 줄, 화물칸 분류대, 수리 작업대, 대포(해적 새 쫓기).
- 한 사람이 모든 걸 할 수 없을 만큼 일이 동시에 터짐 → 자연스럽게 역할이 나뉨.
- 소통이 필요한 순간:
  - "왼쪽으로 꺾는다, 화물 잡아!" — 조타수가 배를 기울이면 갑판 위 소포·사람이 미끄러짐.
  - 우편함 섬을 지나칠 때 단 몇 초 동안만 소포를 던져 넣을 수 있음 → 조타·속도·던지기 타이밍을 맞춰야 함.
  - 번개로 구멍이 나면 수리 담당이 판자를 들고 뛰고, 나머지는 물(비)을 퍼냄.
- 실패해도 웃긴 장면이 나옴(배 밖으로 떨어짐 → 밧줄로 끌어올리기) — 스트리밍/친구 초대에 유리.

### 혼자 할 때
- **자동 장치 업그레이드**: 혼자일 때는 자동 화로 투입기, 오토 조타(직진 유지)가 기본 제공. 플레이어는 '가장 급한 곳'으로 뛰는 선장 역할.
- **인원별 난이도**: 동시 사건 수, 배달지 수, 제한 시간이 인원 수에 따라 바뀜 (1인: 사건 최대 2개 동시, 4인: 5개).
- AI 동료는 넣지 않음 (개발 비용 큼). 대신 '앵무새 조수' 1마리가 정해진 단순 일(소포 하나 옮기기)만 하는 옵션은 고려.

### 한 판의 흐름 (8~12분)
1. 항구에서 소포 실기 (30초, 화물 종류 확인)
2. 항로 출발 → 날씨 사건이 무작위로 발생 (바람, 번개, 해적 새, 엔진 과열)
3. 섬 3~5곳에 배달 (지나가며 던지기 or 잠깐 정박)
4. 도착 → 별점(배달 수, 소포 상태, 시간) → 돈으로 배 업그레이드
- 메타 진행: 항로 지도(노드 15~20개)를 차례로 열어 감. 끝에 '폭풍의 눈' 마지막 배달 = 엔딩.

### 필요한 3D 에셋 (대략)
| 분류 | 예시 | 개수 |
|---|---|---|
| 배 | 선체 1종(업그레이드 부품 3~4개 교체), 스테이션 6종 | ~10 |
| 캐릭터 | 우편부 캡슐형 1종 + 색/모자 4종 | 1 + 변형 |
| 들고 다니는 것 | 소포 4종, 석탄, 판자, 양동이 | ~8 |
| 배경 | 섬 4~5종(조합해 재사용), 구름, 우편함 | ~8 |
| 적/사건 | 해적 새 1~2종, 번개 이펙트 | ~3 |
| **합계** | | **약 30개** |

**ChatGPT 제작 평가: 쉬움.** 소품 위주, 토이/디오라마 스타일로 맞추기 좋음. 배경 대부분이 하늘·구름이라 환경 에셋이 적음. 애니메이션이 필요한 건 캐릭터 1종뿐.

### 네트워크 난이도: 중간
- 동기화할 것: 배의 위치·기울기(호스트 권한), 플레이어 위치, 들고 있는 물건, 스테이션 상태(화로 온도, 구멍 위치), 소포 물리.
- 위험 요소:
  - **움직이는 배 위의 플레이어** — 배 기준 좌표계로 움직여야 끊김이 없음. 초기에 꼭 시제품으로 검증해야 함 (가장 큰 위험).
  - 굴러다니는 소포 물리 동기화 → 소포는 호스트 물리 + 클라이언트 보간으로 단순화, 개수 제한(동시 20개 이하).
  - 사건이 무작위 → 호스트가 시드·사건을 정하고 알려 주면 됨 (어렵지 않음).

### 비슷한 스팀 게임과 차별점
- **Overcooked! 2** — 고정 주방 vs. *움직이고 기우는 배*. 배 조종 자체가 협동 요소.
- **Sail Forth / Sea of Thieves** — 탐험·PvP 중심의 큰 게임 vs. 짧은 판·배달 목표·PvE만.
- **Lovers in a Dangerous Spacetime** — 2D 스테이션 협동 vs. 3D 갑판을 뛰어다니는 몸 쓰는 협동, 물리 소동.

## B. 등불 원정대 (가제: *Lanternfall*)

**한 줄 소개**: 빛이 꺼진 지하 도시로 내려가는 원정대. 등불 기름이 바닥나기 전에 유물을 들고 돌아와야 한다.

**장르**: 협동 탐사·생존 로그라이트 (1인칭 또는 3인칭, 절차 생성 던전)

### 핵심 재미 (협동)
- **빛 = 체력 = 시간.** 등불 기름은 팀 공용 자원. 어둠 속에 오래 있으면 그림자 괴물이 다가옴.
- 역할(직업 선택): 등불지기(넓은 빛, 느림), 정찰꾼(빛 없음, 빠름, 지도 그리기), 짐꾼(유물 운반, 많이 들지만 무방비), 기술자(문·함정 해제).
- 소통이 필요한 순간:
  - 정찰꾼이 어둠 속에서 길을 찾아 "왼쪽 셋째 통로" 라고 말로 안내.
  - 무거운 유물은 둘이 같이 들어야 함 → 그동안 다른 둘이 빛을 지켜 줌.
  - 쓰러진 동료를 등불로 비춰야 살릴 수 있음 → 구하러 갈지, 기름을 아낄지 결정.

### 혼자 할 때
- **직업 조합 전환**: 혼자일 때는 '만능 원정대원'(빛 중간, 운반 중간) 하나로 플레이, 던전 크기와 괴물 수가 줄어듦.
- 유물 무게 제한을 1인용으로 조정, 2인 운반 유물은 '수레'로 대체.
- 선택: 단순 AI 짐꾼 당나귀(따라오기만 함) — 따라오기 AI는 비교적 만들기 쉬움.

### 한 판의 흐름 (25~35분)
1. 지상 캠프: 기름·도구 구입, 직업 선택 (3분)
2. 지하 1~3층 탐사: 방마다 유물·기름·함정·괴물 (20분)
3. 기름이 반쯤 남았을 때 '더 내려갈지 돌아갈지' 결정 — 핵심 긴장
4. 엘리베이터로 귀환 → 유물 판매 → 캠프 업그레이드
- 메타 진행: 깊이 5층 '빛의 심장'을 되살리면 엔딩. 실패해도 캠프 업그레이드는 유지.

### 필요한 3D 에셋 (대략)
| 분류 | 예시 | 개수 |
|---|---|---|
| 던전 조각 | 바닥·벽·모서리·문·계단·기둥 (층마다 2테마) | 15~25 |
| 소품 | 유물 8종, 기름통, 상자, 함정 4종 | ~16 |
| 캐릭터 | 원정대원 1종 + 직업별 장비 4종 | 1 + 4 |
| 괴물 | 그림자 괴물 3~4종 (애니메이션 필요) | 3~4 |
| 캠프 | 상점, 엘리베이터, 텐트 | ~5 |
| **합계** | | **약 45~55개** |

**ChatGPT 제작 평가: 중간.** 어두운 화면이라 디테일이 덜 보여 단순 모형이 잘 어울리는 장점. 하지만 던전 조각은 **크기·이음새가 정확히 맞아야** 해서 생성 결과를 그대로 쓰기 어렵고 손질이 필요. 괴물 애니메이션도 부담.

### 네트워크 난이도: 높음
- 동기화할 것: 절차 생성 던전(시드 공유로 해결), 괴물 AI 위치·상태, 함정·문 상태, 공용 기름 수치, 들고 있는 유물, 쓰러짐/부활, 빛 범위(괴물 판정에 영향).
- 위험 요소:
  - **절차 생성 + 적 AI + 네트워크** 세 가지가 한꺼번에 — 작은 팀 6개월에는 무거움.
  - 공포·긴장 분위기는 조명·사운드 품질 의존도가 높음 → 임시 모형 단계에서 재미 검증이 어려움.
  - 장르 경쟁이 치열 (아래 참고). 차별점이 약하면 묻힘.

### 비슷한 스팀 게임과 차별점
- **Lethal Company / R.E.P.O.** — 공포·회수 협동의 대표작. 우리는 공포보다 '빛 자원 관리'와 직업 분담 중심, 덜 무서움.
- **Deep Rock Galactic** — 전투·채굴 중심 vs. 전투 거의 없이 회피·관리 중심.
- **Don't Starve Together** — 2D 생존 vs. 짧은 원정 단위 3D 로그라이트.

## C. 태엽탑 (가제: *Clockwork Tower*)

**한 줄 소개**: 멈춘 거대 태엽 시계탑을 한 층씩 올라가며 톱니·레버·추를 맞물려 다시 돌리는 두 태엽 인형 이야기.

**장르**: 협동 물리·장치 퍼즐 (3인칭, 손으로 만든 퍼즐 방)

### 핵심 재미 (협동)
- 퍼즐 방마다 장치(톱니, 도르래, 저울, 회전 발판, 레버, 레이저 대신 '빛 반사 거울')가 있고, **동시에 두 곳을 조작해야** 풀림.
- 캐릭터 능력이 다름: 무거운 인형(저울을 누름, 큰 상자 밀기) / 가벼운 인형(높이 점프, 좁은 틈 통과, 다른 인형 위에 올라탐).
- 소통이 필요한 순간:
  - "내가 레버 당기면 네 쪽 다리가 3초 열려, 셋에 간다!" — 타이밍 맞추기.
  - 한쪽만 보이는 정보(벽 너머 톱니 무늬)를 말로 설명해 맞추기.
  - 3~4인일 때는 방에 장치가 더 늘어나는 '확장 방' 버전 사용.

### 혼자 할 때
- **인형 전환 방식**: 혼자일 때는 두 인형을 버튼 하나로 번갈아 조종 (Trine / The Lost Vikings 방식). 멈춰 둔 인형은 그 자리에서 레버·저울을 계속 누르고 있음.
- 타이밍이 꼭 동시에 필요한 장치는 1인일 때 '태엽 타이머'(몇 초 유지)로 자동 대체.
- 인원별로 방 구성을 바꿈: 1~2인 기본 방, 3~4인 확장 방 (같은 방에 장치 추가).
- **AI가 필요 없음** — 혼자 플레이 조건을 가장 깔끔하게 만족.

### 한 판의 흐름
1. 탑의 한 층(챕터) = 퍼즐 방 4~6개 + 마지막 '큰 시계 장치' 방 (챕터당 40~60분)
2. 방 하나 5~15분: 들어감 → 장치 관찰 → 시도·실패 → 해결 → 다음 방 문이 열림
3. 숨은 태엽 열쇠 모으기(선택 도전), 방마다 체크포인트 저장
- 데모: 1층(방 5~6개). 정식판: 5층 약 30개 방, 꼭대기 시계를 다시 돌리면 엔딩.

### 필요한 3D 에셋 (대략)
| 분류 | 예시 | 개수 |
|---|---|---|
| 장치 | 톱니 3크기, 레버, 저울, 도르래, 회전 발판, 거울, 문, 추 | ~12 |
| 방 조각 | 바닥·벽·계단·난간 (층마다 색만 바꿈) | ~10 |
| 캐릭터 | 태엽 인형 2종 (무거운/가벼운) | 2 |
| 소품 | 상자, 열쇠, 장식 시계 부품 | ~6 |
| **합계** | | **약 30개** |

**ChatGPT 제작 평가: 쉬움.** 톱니·레버 같은 기하학 모양은 상자·원기둥 임시 모형으로도 바로 재미 검증 가능. 스타일을 '나무 장난감 + 놋쇠' 로 정하면 일관성 맞추기 쉬움. 캐릭터 2종만 애니메이션 필요.

### 네트워크 난이도: 낮음~중간
- 동기화할 것: 플레이어 2~4명 위치·동작, 장치 상태(레버 on/off, 톱니 각도, 저울 무게), 밀 수 있는 상자 위치.
- 위험 요소:
  - 장치는 대부분 **상태 기계**(on/off, 각도)라 동기화가 쉬움. 물리 상자는 호스트 권한으로 개수 적게.
  - 타이밍 퍼즐은 지연 시간(핑)에 민감 → 판정 여유를 넉넉히(0.3초 이상) 두고 호스트 기준 판정.
  - **가장 큰 위험은 기술이 아니라 콘텐츠**: 재밌는 퍼즐 방을 손으로 계속 만들어야 함 → 기획팀 레벨 디자인 일이 많음. 반복 플레이 가치가 낮아 정식판 분량(방 30개)이 판매에 중요.

### 비슷한 스팀 게임과 차별점
- **Portal 2 (협동)** — 고정 2인 vs. 1~4인 확장 방, 혼자 플레이 정식 지원.

## 기획팀 추천: **A. 폭풍 우편선**

**이유**
1. **협동의 재미가 가장 바로 보임.** 처음 하는 친구도 30초면 "너 화로, 나 조타" 가 됨. 스팀 친구 초대·스트리밍에서 퍼지기 좋은 장면(배 밖으로 떨어지기, 소포 날아가기)이 저절로 생김.
2. **에셋이 적고 ChatGPT와 잘 맞음.** 약 30개, 대부분 소품. 배경이 하늘·구름이라 환경 제작 부담이 작음.
3. **반복 플레이 가치.** 무작위 사건 + 항로 지도로 같은 판이 잘 안 나옴 → C안처럼 콘텐츠를 계속 손으로 만들 필요가 적음.
4. **6개월 데모 범위가 분명함.** 데모 = 배 1척, 스테이션 4~5개, 항로 노드 5개, 사건 5종.
5. **네트워크는 B안보다 훨씬 가볍고**, 가장 큰 위험(움직이는 배 위의 플레이어 동기화)이 하나로 좁혀져 있어 초기에 확인 가능.

**조건 / 주의**
- 개발팀이 첫 2~3주 안에 "움직이고 기우는 배 위에서 2인이 걸어 다니고 물건을 드는" 네트워크 시제품을 만들어 위험을 먼저 확인해야 합니다. 여기서 막히면 **C. 태엽탑** 을 차선책으로 권합니다 (기술 위험이 가장 낮고 혼자 플레이 조건을 가장 깔끔하게 만족).
- 혼자 플레이의 재미(자동 장치 + 선장 역할)는 기획 단계에서 따로 수치 설계가 필요합니다.
- B안은 매력이 크지만 같은 장르 경쟁작이 강하고 기술 위험이 높아, 첫 작품으로는 권하지 않습니다.
