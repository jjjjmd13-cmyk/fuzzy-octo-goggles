가게 방 바닥 원점, Y-up, 미터 단위로 네 모형을 제작했다. 마당 바닥은 y = 0, 울타리 줄은 x = 9에 맞췄다. 먼 배경 잔디는 y = −0.25에 두고, 기존 찻길 양 끝에 보이는 도로를 연장했다. z = ±14 부근은 낮은 담과 덤불로 양옆을 가리고, 차도를 가로지르는 마감 담은 트럭이 사라지는 지점 너머에 배치했다. 천장 판은 x ±4.1, z ±3.6을 덮고, 정면 처마는 x = 4.3까지 나온다.

Khronos glTF 검사 오류·경고 0건. 내장 알베도 PNG 최대 512 × 512와 Godot 4.4.1 씬 임포트, 원점·조명 고리·무충돌 배치를 확인했다. 새 GLB의 `.import`에서 알베도 텍스처 내장을 유지한다. `art/incoming/outside/`에 위에서 비스듬히 본 모습과 마당 눈높이 미리보기 4장을 넣었다. 천장 미리보기에는 실내 컷을 추가했다.
