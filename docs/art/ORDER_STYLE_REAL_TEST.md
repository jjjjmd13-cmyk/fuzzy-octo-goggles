## 받은 뒤 확인할 것 (일관성 점검)

1. **세 개가 같은 그림체인가**: 강아지·목욕통·빵집을 한 화면에 놓았을 때 재질 질감의 세기, 색의 차분함, 모서리 둥글기가 같아 보이는가 (하나만 사진 같거나 하나만 장난감 같지 않은가).
2. **A 와의 차이가 보이는가**: 비교 PNG 에서 파스텔 A 와 '질감이 보이는' 정도의 차이가 분명한가 — 너무 비슷하면 비교 의미가 없고, 너무 사실적이면 귀여움이 사라짐.
3. **귀여움 유지**: 강아지 비율 (큰 머리·큰 눈)·웃는 얼굴이 그대로인가. 무섭거나 사진 같은 털이 아닌가.
4. **바꿔 끼우기**: 크기·원점·부위 이름이 지금 파일과 같아서, 개발팀이 시험 장면에서 그대로 바꿔 끼울 수 있는가 (강아지 털 칠하기·목욕통 높이·빵집 자리).
5. **스팀 덱**: 텍스처 1024² 이하, GLB 8 MB 이하, 삼각형 (8,000 · 4,000 · 5,000) 안.
6. 게임 파일 (`assets/` 등) 이 하나도 안 바뀌었는가.
