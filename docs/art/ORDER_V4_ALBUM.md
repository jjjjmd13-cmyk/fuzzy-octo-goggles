## 받은 뒤 확인할 것

1. **3D 원점·이름**: `album_book` 의 `Cover` 원점이 책등 쪽 (열면 책처럼 열리는가), `photo_board` 에 `Slot_1`~`Slot_6` 빈 오브젝트가 있는가.
2. **테두리 구멍**: 사진 테두리 4장의 가운데가 정말 투명하고, 4장의 구멍 위치·크기가 똑같은가 (사진이 같은 자리에 들어가게).
3. **크기**: PNG 가 위 크기와 같은가 (다르면 개발팀이 맞추지만 흐려질 수 있음).
4. **글자 없음**: 테두리·스티커·책 표지에 글자가 없는가.
5. 좋아하는 곳 4장이 같은 실루엣에 하트 자리만 다른가 (한눈에 비교되게).
