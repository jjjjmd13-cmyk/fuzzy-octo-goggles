## 받은 뒤 확인할 것 (3줄)

1. 손에 들었을 때 끝이 앞(−Z)을 향하고, 원점이 손잡이에 있는가 (게임 오른쪽 아래에서 손에 붙어 보이는지).
2. 크기가 표와 비슷한가 (너무 크면 화면을 가림).
3. 움직이는 부위 이름(`Head`·`Pump`·`Fan`·`Blade_L`·`Blade_R`)이 맞는가 — 틀려도 들고 쓰는 건 되지만 움직이지 않음.
