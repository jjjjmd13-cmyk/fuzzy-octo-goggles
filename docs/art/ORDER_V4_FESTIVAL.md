## 받은 뒤 확인할 것

1. **마당 장식 좌표**: 게임에서 18일차 아침에 풍선이 정문 양옆·우편함 옆에 서는가, 깃발 줄이 가게 벽에서 마당 끝까지 이어지는가. 엉뚱한 곳이면 원점이 방 가운데가 아닌 것.
2. **길 막힘**: 손님이 울타리 틈 → 정문으로 걸어올 때 아치·풍선에 걸리지 않는가.
3. **모자**: 주인 머리 위에 떠 있거나 파묻히지 않는가 (원점 = 바닥).
4. **봉투**: 우편함 입구 위에 보이고, 글자가 없는가.
5. 삼각형 한도 (4,000 · 600 · 300), 텍스처 1024² 이하.
