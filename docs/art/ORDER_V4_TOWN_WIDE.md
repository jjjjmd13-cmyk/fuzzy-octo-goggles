## 받은 뒤 확인할 것

1. **좌표**: 게임에서 양옆 이웃이 우리 가게 벽에 딱 붙어 있고, 앞마당·울타리가 우리 마당과 한 줄로 이어지는가. 엉뚱한 곳이면 원점이 방 가운데가 아닌 것.
2. **길**: 손님 길 (찻길 → 정문, z ≈ 2.6) 과 택배 트럭 길 (x ≈ 10.5) 을 막는 것이 없는가.
3. **먼 배경**: 마당·가게 창으로 보았을 때 끝이 안 보이고, 찻길 양 끝이 막혀 보이는가. 잔디 판이 찻길·마당 위로 올라오지 않는가.
4. **천장**: 가게 안에서 천장이 벽 위에 딱 맞고 틈이 없는가, 조명 고리가 목욕통 위에 있는가. 마당에서 지붕이 보이는가.
5. 삼각형 (4,000 · 4,000 · 6,000 · 2,000), 텍스처 1024² 이하, 지난번 이웃 건물과 같은 그림체.

## 올리는 곳 · PR · 병합 규칙 (ChatGPT 작업자에게도 같이 전달)

- **올리는 곳**: `assets/models/outside/town_side_a.glb`·`town_side_b.glb`·`town_far.glb`, `assets/models/shop/ceiling.glb` + 미리보기 PNG 는 `art/incoming/outside/`. 이미 있는 파일 (`town_*`, `shop_front` 등) 은 고치지 않음 (게임에 연결하는 것은 개발팀).
- **PR 제목**: `[그래픽] 동네 넓히기 (양옆 이웃 2·먼 배경) + 가게 천장 (파스텔)`
- **병합 규칙**: CI 가 **초록불일 때만** 병합 요청. main 과 **충돌이 나면 고치지 말고 그대로** 두고 PR 에 적기. **main 에 직접 푸시 금지.** 코드 폴더 (`scripts/` · `scenes/` · `tests/` · `project.godot` · `addons/`) 는 **건드리지 않음**. 병합은 대표가 함.
