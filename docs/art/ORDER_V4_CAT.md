## 받은 뒤 확인할 것

1. **이름·계층**: Godot 에서 열어 위 이름이 모두 있는가, `Eye_L` 아래 `Pupil_L`·`Glint_L`, `Tail_1 → 2 → 3` 이 자식으로 이어졌는가. 틀린 부위만 안 움직임 (게임은 안 멈춤).
2. **원점**: `Head` 원점이 목에 있어 고개를 돌리면 목에서 도는가, 귀·꼬리가 뿌리에서 도는가.
3. **털 재질**: 털 메시가 `FurCleanAlbedo` 하나이고 텍스처에 진흙·물 자국이 없는가. 빠른 확인에서 적시기·거품을 칠해 보면 **칠한 곳만** 바뀌는가 (UV 겹침이면 다른 곳도 같이 바뀜).
4. **크기·방향**: 강아지 옆에 세웠을 때 조금 작고, 얼굴이 같은 쪽(−Z)을 보는가. 목욕통 안에 앉혔을 때 엉덩이가 바닥에 붙는가.
5. **삼각형** 8,000 이하, 텍스처 2048² 이하.
