# 스팀 실기 수동 테스트

스팀 연동(로비, 친구 초대, 참가)은 CI 에서 자동으로 확인할 수 없어 사람이 직접 한다.
이 문서 한 장만 보고 따라 할 수 있게 썼다. 전체 테스트 계획은 [TEST_PLAN.md](TEST_PLAN.md) 6장(STEAM).

- **준비물**: 스팀이 깔린 PC 2대, 서로 스팀 친구인 계정 2개 (A = 호스트, B = 손님)
- **걸리는 시간**: 준비 30분 + 테스트 30~40분
- **기준 코드**: 개발팀 협동 기반(PR #4 `dev/foundation`)이 `main` 에 들어간 뒤의 커밋

> 아직 내보내기(export) 빌드가 없어서 **Godot 에디터로 프로젝트를 직접 실행**한다.
> 내보내기 빌드가 생기면 1장을 "빌드 zip 받기"로 바꾼다.

---

## 1. 준비 (두 PC 모두 똑같이)

### 1-1. 스팀

1. 스팀을 켜고 로그인한다 (PC 1 = 계정 A, PC 2 = 계정 B).
2. A 와 B 가 서로 친구인지 확인한다 (친구 목록에 온라인으로 보여야 함).
3. 스팀 설정 → 게임 중 → **"게임 중 Steam 오버레이 사용"** 을 켠다.
4. 앱 ID 는 테스트용 **480 (Spacewar)** 을 쓴다. 따로 설치할 필요 없다.
   테스트 중에는 스팀 친구 목록에 "Spacewar 플레이 중"으로 보이는 게 정상이다.

### 1-2. Godot 4.4.1

[Godot 4.4.1 릴리스](https://github.com/godotengine/godot/releases/tag/4.4.1-stable) 에서 받는다. 다른 버전은 쓰지 않는다.

- Windows: `Godot_v4.4.1-stable_win64.exe.zip`
- Linux / Steam Deck(데스크톱 모드): `Godot_v4.4.1-stable_linux.x86_64.zip`

압축을 푼 폴더를 기억해 둔다 (아래에서 `<godot>` 로 씀).

### 1-3. 게임 코드 받기

두 PC 가 **같은 커밋**이어야 한다.

```bash
git clone https://github.com/jjjjmd13-cmyk/fuzzy-octo-goggles.git
cd fuzzy-octo-goggles
git checkout main          # 특정 PR 을 볼 때는 그 브랜치
git log -1 --format=%h     # 커밋 해시를 결과표에 적는다. 두 PC 가 같아야 함
```

git 이 없으면 GitHub 페이지 → Code → Download ZIP 으로 받아도 된다 (커밋 해시는 페이지 위쪽에서 확인).

### 1-4. GodotSteam 애드온 받기

애드온은 저장소에 들어 있지 않다. 없으면 메뉴의 "친구와 하기" 버튼이 꺼져 있다.

- **Linux / Windows(Git Bash)**: 저장소 폴더에서
  ```bash
  tools/fetch_godotsteam.sh
  ```
  `curl`, `unzip`, `python3` 가 필요하다. 끝나면 `addons/godotsteam/` 폴더가 생긴다.
- **스크립트를 못 쓸 때 (직접 받기)**: [GodotSteam 릴리스(Codeberg)](https://codeberg.org/godotsteam/godotsteam/releases) 에서
  이름에 `gdextension` 과 `4.4` 가 들어간 zip 을 받아, 그 안의 `addons/godotsteam` 폴더를 저장소의 `addons/` 아래에 복사한다.
- 받은 GodotSteam 버전(태그)을 결과표에 적는다. **두 PC 가 같은 버전**이어야 한다.

### 1-5. 첫 임포트와 실행 확인

1. `<godot>` 실행 → 프로젝트 관리자 → **가져오기** → 저장소 폴더의 `project.godot` 선택 → 열기.
   (첫 임포트는 1~2분 걸린다. 끝나면 에디터는 닫아도 된다.)
2. 게임 실행: 에디터에서 **F5**, 또는 명령줄에서
   ```bash
   <godot 실행 파일> --path <저장소 폴더>
   ```
   명령줄 실행을 추천한다. 오류가 터미널에 찍혀서 결과표에 붙이기 쉽다.
3. 메인 메뉴 확인:
   - "친구와 하기 (스팀 로비 만들기)" 버튼이 **켜져 있고**, 아래에 "`<스팀 이름>` 님, 로비를 만든 뒤…" 가 보이면 준비 끝.
   - "스팀을 쓸 수 없음: …" 이 보이면 그 문장을 그대로 적고 아래 "문제가 생기면" 을 본다.

## 문제가 생기면

| 보이는 것 | 확인할 것 |
|---|---|
| "스팀을 쓸 수 없음: GodotSteam 애드온이 설치되지 않음" | 1-4 를 다시. `addons/godotsteam/` 이 있는지, 그 뒤 프로젝트를 한 번 다시 임포트(에디터 열기)했는지 |
| "스팀을 쓸 수 없음: …" (다른 문장) | 스팀이 켜져 있고 로그인돼 있는지. 문장을 그대로 결과표에 적는다 |
| "이 GodotSteam 빌드에는 SteamMultiplayerPeer 가 없습니다" | 받은 GodotSteam zip 이 멀티플레이어 피어를 포함한 판인지. 받은 파일 이름을 적고 개발팀에 이슈 |
| Shift+Tab 으로 오버레이가 안 뜸 | 스팀 설정에서 오버레이가 켜졌는지. 에디터/명령줄로 실행한 게임에는 오버레이가 안 붙는 경우가 있다 → STEAM-01·03 은 ❌ 로 적고, **STEAM-04(친구 목록에서 초대)** 로 나머지를 계속 진행 |
| 초대를 수락해도 아무 일 없음 | 두 PC 커밋·GodotSteam 버전이 같은지, B 가 게임을 켠 상태였는지(STEAM-05 는 지금 안 됨) |
| "스팀 로비 참가 시간 초과" / "로비에 들어갈 수 없습니다" | 로그와 함께 이슈 등록. A 가 아직 게임 안에 있었는지 적는다 |

로그를 남기려면 명령줄 실행 때 출력 파일을 지정한다:

```bash
<godot 실행 파일> --path <저장소 폴더> --log-file steam_test_A.log
```
