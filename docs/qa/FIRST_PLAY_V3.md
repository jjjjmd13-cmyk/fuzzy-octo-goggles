## 날마다

하루 영업은 실제 시간 **8분** (9시 → 6시)이다. 메뉴·정산·아침 화면에 머무는 시간은 사람마다 다르다.

| | 손님 | 씻김 / 떠남 | 번 돈 | 한 손님 손동작 시간 | 산 것 |
|---|---|---|---|---|---|
| 1일차 | 강아지 4 | 4 / 0 | 140 (4 × 35) | 약 53~57초 | 정산에서 창가 화분 (80) |
| 2일차 | 강아지 3 (간지럼쟁이 3) · 고양이 2 (간지럼쟁이) | 5 / 0 | 195 | 약 55초 | 정산에서 넓은 샤워기 (150) + 기본 샴푸 (20) |
| 3일차 | 강아지 2 · 고양이 4 (겁쟁이 2·간지럼쟁이 1) | 6 / 0 | 260 | 약 55초 | — |
| 합계 | 15 | 15 / 0 | 595 | | |

- 손 흉내 기준으로 손님 기분은 강아지 0.39, 고양이 0.07~0.40 이다 (팁 5 정도).
- 처음 하는 사람은 손 흉내보다 느리다. 첫 손님을 씻는 동안 대기 의자에 3명까지 찰 수 있다 (#61 리뷰 Xvfb 화면). 참을성이 150초라 떠나는 손님이 생길 수 있는데, 진행을 막지는 않는다.
- 1일차 수입 140 이라 넓은 샤워기(150)는 2일차를 마쳐야 살 수 있다. 의도한 "하루 아끼기"와 같다.
- 쇼핑을 하지 않으면 기본 샴푸 8마리분이 2일차 5번째 손님에서 떨어진다. 이번 점검에서도 2일차 끝에 0이 됐다. 정산에 "남은 샴푸 N마리분 / 내일 손님 M명" 이 나오고, 샴푸가 없어도 씻기 단계는 끝까지 갈 수 있다.

## 사람 대표가 볼 것 (짧게)

Windows 빌드 받는 법은 `docs/qa/BUILD.md` 에 있다. 저장 파일을 지우고 처음부터 해 본다 (`%APPDATA%\Godot\app_userdata\PawsAndBubbles\slice_save.json`).

1. 소리: 배경음악이 34초마다 다시 처음으로 이어질 때 박자가 어긋나지 않는지. 음량 막대(Esc)가 바로 먹는지.
2. 첫 손님: 위쪽 손동작 그림만 보고 6단계를 끝까지 할 수 있는지. 특히 **샴푸 짜기**(누르고 있다가 떼기)와 **드라이어**(휠로 거리)가 알아지는지.
3. 손맛: 문지르기 원 그리기, 헹구기 위→아래 끌기가 마우스로 편한지. 손목이 아프지 않은지.
4. 1일차 첫 손님을 씻는 동안 대기 손님이 떠나는지. 떠나면 억울한 느낌인지.
5. 고양이·겁쟁이: 요청 카드의 성격 한 줄과 좁아진 초록 칸을 보고 온도를 맞출 마음이 드는지.
6. 정산 → 쇼핑: 무엇을 살지 고민이 되는지 (넓은 샤워기 150 을 언제 살 수 있었는지).
7. 하루 8분이 길거나 짧게 느껴지는지. 3일 전체 걸린 시간.
8. 끝 화면이 "끝났다"는 느낌을 주는지. 다시 하고 싶은지.
