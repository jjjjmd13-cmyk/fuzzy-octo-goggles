## 감사의 날 (18일차)

- 18일차 정산 → [다음 날] → 감사의 날. 클릭 없이 **약 69초** (저녁 2초 → 단골 46초 → 그때와 지금 10초 → 단체 사진 → 별). 점검표 "1분 반 안팎" 안이다.
- 단골이 한 쌍씩 들어와 이름·단계·한마디 ("콩이 · 단짝 / 우리 애가 제일 좋아하는 사람이에요!") ✅
- 그때와 지금 ✅ ("짱구 · 그때와 지금 / 첫 방문 2일차 / ♥ 6일차 단짝이 된 날"). 단 #137 ("오늘 15일차")
- 단체 사진: 주인 8명 뒷줄 + 24마리 앞줄, "찰칵! 단체 사진이 사진첩 마지막 쪽에 붙었어요" ✅
- 별 3개 줄: "☆ 금색 사진 12장 ☆ 5단계 도구 3개 ★ 단짝 단골 6마리" — 아무것도 안 산 실행이라 별 1개가 맞음 ✅. "플레이해 주셔서 고마워요! / Thanks for playing!" ✅
- [계속 영업하기] → 19일차 아침, 엔딩은 다시 안 나옴 ✅. 이어하기도 19일차부터, 엔딩 없음 ✅
