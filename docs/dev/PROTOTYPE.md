# 첫 시제품 실행 방법 (등불 원정대)

GDD 13장 시제품입니다. **"어두운 방 3개에서, 2인이 큰 등불 하나와 공용 기름을 나눠 쓰고, 그림자 추적자 1마리가 빛 밖의 플레이어에게 다가와 잡는다."**
그래픽은 전부 임시 모형(상자·캡슐)이고, 소리는 아직 없습니다.

Godot 를 처음 쓰는 사람 기준으로 적었습니다. 15분이면 실행까지 갑니다.

---

## 1. 준비 (처음 한 번만)

1. **Godot 4.4.1 받기**
   - https://godotengine.org/download/archive/4.4.1-stable/ 에서 **Windows 64-bit 표준판(Standard)** 을 받습니다. **.NET 판이 아닙니다.**
   - 받은 zip 을 풀면 `Godot_v4.4.1-stable_win64.exe` 가 나옵니다. 설치 없이 이 파일을 실행하면 됩니다.
2. **게임 파일 받기**
   - GitHub 저장소 화면에서 초록색 **Code → Download ZIP** 을 눌러 받고 압축을 풉니다.
   - (git 을 쓴다면 `git clone` 해도 됩니다.)
3. **Godot 에서 열기**
   - Godot 를 실행하면 "프로젝트 관리자" 창이 뜹니다.
   - **가져오기(Import)** → 압축 푼 폴더 안의 `project.godot` 파일 선택 → **가져오기 및 편집**.
   - 처음 열 때 1~2분 동안 파일을 읽습니다 (아래 진행 막대). 끝날 때까지 기다립니다.
   - 편집기 화면이 영어라면: 위 메뉴 **Editor → Editor Settings → Interface → Editor → Editor Language** 에서 한국어로 바꿀 수 있습니다 (필수 아님).

## 2. 혼자 해 보기

1. 편집기 **오른쪽 위의 ▶ 버튼**(또는 키보드 **F5**)을 누릅니다.
2. 게임 창이 뜨면 **혼자 하기** 를 누릅니다.
3. 끝내려면 **Esc → 메뉴로 나가기**, 또는 게임 창을 닫습니다.

혼자 하기에서 확인할 수 있는 것: 이동·달리기, 등불 줍기·내려놓기·밝기, 손등, 기름이 줄어드는 것, 기름 0 → 심지 → 어둠, 어둠 게이지, 추적자에게 잡히기.
**부활만 2인이 필요합니다** (혼자일 때는 쓰러지면 바로 원정 실패 → 5초 뒤 다시 시작).

## 3. 같은 PC 에서 창 두 개로 2인 해 보기

창 두 개를 띄워 한 사람이 번갈아 조작하거나, 친구와 한 PC 에서 나눠 해 봅니다.

1. 편집기 위 메뉴 **디버그(Debug) → 실행 인스턴스 사용자 지정(Customize Run Instances...)** 을 엽니다.
2. **여러 인스턴스 사용(Enable Multiple Instances)** 을 켜고, 개수를 **2** 로 바꾼 뒤 확인.
3. **▶ (F5)** 를 누르면 게임 창이 두 개 뜹니다.
4. **첫 번째 창**: 메뉴 아래쪽 "개발용: IP로 접속" 칸에서 **호스트 열기**.
5. **두 번째 창**: 주소가 `127.0.0.1` 인 채로 **접속**.
6. 두 창 모두 게임에 들어가고, 서로의 캡슐이 보이면 성공입니다. (동료가 들어오면 판이 2인 수치로 처음부터 다시 시작합니다.)

- 마우스는 클릭한 창이 잡습니다. 다른 창을 조작하려면 **Esc** 로 마우스를 풀고 다른 창을 클릭합니다.
- 다 끝나면 디버그 메뉴에서 인스턴스 개수를 1 로 돌려 두세요.

> 다른 PC 의 친구와 할 때: 호스트 PC 의 IP 주소를 두 번째 사람이 주소 칸에 넣고 접속합니다 (같은 공유기 안에서만 됨). 스팀 친구 초대는 아직 시제품에 연결하지 않았습니다.

## 4. 조작

| 동작 | 키보드·마우스 | 게임패드 |
|---|---|---|
| 이동 / 달리기 | WASD / Shift (스태미나 5초) | 왼쪽 스틱 / 왼쪽 스틱 누르기 |
| 둘러보기 | 마우스 | 오른쪽 스틱 |
| 줍기 (등불·기름병) | E | A |
| 동료 부활 | E **누르고 있기** (3초) | A 누르고 있기 |
| 등불 내려놓기 | Q | B |
| 등불 건네기 (3 m 안의 동료에게) | R | Y |
| 등불 밝기 올리기 / 내리기 | 휠 위 / 휠 아래 (또는 2 / 1) | RB / LB |
| 손등 켜기·끄기 | F | X |
| 메뉴 (마우스 풀기) | Esc | Back |
| 도움말 보이기·숨기기 | F1 | — |

### 디버그 키 (호스트 창에서만 동작)

| 키 | 하는 일 | 언제 |
|---|---|---|
| **F5** | **기름 30 으로** 처음부터 다시 시작 | 플레이 테스트 **2판째** (PLAYTEST_PROTOTYPE.md) |
| F6 | 처음부터 다시 시작 (기름은 인원별 표대로) | 1·3판째 시작 |
| F7 | 나를 쓰러뜨리기 | 부활을 바로 시험할 때 |
| F3 | 수치 보기 (기름 소수점, 분당 소모, 추적자 상태, 각자 어둠 게이지) | QA 확인용 |

실행 인자로도 바꿀 수 있습니다: `-- --oil-start=30` (매 판 시작 기름).

## 5. 화면 읽는 법

- **바닥의 빛 원**: 큰 등불의 판정 반경 그대로입니다. 원 안 = 빛 안. 추적자는 이 원 안으로 들어오지 않습니다.
- **아래 막대**: 공용 기름. 20 이하면 빨갛게 바뀌고 등불이 깜빡이며, 키움(12 m)을 쓸 수 없습니다.
  기름이 0 이 되면 "심지 N초" (반경 2 m 희미한 빛), 그 뒤 "완전한 어둠".
- **화면 가장자리가 어두워짐**: 내 어둠 게이지 (숫자는 안 보임, F3 으로 확인). 30 이상이면 추적자의 표적 후보가 됩니다.
- **추적자 눈이 빨갛게 + 붉은 빛**: 공격 준비 0.8초. 이때 등불을 든 동료가 달려와 빛으로 덮으면 추적자가 도망갑니다.
- **쓰러짐**: 30초 안에 동료가 **등불 빛 원 안에서** E 를 3초 누르면 일어납니다 (기름 5 소모). 30초가 지나면 기절 (이번 판엔 못 일어남).
- **전원 쓰러짐** = 원정 실패 → 5초 뒤 처음부터 다시 시작.

## 7. 수치 바꾸기 (기획팀)

- 모든 수치는 **`data/balance/balance.tres` 한 파일**에 있습니다. 키 이름은 [TUNING.md](../design/TUNING.md) 와 같습니다.
- Godot 편집기 왼쪽 아래 **파일시스템** 창에서 `data/balance/balance.tres` 를 더블클릭하면 오른쪽 **인스펙터** 에 묶음별로 나옵니다. 값을 고치고 **Ctrl+S** 로 저장한 뒤 ▶ 로 실행.
- 메모장으로 열어 `oil_start = 100.0` 같은 줄을 고쳐도 됩니다.
- 인원별 표(TUNING 7장)는 `party_oil_start` 처럼 `party_` 로 시작하는 줄이며 `[1인, 2인, 3인, 4인]` 순서입니다.
- `proto_` 로 시작하는 값은 TUNING.md 에 아직 없는 시제품용 값입니다 (상호작용 거리, 건네기 거리, 실패 뒤 다시 시작 시간, F5 기름).

## 8. 실행 파일(.exe)로 만들기

Godot 없이 실행 파일로 돌리고 싶을 때. Windows·Linux 내보내기 설정(`export_presets.cfg`)이 들어 있습니다.

1. 편집기 메뉴 **프로젝트(Project) → 내보내기(Export...)**.
2. 처음이면 아래에 "내보내기 템플릿이 없음" 이 뜹니다 → **내보내기 템플릿 관리(Manage Export Templates)** → **다운로드 및 설치** (약 1.2 GB, 한 번만).
3. 왼쪽 목록에서 **Windows Desktop** 선택 → **프로젝트 내보내기(Export Project...)** → 저장 위치 확인 → **디버그와 함께 내보내기** 체크 해제 → 저장.
4. `build/windows/Lanternfall.exe` 하나가 생깁니다 (파일 하나에 게임이 다 들어 있음). 더블클릭으로 실행. 2인은 두 번 실행해서 한 창은 "호스트 열기", 다른 창은 "접속".

- 서명하지 않은 실행 파일이라 Windows 가 "PC 보호" 경고를 띄울 수 있습니다 → **추가 정보 → 실행**.
- CI 에서 자동으로 만드는 것은 다음 작업입니다.

## 9. 시제품에서 정한 것 / 아직 없는 것

기획 문서에 없던 부분을 이렇게 정했습니다. 다르면 알려 주세요 (기획팀).

| 항목 | 시제품에서 정한 것 |
|---|---|
| 심지 빛(2 m) | 어둠 게이지에서는 **손등과 같은 작은 빛** (+1/초). 추적자를 막지 못함 |
| 기름이 5 미만일 때 부활 | 부활은 되고 기름은 0 이 됨 |
| 부활 조건 | 쓰러진 사람이 **큰 등불 반경 안**에 있고, 부활하는 사람이 2 m 안에서 E 를 누르고 있음 |
| 혼자일 때 쓰러짐 | '마지막 불씨'는 시제품 범위 밖 → 바로 원정 실패 |
| 동료가 들어올 때 | 판을 처음부터 다시 시작 (인원별 수치 적용). 로비가 생기면 없앰 |
| 등불 든 사람이 쓰러지거나 나감 | 그 자리에 등불이 떨어짐 (켜진 채) |
| 플레이어끼리 | 서로 통과함 (몸으로 막지 않음) |

아직 없는 것: 소리(경고음·추적자 소리), 화면 가장자리 동료 표시, 밝기(감마) 설정, FOV 설정, 스팀 연결, 기름 도둑, 절차 생성.
