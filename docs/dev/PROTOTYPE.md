# 첫 시제품 실행 방법 (멍냥 목욕탕)

GDD_V2 4장 첫 시제품입니다. **"방 하나에서 강아지가 들어오고, 욕조·드라이어로 씻기고 말려서 출구로 보낸다. 젖은 강아지를 내려놓으면 도망간다."**
그래픽은 임시 모형(공·상자), 소리는 개발팀이 코드로 만든 임시 소리입니다.

## 1. 실행 (Godot 처음이면)

1. https://godotengine.org/download/archive/4.4.1-stable/ 에서 **Windows 64-bit 표준판**(.NET 아님)을 받아 압축을 풀고 `Godot_v4.4.1-stable_win64.exe` 실행.
2. 저장소를 **Code → Download ZIP** 으로 받아 압축을 풂.
3. Godot 프로젝트 관리자에서 **가져오기** → `project.godot` 선택 → **가져오기 및 편집** (처음엔 1~2분 기다림).
4. 오른쪽 위 **▶ (F5)** → 메뉴에서 **혼자 하기**.

- 실행 파일만 받고 싶으면 GitHub Actions 의 "Windows 실행 파일" 결과물(QA CI)을 받으면 됩니다.
- **2인 (같은 PC 창 두 개)**: 편집기 메뉴 **디버그 → 실행 인스턴스 사용자 지정** 에서 여러 인스턴스를 켜고 2 로 → ▶. 첫 창 "호스트 열기", 둘째 창 "접속".

## 2. 조작

| 동작 | 키보드 | 게임패드 |
|---|---|---|
| 이동 | WASD | 왼쪽 스틱 |
| 들기 / 내려놓기 / 기계에 넣기 / 꺼내기 / 출구로 보내기 | **Space** | A |
| 대시 (짧게 빨리, 0.8초마다) | Shift | X |
| 메뉴 / 도움말 | Esc / F1 | Back |

Space 를 누르면 그 자리에서 할 수 있는 일을 알아서 합니다. 화면 아래에 **다음에 할 일**(노란 글자, 예: "대기석의 강아지에게 가서 Space")과 **지금 Space 로 할 일**(흰 글자)이 나옵니다.
시작 안내 문장은 누군가 손님을 처음 들 때까지 화면 위쪽에 남아 있습니다.

## 3. 한 판

1. 강아지(갈색 = 진흙)가 입구 밖 줄을 지나 **분홍 대기석**에 앉습니다. 자리 3개가 차면 입구 밖 매트에 줄을 섭니다 (줄도 3마리까지).
2. 들고 **욕조(파랑, "목욕" 이름표)** 에 Space → 4초 뒤 **젖음(진한 파랑)**. 다 되면 기계 위에 초록 공.
3. 꺼내서 **드라이어(주황, "말리기" 이름표)** 에 Space → 3초 뒤 **뽀송(흰색, 크게 부풂)**.
4. 뽀송 강아지를 **오른쪽 초록 문("출구" 이름표)** 앞에서 Space → 띵! 보낸 손님 +1.
- **젖은 강아지를 바닥에 내려놓으면** 몸을 털고 뛰어다니며 물웅덩이를 남깁니다. 웅덩이를 밟으면 주욱 미끄러집니다. 쫓아가서 Space 로 잡으세요.
- 머리 위: 남은 단계(목욕·말리기)와 **하트 3개**. 기다리면 하트가 줄고(하나에 20초), 다 비면 "흥!" 하고 나갑니다. 들고 있을 때·기계가 도는 동안은 줄지 않습니다.
- 3분 뒤 결과 화면 (보낸 수, 화나서 나간 수, 별). **아무 키**로 다시 시작.
- 별: 1인 3 / 5 / 6마리, 2인 5 / 7 / 9마리. 별 3개는 화나서 나간 손님이 0 이어야 합니다.

## 4. 효과음 7개

| 언제 | 소리 | 파일 |
|---|---|---|
| 진흙 손님 도착 | 철퍽 | `assets/sfx/splat.wav` |
| 욕조 끝 | 뽀글 → 펑 | `bubble_pop.wav` |
| 젖은 손님이 몸을 털 때 | 뚝뚝 | `drip.wav` |
| 드라이어 끝 (털이 부풂) | 뽀옹 | `poof.wav` |
| 손님 보냄 | 띵 | `ding.wav` |
| 화나서 나감 | 흥 | `huff.wav` |
| 웅덩이에서 미끄러짐 | 휘익 | `slip.wav` |

지금 소리는 `tools/make_sfx.py` 로 만든 임시 소리입니다 (외부 파일 없음, 돈·라이선스 문제 없음). 진짜 소리는 같은 파일 이름으로 바꿔 넣으면 됩니다.

## 5. 수치 바꾸기 (기획팀)

- 모든 수치는 **`data/balance/bath_balance.tres` 한 파일** (TUNING_V2.md 키 이름 그대로). 편집기에서 더블클릭 → 인스펙터에서 고치고 Ctrl+S.
- `party_` 줄은 인원별 표 `[1인, 2인, 3인, 4인]`.
- `proto_` 줄은 TUNING_V2 에 아직 없는 개발팀 임시 값입니다: 내려놓는 거리 0.9 m, 들기 부채꼴 반각 70°, 미끄러진 뒤 다시 안 미끄러지는 시간 0.4초.

## 6. 시제품에서 정한 것 / 아직 없는 것

| 항목 | 정한 것 |
|---|---|
| 기계에 넣을 수 있는 상태 | 욕조는 진흙만, 드라이어는 젖음만. 기계가 도는 동안은 꺼낼 수 없음 |
| 줄 선 손님 | 입구 밖이라 아직 들 수 없음. 자리가 비면 맨 앞이 들어와 앉음 |
| 털 때 웅덩이 | 반경 1.5 m 안에 작은 웅덩이 3개 |
| 도망가는 손님 | 기계는 피해 감 (뚫고 지나가지 않음) |
| 플레이어끼리 | 서로 막힘. 밀기(`player_push_strength`)는 아직 없음 |
| 입구·출구 | 입구는 카메라 쪽(그리지 않는 남쪽 벽) 밖, 출구는 오른쪽 벽의 초록 문 |
| 시작 안내 | 시간(`intro_text_time` 3초) 대신 **누군가 손님을 처음 들 때까지** 보임 (QA 리뷰). `intro_text_time` 은 지금 안 씀 |
| 다음 할 일 안내 | 빈손: 대기석 손님에게 / 도망간 손님 잡기 / 기계에서 꺼내기. 들고 있으면: 진흙 → 목욕, 젖음 → 말리기, 뽀송 → 출구 |

아직 없는 것: 감정 표현(E), 밀기, 미끄럼 보내기(다음 반복), 배경 음악, 영어 문구, 진짜 그래픽.
