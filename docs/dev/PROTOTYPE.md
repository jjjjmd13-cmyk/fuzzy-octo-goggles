# V3 시제품 1 실행 방법 (멍냥 목욕탕 — 손맛)

GDD_V3 8장 시제품 1입니다. **"목욕대 작업대 시점에서 강아지 한 마리를 적시고, 거품 내고, 헹구고, 말려서 돈을 받고, 그 돈으로 샴푸 하나를 산다."**
그래픽은 임시 모형(공·상자·원기둥), 소리는 개발팀이 코드로 만든 임시 소리입니다.

## 1. 실행 (Godot 처음이면)

1. https://godotengine.org/download/archive/4.4.1-stable/ 에서 **Windows 64-bit 표준판**(.NET 아님)을 받아 압축을 풀고 `Godot_v4.4.1-stable_win64.exe` 실행.
2. 저장소를 **Code → Download ZIP** 으로 받아 압축을 풂.
3. Godot 프로젝트 관리자에서 **가져오기** → `project.godot` 선택 → **가져오기 및 편집** (처음엔 1~2분 기다림).
4. 오른쪽 위 **▶ (F5)** → 메뉴에서 **혼자 하기**.

- 실행 파일만 받고 싶으면 GitHub Actions 의 "Windows 실행 파일" 결과물(QA CI)을 받으면 됩니다.
- **2인 (같은 PC 창 두 개)**: 편집기 메뉴 **디버그 → 실행 인스턴스 사용자 지정** 에서 여러 인스턴스를 켜고 2 로 → ▶. 첫 창 "호스트 열기", 둘째 창 "접속".

## 2. 조작

| 동작 | 마우스·키보드 | 게임패드 |
|---|---|---|
| 도구 쓰기 (뿌리기·문지르기·닦기·말리기) | **왼쪽 버튼 누른 채 움직이기** | RT |
| 강아지 돌리기 (회전판) | **오른쪽 버튼 끌기**, A/D, ←/→ | 오른쪽 스틱 |
| 커서 | 마우스 | 왼쪽 스틱 |
| 도구 고르기 | 1 샤워기 · 2 샴푸 · 3 수건 · 4 드라이어, 휠, 화면 오른쪽 아래 도구 막대 | 십자 ◀ ▶ |
| 물 온도 | Q 차갑게 / E 뜨겁게 (왼쪽 다이얼, 초록 = 좋음) | 십자 ▼ ▲ |
| 드라이어 가까이 대기 | Shift 누른 채 | B |
| 자리 바꾸기 (목욕대 ↔ 컴퓨터) | **Tab**, 오른쪽 위 버튼 | LB |
| 동전 줍기 | 동전을 왼쪽 클릭 | 커서를 동전에 대고 RT |
| 메뉴 / 도움말 | Esc / F1 | Start / Back |

목욕대 자리에서는 마우스 화살표 대신 **도구 모양 커서**가 나옵니다 (샤워기 = 물방울 색이 온도에 따라 파랑→빨강, 샴푸 = 병 → 짜고 나면 손, 수건, 드라이어).

## 3. 한 마리

화면 왼쪽 위 **요청 카드**에 다섯 단계가 있고, 끝난 단계는 **✓ + 딩** 소리. 진행은 숫자·막대 없이 강아지 몸으로만 보입니다. 거의 다 되면(80%) 남은 곳이 한 번 **노랗게 반짝**입니다. 90% (`stage_complete_ratio`) 를 칠하면 다음 단계.

1. **적시기 (1 샤워기)**: 누른 채 몸을 훑으면 털이 **진하게** 젖고, 진흙이 있던 곳에서 **흙탕물**이 떨어집니다. 물이 **차가우면(다이얼 파랑)** 펄쩍 뛰며 물이 튀고 기분이 나빠집니다. 뜨거워도(빨강) 조금씩 나빠지고, 좋은 온도(초록)면 조금씩 좋아집니다.
2. **거품 (2 샴푸)**: **클릭 = 병에서 거품 한 덩이** (처음 짤 때 병에서 한 마리분을 씀). 누른 채 **빠르게 문지를수록** 거품이 빨리 늘고 소리가 커집니다. 문지른 곳은 진흙이 지워지고 거품 공이 붙습니다. 거품 한 덩이로 몸의 약 1/4 — 다 떨어지면 다시 클릭.
   - **같은 곳을 3초** 문지르면 다리를 찰랑찰랑, **6초**면 몸을 부르르 털어서 **화면에 거품이 튑니다**.
3. **헹구기 (1 샤워기)**: 물줄기가 닿은 거품 공이 작아지다 사라집니다.
4. **수건 (3 수건)**: 몸을 닦습니다.
5. **드라이어 (4 드라이어)**: 말릴수록 털이 **밝아지고 부풉니다**. Shift 로 가까이 대면 빨리 마르지만 너무 가까우면(0.15 m 이내) 싫어합니다. **얼굴에 바람**을 대면 볼이 펄럭입니다.
6. **계산**: 테이블 오른쪽에 **동전**(요금 30 + 기분 팁 + 향 팁)이 나옵니다. 클릭해서 주우면 **짤랑**, 위쪽 돈이 늘고, 1초 뒤 다음 손님이 올라옵니다 (끝없이, 카드에 "N번째 손님").

- **기분 얼굴**(왼쪽 😊😐😣, 강아지 입·귀·꼬리도 같이 바뀜): 차가운 물·눈에 물이나 거품·너무 가까운 드라이어는 나쁨, 좋은 온도의 물은 좋음. 끝났을 때 얼굴에 따라 팁 0 / 5 / 15.
- **복숭아 손님**: 카드에 분홍 글씨 "복숭아 향으로 부탁해요" (손님 3마리 중 1마리 꼴). 복숭아 샴푸로 씻기면 **향 팁 10**.

## 4. 컴퓨터 자리 (샴푸 사기)

Tab → 카메라가 0.4초 동안 컴퓨터로 옮겨 가고 가게 창이 열립니다.

- 시작할 때 **기본 샴푸 한 병(8마리분)**, 돈 0.
- **기본 샴푸** 20, **복숭아 샴푸** 60 (각 8마리분). 사면 그 샴푸를 바로 씁니다 (아래 "쓰기" 버튼으로 바꿀 수 있음).
- 복숭아 샴푸로 짜면 **분홍 거품**.
- 쓰는 샴푸가 떨어지면 클릭해도 거품이 안 나고 "샴푸가 떨어졌어요! … 컴퓨터 자리에 가서 사세요" 안내가 나옵니다.
- 목표 속도: 한 마리 약 2분, 첫 구매(복숭아) 4~5분.

## 5. 둘 이상이 할 때

- 목욕대 자리에 **먼저 앉은 사람이 작업자**입니다. 작업자 화면에서만 칠해지고, 같은 자리의 다른 사람은 진행 결과(단계별 비율)만 보며 "다른 사람이 씻기는 중이에요" 안내가 나옵니다. 동전은 누구나 주울 수 있습니다.
- 작업자가 컴퓨터로 가면 목욕대에 남은 다음 사람이 이어서 씻깁니다.
- 손님·단계·기분·돈·샴푸는 호스트가 정합니다 (혼자 하기도 같은 방식).

## 7. 수치 바꾸기 (기획팀)

- 모든 수치는 **`data/balance/sim_balance.tres` 한 파일** (TUNING_V3.md 키 이름 그대로). 편집기에서 더블클릭 → 인스펙터에서 고치고 Ctrl+S.
- `tests/test_balance` 가 TUNING_V3.md 의 ✅ 줄을 직접 읽어 리소스와 비교하므로, 표와 리소스를 같이 바꿔야 테스트가 통과합니다.
- `proto_` 줄은 TUNING_V3 에 아직 없는 개발팀 임시 값입니다 (아래 표).

| 키 | 값 | 뜻 |
|---|---|---|
| `proto_dose_coverage` | 0.25 | 거품 한 덩이로 문지를 수 있는 몸 비율 |
| `proto_cold_cooldown` | 2 s | 차가운 물 펄쩍 쿨타임 (TUNING_V3 설명란 값) |
| `proto_eye_cooldown` | 1 s | 눈에 물·거품 쿨타임 |
| `proto_tickle_radius` | 0.15 m | "같은 곳" 반경 (TUNING_V3 설명란 값) |
| `proto_dryer_near` | 0.15 m | 드라이어 "너무 가까움" (설명란 값) |
| `proto_shake_screen_time` | 1.5 s | 화면 거품 보이는 시간 (설명란 값) |
| `proto_peach_request_chance` | 0.34 | 복숭아 요청 손님 비율 (3마리 중 1마리) |
| `proto_next_dog_delay` | 1 s | 동전을 다 주운 뒤 다음 손님까지 |

## 8. 시제품에서 정한 것 / 아직 없는 것

| 항목 | 정한 것 |
|---|---|
| 카드 단계 | 적시기 · 거품 · 헹구기 · 수건 · 드라이어 (다섯 줄) |
| 도구와 단계 | 샤워기는 적시기·헹구기 단계에서만 칠함 (거품 단계에 뿌리면 거품 공만 씻김). 수건·드라이어는 자기 단계에서만 진행 |
| 드라이어 거리 | 마우스로는 거리를 못 정해서 보통 0.35 m, **Shift = 0.1 m**. 사이는 `tool_dryer_rate_near`~`far` 를 선으로 이음 |
| 뽀송 크기 | `tool_dryer_fluff_scale` 2배를 모형 전체로 키우면 화면을 덮어서, 모형은 1.3배(2배의 30%)까지만 키움. 진짜 털 부풀기는 그래픽이 오면 셰이더로 |
| 배 밑 | 작업대 시점에서 손이 안 닿는 배 밑(몸 중심에서 바로 아래 방향 53° 안쪽, 몸 표면의 약 20%)은 진행 비율에서 뺌 |
| 수건 | 마스크 텍스처 채널이 4개라 수건 진행은 몸 색에 안 보임 (소리·카드로만). 남은 곳 반짝임도 수건 단계는 없음 |
| 기분 팁 | 계산할 때의 얼굴로 정함 |
| 동전 | 숫자 대신 동전 (값은 동전 위 작은 글자). 화면 위 돈만 숫자 |

아직 없는 것: 탈출(`escape_*`), 다른 동물·자리, 영업 시간·결과 화면, 배경 음악, 영어 문구, 진짜 그래픽(CHATGPT_PROMPTS_V3 대기).
