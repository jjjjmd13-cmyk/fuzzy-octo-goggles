# V3 시제품 1-2 실행 방법 (멍냥 목욕탕 — 단계마다 다른 손동작 + 주인 손님)

GDD_V3 8.1-2 (시제품 1 두 번째 반복)입니다. **주인이 강아지를 맡기면, 단계마다 다른 손동작 6개로 씻기고, 주인이 반응하며 동전을 건넨다. 마우스 하나로 끝까지.**
그래픽은 임시 모형(구·캡슐로 만든 장난감 강아지·주인), 소리는 개발팀이 코드로 만든 임시 소리입니다. 받은 2D 그림은 `assets/ui/` 에 넣으면 바로 쓰입니다 (`assets/ui/README.md`).

## 1. 실행 (Godot 처음이면)

1. https://godotengine.org/download/archive/4.4.1-stable/ 에서 **Windows 64-bit 표준판**(.NET 아님)을 받아 압축을 풀고 `Godot_v4.4.1-stable_win64.exe` 실행.
2. 저장소를 **Code → Download ZIP** 으로 받아 압축을 풂.
3. Godot 프로젝트 관리자에서 **가져오기** → `project.godot` 선택 → **가져오기 및 편집** (처음엔 1~2분 기다림).
4. 오른쪽 위 **▶ (F5)** → 메뉴에서 **혼자 하기**.

- 실행 파일만 받고 싶으면 GitHub Actions 의 "Windows 실행 파일" 결과물(QA CI)을 받으면 됩니다.
- **2인 (같은 PC 창 두 개)**: 편집기 메뉴 **디버그 → 실행 인스턴스 사용자 지정** 에서 여러 인스턴스를 켜고 2 로 → ▶. 첫 창 "호스트 열기", 둘째 창 "접속".

## 2. 조작 — 마우스 하나로 (GDD_V3 2장)

| 동작 | 마우스 | 게임패드 |
|---|---|---|
| 도구 쓰기 (단계마다 쓰는 법이 다름, 3장) | **왼쪽 버튼** | RT |
| 단계의 '양' (물 온도, 드라이어 거리) | **휠** (키보드 Q/E 도 됨) | 오른쪽 스틱 ▲▼ |
| 커서 | 마우스 | 왼쪽 스틱 |
| 도구 | **저절로 손에 들림.** 직접 바꾸려면 오른쪽 아래 도구걸이 클릭 | 커서로 도구걸이 |
| 강아지 돌리기 | **저절로 돎** (보이는 쪽이 85% 되면 1.2초 동안 90°). 일찍 돌리려면 회전판 양쪽 **화살표** 클릭 | 커서로 화살표 |
| 동전 줍기 | 동전 클릭 | 커서를 동전에 대고 RT |
| 자리 바꾸기 (목욕대 ↔ 컴퓨터) | 오른쪽 위 버튼, Tab | LB·RB |
| 메뉴 / 도움말 | Esc / F1 | Start / Back |

오른쪽 버튼·숫자 키는 쓰지 않습니다. 목욕대 자리에서는 마우스 화살표 대신 **도구 모양 커서**가 나옵니다.

## 3. 손님 한 마리 (주인 + 강아지)

1. **주인이 강아지를 안고 들어와** 목욕통 옆에서 **말풍선 그림**으로 요청합니다 (목욕 / 복숭아 향). 강아지를 목욕통에 내려놓고 **대기 의자**에 앉습니다 (목욕대 화면 오른쪽 뒤에 보임). 강아지는 가끔 주인 쪽을 봅니다 (기분이 나쁘면 낑낑).
2. 왼쪽 위 **요청 카드**의 여섯 단계를 차례로 합니다. 끝난 단계는 **✓ + 딩**. 진행은 숫자·막대 없이 강아지 몸으로만 보이고, 거의 다 되면 남은 곳이 1.5초마다 노랗게 반짝입니다.

| 단계 | 도구 | 손동작 | 보이는 것 |
|---|---|---|---|
| 적시기 | 샤워기 | **누르는 동안 물이 나옴 + 조준** (휠 = 물 온도, 다이얼 초록이 좋음) | 물줄기, 맞은 곳이 진해짐, 흙탕물. 차가우면 펄쩍, 물이 얼굴로 가면 고개를 돌리고 눈을 감음 |
| 샴푸 짜기 | 병 | **누르고 있는 시간 = 짜는 양.** 떼면 몸에 떨어짐 | 병이 찌그러지고 덩이가 커짐. 너무 많으면(40% 넘게) 거품이 흘러내리고 병을 한 번 더 씀 |
| 문지르기 | 손 | **동그랗게 원 그리기** (빠를수록 크게) | 원을 그리면 커서에 흰 고리. 왕복만 하면 거품이 거의 안 늚. 샴푸가 떨어지면 병이 다시 손에 |
| 헹구기 | 바가지 | **위에서 아래로 쭉 끌기** (화면 높이 1/4 이상) | 그 자리 세로 띠의 거품이 한 번에 씻김. 3~4번이면 끝. 머리에 쏟으면 부르르 |
| 수건 | 수건 | **꾹꾹 클릭** (0.12초마다 한 번까지) | 누른 자리 물방울이 사라짐. 배를 누르면 "킁" |
| 드라이어 | 드라이어 | **커서로 방향 + 휠로 거리** (0.08~0.5 m) | 가까울수록 빨리 마르고 귀·꼬리가 세게 날림. 0.15 m 밑은 싫어함 (다이얼 빨간 칸). 얼굴에 대면 볼 펄럭 |

3. 다 씻으면 **주인이 와서 반응**합니다: 😊 하트 + 박수 / 😐 끄덕 / 😣 한숨. 목욕통 앞에 **동전**(요금 30 + 기분 팁 + 향 팁)을 놓아 주고, 클릭해서 주우면 **강아지가 주인에게 달려가고(멍!) 함께 나갑니다.** 곧 다음 손님이 들어옵니다.

- **기분 얼굴**(카드 아래, 강아지 눈·귀·혀·꼬리도 같이): 차가운 물·눈에 물이나 거품·너무 가까운 드라이어는 나쁨, 좋은 온도의 물은 좋음. 끝났을 때 얼굴로 팁 0 / 5 / 15.
- **복숭아 손님**: 말풍선·카드에 복숭아 (손님 3명 중 1명 꼴). 복숭아 샴푸로 씻기면 **향 팁 10**.
- 같은 곳을 원으로 3초 문지르면 다리 찰랑, 6초면 몸 털기 (화면에 거품).

## 4. 컴퓨터 자리 (샴푸 사기)

Tab → 카메라가 0.4초 동안 컴퓨터로 옮겨 가고 가게 창이 열립니다.

- 시작할 때 **기본 샴푸 한 병(8마리분)**, 돈 0.
- **기본 샴푸** 20, **복숭아 샴푸** 60 (각 8마리분). 사면 그 샴푸를 바로 씁니다 (아래 "쓰기" 버튼으로 바꿀 수 있음).
- 복숭아 샴푸로 짜면 **분홍 거품**.
- 쓰는 샴푸가 떨어지면 병을 눌러도 거품이 안 나고 "샴푸가 떨어졌어요! … 컴퓨터 자리에 가서 사세요" 안내가 나옵니다.
- 목표 속도 (TUNING_V3 `stage_target_seconds`): 적시기 12 · 샴푸 짜기 3 · 문지르기 15 · 헹구기 10 · 수건 10 · 드라이어 15초, 한 마리 약 65초. `tests/game/test_wash_pace` 가 사람 흉내 손(`tests/game/wash_hands.gd`)으로 잽니다. 지금: **적시기 16 · 샴푸 짜기 0.7(누른 시간) · 문지르기 16 · 헹구기 9 · 수건 8 · 드라이어 11초, 한 마리 61초** (저절로 도는 시간 포함).

## 5. 둘 이상이 할 때

- 목욕대 자리에 **먼저 앉은 사람이 작업자**입니다. 작업자 화면에서만 칠해지고, 같은 자리의 다른 사람은 진행 결과(단계별 비율)만 보며 "다른 사람이 씻기는 중이에요" 안내가 나옵니다. 동전은 누구나 주울 수 있습니다.
- 작업자가 컴퓨터로 가면 목욕대에 남은 다음 사람이 이어서 씻깁니다.
- 손님·단계·기분·돈·샴푸는 호스트가 정합니다 (혼자 하기도 같은 방식).

## 7. 수치 바꾸기 (기획팀)

- 모든 수치는 **`data/balance/sim_balance.tres` 한 파일** (TUNING_V3.md 키 이름 그대로). 편집기에서 더블클릭 → 인스펙터에서 고치고 Ctrl+S.
- `tests/test_balance` 가 TUNING_V3.md 의 ✅ 줄을 직접 읽어 리소스와 비교하므로, 표와 리소스를 같이 바꿔야 테스트가 통과합니다.
- `proto_` 줄은 개발팀 임시 값입니다 (TUNING_V3 7장).

| 키 | 값 | 뜻 |
|---|---|---|
| `proto_dose_coverage` | 0.25 | 거품 한 덩이로 문지를 수 있는 몸 비율 |
| `proto_cold_cooldown` | 2 s | 차가운 물 펄쩍 쿨타임 (TUNING_V3 설명란 값) |
| `proto_eye_cooldown` | 3 s | 눈에 물·거품 쿨타임 (처음 1초 → QA 측정에서 너무 가혹해 3초) |
| `proto_tickle_radius` | 0.15 m | "같은 곳" 반경 (TUNING_V3 설명란 값) |
| `proto_dryer_near` | 0.15 m | 드라이어 "너무 가까움" (설명란 값) |
| `proto_shake_screen_time` | 1.5 s | 화면 거품 보이는 시간 (설명란 값) |
| `proto_peach_request_chance` | 0.34 | 복숭아 요청 손님 비율 (3마리 중 1마리) |
| `proto_next_dog_delay` | 1 s | 동전을 다 주운 뒤 다음 손님까지 |

## 8. 시제품에서 정한 것 / 아직 없는 것

| 항목 | 정한 것 |
|---|---|
| 붓 크기 | 사람 흉내 손으로 목표 시간에 맞춤: `tool_shower_radius` 0.18 → 0.24 m, `tool_scrub_radius` 0.15 → 0.2 m (TUNING_V3 바꾼 기록) |
| 원 그리기 판정 | 최근 0.7초 커서 궤적이 그 무게중심을 270° 이상 한 방향으로 돌았으면 원. 반지름 10 px 밑(손떨림)과 가운데를 가로지르는 직선(왕복)은 세지 않음 |
| 저절로 돌기 | 카메라 쪽 몸 표면(표본 약 400곳)의 85% 가 끝나면 90° (앞 → 옆 → 뒤 → 옆). 다 끝난 단계에서는 안 돎 |
| 샴푸 짜기 단계 | 마스크 없음. 한 번 짜서 떨어뜨리면 끝. 문지르다 샴푸가 떨어지면 병이 다시 손에 들리고 더 짜도 단계는 그대로 |
| 헹구기 띠 | 화면에서 쓴 x 자리의 세로 띠 (폭 0.3 m 를 강아지 깊이에서 픽셀로 바꿈) 를 8 px 간격 광선으로 칠함 |
| 수건 도장 | 한 번 누르면 반경 0.12 m 를 바로 다 닦음 (물방울 수 = 남은 물기) |
| 주인 | 2등신 장난감 6종(모자·옷 색). `assets/ui/owner_<번호>.png` 가 있으면 판자 그림으로 바뀜 |
| 뽀송 크기 | 모형은 1.3배(2배의 30%)까지 |
| 배 밑 | 진행 비율에서 뺌 (몸 표면의 약 20%) |

아직 없는 것 (수직 단면 `docs/design/MILESTONE_V3_SLICE.md` 에서 차례로): 하루 영업·대기 의자 여러 개·정산·다음 날, 고양이·성격, 쇼핑 4칸, 저장, 음악, 처음 하는 사람 안내, 받은 그림 연결.
