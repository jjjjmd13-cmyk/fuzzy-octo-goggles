# 이름 미정 협동 게임 (가제)

Godot 4로 만드는 3D 협동 게임입니다. 스팀 친구 초대로 같이 하거나 혼자서도 할 수 있습니다.

가상의 인디 스튜디오가 만듭니다. 부서(기획팀 · 개발팀 · QA)마다 Claude 세션이 하나씩 있고, 대표 세션이 일을 나눕니다.
운영 규칙은 [CLAUDE.md](CLAUDE.md), 부서별 진행 상황은 [docs/status/](docs/status/) 에 있습니다.

| 폴더 | 내용 |
|---|---|
| `docs/design/` | 게임 기획서 (기획팀) |
| `docs/art/` | ChatGPT 그래픽 요청문, 받은 그림 목록 (기획팀) |
| `docs/qa/` | 테스트 계획, 버그 기록 (QA) |
| `docs/status/` | 부서별 현재 상태 |
