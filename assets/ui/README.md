# 2D 그림 넣는 곳 (교체 지점)

ChatGPT 로 받은 그림(`docs/art/ORDER_V3.md` 5장)을 **아래 이름의 PNG** 로 이 폴더에 넣으면, 다음 실행부터 게임이 그 그림을 씁니다.
없으면 지금의 임시 도형을 그립니다. 코드는 바꾸지 않아도 됩니다 (`scripts/game/ui_art.gd`).

- 투명 배경 PNG 가 가장 좋습니다. 흰 배경이면 개발팀이 지웁니다.
- 크기는 대략이면 됩니다 (게임이 맞춰 줄임). 정사각형 아이콘은 256~512 px.
- 한 장에 여러 개가 그려져 왔으면 개발팀이 잘라서 아래 이름으로 넣습니다.
